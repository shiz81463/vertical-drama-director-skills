## 一、为什么这套工具这么强

市面上绝大多数 AI 短剧工作流，本质上还是“写一段很长的 Prompt → 上平台碰运气抽卡 → 废了就瞎改两句重抽 → 剪辑靠肉眼硬抠”。

**这套编导套装的降维打击，在于彻底用“软件工程思维”驯服生成式 AI 的随机性：**

### 1. 「LLM + 确定性编译器」混合架构：AI 专心做创意，容易错的活全交给代码
大模型天生不擅长算精确秒数、守死几十条格式约束、记住跨段道具状态。本套装独创**编译式提示词引擎（译镜 V2.0）**：
* **AI 只写极简的结构化源文件**（集卡 / 场景卡 / 人物卡 / 段落源），专注表演、调度与戏感；
* **编译器脚本（`build.js`）接管一切确定性工作**：原字注入剧集风格锁、精确计算每一拍的起止秒与硬切点、展开 **34 个可直接点名调用的机位术语**、按四维状态账本自动对齐上下段的【承接画面 / 结束画面】、跑完几十项硬规则静态检查——**❌ 报错不清零，根本不放行上平台烧算力。**

### 2. 用“TDD 测试驱动”沉淀的 23 条真机抽帧反面案例库
每一条规则都不是拍脑袋编出来的，而是拿真实商业剧集踩出来的血泪账：
* 内置 **[反面案例库](skills/译镜/反面案例/README.md)**（23 条典型翻车写法 + 成片真实抽帧证据），专治 AI 视频最隐蔽的怪病：
  * 写“画面上半/下半” → **触发上下分屏**
  * 写“眼睛通红” → **眼珠画成红色怪物**
  * 写“风衣下摆从镜头前扫过” → **整幅黑屏 0.54 秒**
  * 冲刺镜头没写嘴部状态 → **AI 自己张嘴飙脏话**
  * 写“镜头定格/纹丝不动” → **镜尾卡死十几帧静帧**
* 配套自动化回归测试（`self_test.js`）：把反面坏句子逐条注入好稿，检查脚本必须 100% 精准揪出对应规则编号。**踩过的坑永远锁进代码，团队绝不在同一个地方交两次学费。**

### 3. 创作与平台彻底解耦：视频模型再怎么换代，你的核心资产不作废
* **上游「分镜编导 v6」**：只管放之四海而皆准的**戏剧规律、6 环拆戏流程、11 种戏型配方、19 种打戏调度与说话戏型谱**，还能一键把平面站位渲染成 **HTML 俯视机位图（`draw_plan.js`）** 供导演直观审轴线；
* **中游「译镜 V2.0」**：只管把分镜翻译成特定视频平台（当前针对 9:16 竖屏 / Seedance 2.5 深度验证）能演出来的指令；
* **视频模型每隔几个月一换代，你只需重测译镜这一半，整套分镜方法论与剧本资产完全复用。**

### 4. 多模态自动化审片：成片回来，机器先帮你把雷排完
视频下载回来后，一行命令运行 `review.js`，机器立刻完成三项最耗眼力的机械核查：
* **光影与背景一致性拼图**：用 FFmpeg 把同一场戏、同一拍摄方向的所有跨段镜头抽帧拼成对比图，一眼看穿背景漂移与跳光；
* **切点对账**：检测成片真实切点，直接标出哪一段“少切了几刀”（精准抓出最后几镜没演到的废片）；
* **台词语音复核**：接入本地 `faster-whisper` 逐句比对原台词，自动标出漏说、说错、多说或突然串成中文的片段。

### 5. 打通「剪映专业版」最后一公里：帧级抓夹帧 + 废片兜底 + 现做配乐 + 直出工程草稿
绝大多数开源工作流止步于“输出几条 MP4”，而这才是影视后期噩梦的开始。本套装的 `manju-edit` 直接深入到商业剪辑台底层：
* **帧级夹帧/卡帧精准定位**：针对 AI 视频 24fps 进剪映 30fps 时间线最容易在接缝处漏出 1–3 帧“夹帧/混合帧/卡帧”的退稿头号杀手，实测 21 条商业定稿反向校准了剪映向下取帧规则，直接报出**“哪一段、头还是尾、往哪边拖几帧”**；
* **20+ 商业定稿总结的《废片兜底手册》**：掐头、放大重构图、水平镜像、跳点叠盖反应镜……遵循“能挑就不修、能修就不补、补不了才重生成”，把原本要报废重抽的素材救活；
* **Surge XT 开源合成器毫秒级现做音效与配乐**：告别代码拼波形的塑料感，按镜头帧数和切点（误差 0–2ms）现做重击/上升音/悬疑长音，以及统一调性、按情绪切点转场的连贯配乐；
* **直接输出可二次编辑的剪映多轨草稿（`write_draft.mjs`）**：自动带原始素材余量、音画分轨、内置出海 TikTok 英文标准字幕样式（实测单集 256 个片段与真实草稿逐项对齐），在剪映里打开就能直接精修交付。

## 六、实战教程：6 步从剧本到剪映工程

下面用一场 15 秒电梯文戏走完真实生产全链路：
> **剧情**：电梯门将关，林岚伸手拦门，把装着证据的信封递给周屿，说：“你先看完，再问我。”周屿没说话，手伸到信封前却停住了。
> **核心重音**：不在台词多狠，而在他“伸手又没接”的停顿。

> 💡 **强烈建议**：遵守 [模型流程树](skills/分镜编导/编导套装/模型流程树.md) 的节点拆分原则——**分镜和译镜永远分两个对话开**，防止上下文过长导致模型忘细节、烧 Token。

### Step 1｜准备开工四件套（别让 AI 瞎猜）

准备一个清晰的工作目录（推荐每集建 `第01集/`，下设 `源/`、`提示词/`、`成片/`、`审片/`；剧设定与角色/场景图放公共资产目录），明确四件事：
1. **画幅与单集时长**：如竖屏 `9:16`、约 `90 秒`（初次上手建议先拿 1 场戏试跑）；
2. **定稿剧本 + 台词语言**：注明普通话或美式英语（不同语速直接决定每镜秒数），有上下集可附尾/开头防抢戏；
3. **场景总览图 + 角色/道具图**：场景图最好带俯视格（能看清门、走廊、主光源位置）；一人一图、一物一态；
4. **剧设定（画风风格锁）**：新剧没有的话，先让 AI 读 [新剧输入卡](skills/译镜/规则档案/新剧输入卡.md) 和你一起拍板定一版。

---

### Step 2｜对话一：用「分镜编导」出分镜脚本与机位图

新开对话，直接把下面口令改好路径发给 AI：

```text
用分镜编导（Codex 点名 fenjing-biandao）。
读「第01集_剧本.md」定稿。竖屏 9:16，全集约 90 秒，普通话。
场景和角色图在「资产/」目录。先只做电梯这场戏，不要写视频提示词。
这场的情绪重音是“周屿伸手却没接信封”。
请按 6 环交付：开工卡、节拍表、场景卡、逐镜分镜（写清每镜起→止状态）、台词对账和检查结果。
```

AI 会产出结构化分镜表（例：关系镜 3s 交代拦截 → 林岚中近景 5s 给足说词时间 → 周屿反应 4s 接住台词重量 → 两手与信封 3s 停在未接动作瞬间）。交付后跑两条脚本验收：

```sh
# 1. 自动核查分镜格式、台词漏改、可拍性与规则（只做单场加 --partial，整集去掉）
node "skills/分镜编导/scripts/check_storyboard.js" "第01集_分镜.md" --partial

# 2. 生成 HTML 俯视机位图，浏览器打开直接对照总览图审轴线与站位
node "skills/分镜编导/scripts/draw_plan.js" "第01集_分镜.md"
```

**✅ 本步过关标准**：脚本 ❌ 为 0，导演确认机位、轴线、重音和台词无误后，结束本对话。

---

### Step 3｜对话二：用「译镜 V2.0」写源文件并编译成提示词

**新开一个对话**，把确认过的分镜和剧设定交给译镜（5 段以内可一个对话写完，超过 5 段按场戏分对话）：

```text
用译镜（Codex 点名 yijing）读取已确认的「第01集_分镜.md」和「电梯试戏_剧设定.md」。
按 V2 先写电梯这一段，保留普通话台词原文。
严格照「资产/」里平台实际会 @ 的场景总览图推方向，图里没有的角度先列待补。
输出：集卡.txt、场景卡.txt、人物卡.txt、段1.txt，并运行编译与语义审查清单。
凡是为台词加秒或有时间跳的地方，在编译报告里单列给我确认。
```

运行编译与静态检查（AI 具备命令行权限时会自动执行）：

```sh
node "skills/译镜/scripts/build.js" "第01集/源" --bible "电梯试戏_剧设定.md" --out "第01集/提示词"
node "skills/译镜/scripts/check.js" "第01集/提示词" --style "电梯试戏_剧设定.md"
```

以后返工只需改对应的源文件再重编，绝不手撕长提示词：
* 门左右反了、光不对 → 改 `场景卡.txt`
* 衣服换了、引用名错 → 改 `人物卡.txt`
* 节奏太赶、视线或动作衔接不对 → 改 `段N.txt`

**✅ 本步过关标准**：编译报告 ❌ 清零、AI 过完语义审查清单、你确认完“要总控批的事”。

---

### Step 4｜上视频平台生成（先试 1 段，别盲目梭哈整集）

1. 在生成平台（如漫影工坊 Seedance 2.5）按编译报告里的主体清单建好**人物、道具、场景总览**，主体名和提示词里的 `@` 严格一字不差；
2. 核对画幅 `9:16` 与段时长，先生成 `段1` 看效果；若同场多段背景偶发偏移，或后期需补单镜，再按 [详细使用手册](编导套装_使用手册.md) 第 3 节补对应方向图并精确 `@`；
3. 下载成片按 `第01集_段1.mp4`、`第01集_段2.mp4` 规范命名。

> 注：本套装不包含视频平台账号与算力额度，脚本绝不代替用户擅自上传或点击生成。

---

### Step 5｜一键自动审片 + 精准定位病根返工

成片下载到 `第01集/成片/` 后，先跑机器自动审片：

```sh
# 轻量跑法（出同方向光影拼图 + 切点对账，不跑语音识别）
node "skills/译镜/scripts/review.js" "第01集/提示词" "第01集/成片" "第01集/审片" --no-asr

# 完整跑法（加上本地 faster-whisper 语音模型，自动核查台词错漏与串语言）
node "skills/译镜/scripts/review.js" "第01集/提示词" "第01集/成片" "第01集/审片" --asr-model "<你的whisper模型路径>"
```

打开 `第01集/审片/审片报告.md` 与拼图，**按病根表精准返工**，拒绝瞎改：

| 审片发现的问题 | 正确的止血与返工方式 |
| :--- | :--- |
| 反打时背景门跑错边 / 光变方向 | 回场景卡核对总览图俯视格，必要时补一张方向图；**不要**在提示词里反复加“背景保持一致”。 |
| 上段没接信封，下段突然拿在手里 | 核对上下段【结束画面 / 承接画面】，改源文件重编译；只重生成受影响的段。 |
| 少切 1 刀 / 英文台词漏词或太赶 | 核对语速和最后 1 秒留白，回分镜确认加秒或精简赘字，改源文件重编。 |
| 只在切点闪过 1–2 帧无关画面或尾部轻微变形 | **别浪费算力重生成！** 直接进入第 6 步，在剪辑台用 3 秒钟切掉或兜底救活。 |

> ⚠️ 原则：临时手改提示词测通后，务必让 AI 用“回写口令”同步回源文件，避免下次编译覆盖成果。

### Step 6｜用 `manju-edit` 剪辑救片、配乐、直出剪映草稿并帧级质检

新开对话交给 `manju-edit`，按顺序完成剪辑交付：

1. **按分镜粗剪 / 废片兜底 / 深度精剪**：
   ```text
   用 manju-edit，结合「第01集_分镜.md」和「第01集/成片/」里的素材做基础剪辑（有瑕疵素材按兜底手册出救片方案），输出镜头取舍表和可写入剪映的剪辑方案 JSON。
   ```
2. **（可选）按切点毫秒级现做设计类音效与连贯配乐**（需已配置 Surge XT + pedalboard）：
   ```sh
   # 按镜头帧长和音高现做重击 / 上升音 / 悬疑长音
   <python路径> -I "skills/manju-edit/scripts/sound/surge_sfx.py" "第01集/音频" riser len=72f hit pitch=-3 drone len=15

   # 按切点写全程统一调性的多情绪配乐（支持分轨 stems=1，人听过再进片）
   <python路径> -I "skills/manju-edit/scripts/sound/surge_music.py" "第01集/音频/第01集_配乐.wav" mood=悬疑:12,压迫:28,悲伤:45 hits=12,28 stems=1
   ```
3. **直接写成一条新的剪映专业版草稿**（绝不覆盖旧工程，自动留明文备份）：
   ```sh
   node "skills/manju-edit/scripts/write_draft.mjs" "第01集/剪辑方案.json" --dry-run  # 先干跑校验
   node "skills/manju-edit/scripts/write_draft.mjs" "第01集/剪辑方案.json"            # 正式生成草稿
   ```
4. **交付前帧级双保险质检**（打开草稿前查草稿，导出成片后查成片）：
   ```sh
   # 对草稿查公司十条交付红线 + 读原始素材帧级查头尾夹帧/卡帧
   node "skills/manju-edit/scripts/qc_draft.mjs" "<草稿名或路径>"

   # 对最终导出的 MP4 查夹帧、卡帧、黑场、声音硬切、响度峰值，并输出逐镜头接触表
   node "skills/manju-edit/scripts/qc_media.mjs" "第01集/成片/第01集_精剪.mp4" --out "第01集/成片质检"

   # 对可疑时间码导出前后 12 帧逐帧条，肉眼一秒定案
   node "skills/manju-edit/scripts/qc_media.mjs" "第01集/成片/第01集_精剪.mp4" --strip 25.6,58.8
   ```

**✅ 最终交付**：机器把所有时间码级疑点排清，剪辑师在剪映里打开现成多轨草稿完成最后把关与导出。

## 七、个人创作者 vs 商业团队怎么用

* **个人独立创作者**：先跑通自带 V2 样例，再拿一场 15 秒戏走完 6 步；跑顺后再做整集，省下的抽卡钱和修片时间立竿见影。
* **多集连载 / 商业制作团队**：
  * **公共资产层**：整部剧共享剧设定、人物卡、场景卡与导演反馈记录；
  * **岗位接力层**：导演只审「分镜 + HTML 机位图」→ 编导/AI 跑「译镜编译 + 生成 + 自动审片」→ 剪辑直接接手「剪映草稿 + 帧级质检报告」。**交接靠文件与报告，彻底告别口头扯皮和超长聊天记录断档。**
* **只想接入质检的成熟团队**：无需改现有出片流程，直接单独用 `qc_media.mjs` / `qc_draft.mjs` 给成片和剪映草稿做交付前自动“排雷”。
