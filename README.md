三个技能覆盖剧本 → 分镜 → Seedance 分段提示词 → 剪映剪辑。支持 Claude Code 和 Codex。

| 技能 | 版本 | 用途 |
| --- | --- | --- |

## 开始使用

- [安装与使用说明](说明_给人看.md)；[AI 入口](从这里开始_给AI读.md)。
- Windows：运行 `powershell -File .\安装到这台电脑.ps1` 预演，确认后追加 `-Apply`。
- macOS / Linux：运行 `bash 安装到这台电脑.sh` 预演，确认后追加 `--apply`。
- 核对依赖及运行示例：`node 检查环境.mjs --试跑`。

公开版附两个用于译镜试跑的剧设定示例；不包含内部审片记录、团队文档原文或内部链接。使用时请提供自己的剧本、剧设定和资产。旧版仍可从 [v4.0.0](https://github.com/shiz81463/vertical-drama-director-skills/releases/tag/v4.0.0) 下载。
