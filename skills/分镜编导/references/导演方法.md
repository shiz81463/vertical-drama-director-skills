# 导演方法：规则背后的八条原理

v5（2026-11-21）新加。这份不是新规则，是规则背后的道理：导演、剪辑师几十年验证过的做法，分镜编导各环的规则从这里推出来。遇到规则没写到的情况，回这里想：这条原理在这场戏里要求什么。

每条写四样：原理（大白话）、谁说的、落在哪几条规则、竖屏和横屏（电影感）各怎么用。最后一节是 AI 生成和真人拍摄不一样的地方。

标记：
- 〔导演方法〕：电影里成立；在 AI 生成里还没验证。规则带这个标记，等同〔待验证〕，登记在 `测试登记.md`。
- 〔外部实测·zenstory〕：别人在 Seedance 2.0 / 2.5 上做过对照实验（每种写法生成 3 次、打乱顺序盲看，只测了一两个场景，不是漫影工坊）。比〔导演方法〕多一层证据，仍待我们自己验。

## 一、分镜就是剪辑

**原理**：真人剧组会做"覆盖拍摄"（同一场戏从几个角度各拍一遍，剪的时候再挑）。AI 生成没有这一步：每一镜生成出来，基本就是成片里的那一镜。所以画分镜的时候，剪辑就已经做完了。每一镜都得是"非它不可"的那一镜。

**谁说的**：
- 奉俊昊：从《杀人回忆》起画带台词的详细分镜，说成片和分镜约 99% 一样，现场只拍需要的那几条。
- 今敏："动画是先剪辑"，剪辑在分镜阶段做；《未麻的部屋》在分镜阶段扔掉了约 100 个场景。

**落在哪**：
- 环5 验收"删镜自问"：删掉这一镜，观众少知道什么、少感到什么？答不出，就删掉或并进相邻一镜。
- 5.3 切入理由；5.12 插入镜头要推动因果。

**竖屏**：镜头多、切得快，更要删。两镜讲同一件事，就并掉一镜。

**横屏（电影感）**：镜头长，一镜里能装几拍。删的不是镜头，是镜头里"没事发生"的那几秒。

## 二、观众此刻要看什么

**原理**：
- 每一镜回答同一个问题：观众现在最想看什么。
- 一刀切得顺，是因为观众正想看一样东西，而这一镜还看不到它。
- 一样东西在画面里有多大，看它这一刻对故事有多重要。

**谁说的**：
- 麦肯德里克（《成功的滋味》导演，后来教电影）："看不见的目击者"代表观众的眼睛，机位、景别、剪接都由"现在需要看到什么"决定。
- 希区柯克：东西在画面里的大小，跟它此刻的重要性成正比。

**落在哪**：
- 4.4 主力景别：景别看这一刻最要紧的东西该有多大。
- 5.2 镜头怎么引导；5.3 切入理由。
- 5.11 景别要看得清写的东西。

**竖屏**：最要紧的东西落在一侧三分线上、焦点在它身上；要紧的是手、道具，就移焦过去再带回脸，不在中景里指望观众看见。（v6：旧句"放在画面上方六成以内"作废，会分屏）

**横屏**：可以让要紧的东西小、但放在构图的焦点上（光、线条、留白把眼睛引过去）。这是横屏比竖屏多出来的办法。

## 三、意思在两个镜头之间

**原理**：一个镜头本身意思有限；两个镜头接在一起，观众自己会补出意思。最重的那句话，力量常常落在听的人脸上，不在说的人脸上。

**谁说的**：
- 库里肖夫实验：同一张没表情的脸，接在一碗汤、一口棺材、一个小孩后面，观众分别读出饿、悲伤、慈爱。
- 马麦特：每个镜头平平无奇、不加修饰，意思靠前后拼接出来；镜头表本身就是在讲故事。

**落在哪**：
- 2.7 重要事件后跟反应拍；2.8 爽点要有旁观者；2.9 长台词落在不同人脸上。
- 2.15 每场戏标重音（最重的一句或一下）、定它落在谁脸上；5.23 重音落点怎么切。
- 5.9 同框说话时，听的人看不看说的人。

**竖屏**：说的人一镜，听的人一镜，干净地切开。一镜只有一张嘴在动。

**横屏**：可以把说的人和听的人放在同一个画面里（一前一后，焦点在听的人身上），让观众同时看到"话"和"被话打中"。这一招在 AI 里没验证。

## 四、画面松紧跟着戏走

**原理**：
- 画面里的对比越大（大小、明暗、远近、高低、快慢），看着越紧；越相似越松。
- 画面的紧和松，应该跟着戏的紧和松，画成一条曲线。
- 最紧的那一下要留到戏最紧的地方，前面用掉了，到时候就没有更紧的了。
- 强度来自对比：一路紧之后突然一个大景，也是一种"最紧"。

**谁说的**：
- 布洛克《视觉故事》：对比和相似。
- 吕美特拍《十二怒汉》（几乎全片在一间屋里）：前面用广角、机位略高；越往后，镜头越长、机位越近越低，到最后几乎全是低于眼睛高度的特写，观众跟着喘不过气。他和摄影师开拍前就把每个机位都定好了。

**落在哪**：
- 2.16 画面曲线：情绪曲线下面写一行画面怎么跟着变。
- 4.12 强度（收 / 显 / 过 / 破）决定镜头的默认松紧。
- 4.2、4.3 景别呼吸（已有）。

**竖屏**：靠景别和纵深做松紧，少靠俯仰（竖屏大幅俯仰会把人拉扁，见 3.19）。

**横屏**：除了景别，还可以用镜头长短（焦段）和机位高低做曲线。这正是吕美特的做法：越往后镜头越长、越低、越近。

## 五、人先动，镜头有理由才动

**原理**：
- 关系靠人的走位讲：谁走近、谁退开、谁挡在中间。
- 镜头动，要有一个"带着它动"的东西：跟着一个人走、被一个声音拉过去、跟着情绪往前逼。
- 没有理由就不动。
- 特写少用，一用就是大事。

**谁说的**：
- 斯皮尔伯格：常把一整场戏放在一个镜头里，靠演员走位和前后景的纵深讲关系，不站着说话、来回切；有时故意不切，把悬念攒着。
- 芬奇：镜头不会无缘无故动；动的时候和人物同速同向。

**落在哪**：
- 5.2 镜头怎么引导：运镜写出是谁、是什么带着镜头动。
- 5.7 一个移动在一镜里完成；5.14 横屏长镜头调度。
- 3.10 移动顺着画面长边。

**竖屏**：走位顺着纵深走（走向镜头、走进深处）。镜头跟人"同速"，就是人走近，镜头不退。

**横屏**：横向走位最清楚；一场戏可以设计一次"走位改变关系"的调度，代替三四刀正反打。

## 六、观众知道多少

**原理**：同一件事，观众先知道还是后知道，拍法完全相反。
- **观众比人物先知道**，是悬念：先给观众看炸弹（插入镜头），再拍蒙在鼓里的人。这时候镜头要停得住，观众在替人物着急。
- **观众和人物一起知道**，是惊吓：一直藏着，到点一下亮出来。

**谁说的**：希区柯克的"桌下炸弹"：桌下有炸弹，观众不知道，炸了只吓一跳；观众先知道，两个人聊天的几分钟就全是悬念。

**落在哪**：
- 2.17 揭示戏、钩子悬念、追逐潜入这几种戏，写清观众比人物多知道、少知道，还是一样。
- 戏型拍法的揭示戏、钩子悬念两节。

**竖屏**：钩子常用"观众先知道"：开头先亮危险，再切到人。

**横屏**：可以用前后景同框做悬念：前景是危险，后景是不知情的人，一个镜头里观众就知道了。

## 七、一个变化只发生一次，状态要交接

**原理**：
- 每一镜开头是什么样、结尾是什么样，要写清楚；下一镜的开头必须接上上一镜的结尾。机位、景别可以换，人的姿态、手里的东西、门开没开不能变。
- 放下钥匙、推开门、坐下这种变化，只在一镜里发生一次；后面的镜头顺着结果往下接，不换个角度再演一遍。
- 高潮故意从几个角度重放同一瞬间，要标明是重放。

**谁说的**：这是剪辑连贯的基本功（动作剪辑点：做到一半换镜头，下一镜接着做完）。外面三个 AI 短剧项目不约而同都把它做成了一栏：zenstory 写"起点 → 动作 → 终点"，ViMax 写首帧、尾帧、运动，漫剧老李写"前态 → 后态"。

**落在哪**：
- 5.20 分镜表加"起 → 止"一列；5.7 一个移动在一镜里完成；5.13b 一镜一个物理变化。
- 译镜的结束状态、连续性账本、补镜头时读前后段，都从这一列拿。

## 八、规则打架时的先后

**原理**：一刀好不好，要看好几件事，它们会打架。打架时，从最不要紧的那件往上让。

**谁说的**：剪辑师默奇（剪过《现代启示录》《英国病人》）列了六件，按重要性排：情绪 > 故事 > 节奏 > 视线 > 画面上的左右方向 > 三维空间。他说情绪最后才让。

**落在哪**：`SKILL.md`"规则打架时听谁的"一节。我们的顺序和默奇不完全一样：
- **拍得出来排第一**：AI 拍不出来的镜头，再动人也没用。
- **看得懂排在情绪前面**：竖屏短剧的观众是碎片时间在看，看不懂就划走了。这一条用户还没确认。

## 九、AI 生成和真人拍摄不一样的地方

上面八条是电影的道理。下面几条是生成模型的脾气，规则要绕着它们设计。

| 现象 | 证据 | 规则 |
|---|---|---|
| 没有覆盖拍摄，生成的那一镜就是成片 | 生成方式本身 | 原理一 |
| 一镜里两张嘴，模型会让两个人都动嘴 | 惹火34、第 29 集 | 5.8、5.17 一镜一张嘴 |
| 镜头里的先后顺序靠不住："她说完他再看"，9 次错 7 次 | 〔外部实测·zenstory〕 | 5.22 先后要紧就切开 |
| 动作快慢由镜长决定：同样一回合打斗，6 秒里会发呆约 1.5 秒，4 秒里 3 秒打完；写"一气呵成"没用 | 〔外部实测·zenstory〕 | 5.21 一镜容量 |
| 一镜塞多了不会被删，会被压扁：5 秒 6 个动作，第三个起每个约半秒 | 〔外部实测·zenstory〕 | 5.21 |
| 打到人身上的一下，侧面拍 3 次 1 次看得出；机位在出手的人身后、接触点被他挡住，3 次都看得出 | 〔外部实测·zenstory〕 | 打戏镜头调度 第 18 种 |
| 站位参照的东西不在场景图里，模型会自己造一个，还会改房间 | 〔外部实测·zenstory〕 | 3.16 补 |
| 只写"隔着桌子相对"，9 次全站到桌子同一侧；按机位写前后景，3 次都对 | 〔外部实测·zenstory〕 | 分镜写关系，译镜翻成这个机位看到的前后景（译镜那一半） |
| 画外音念的台词常常没念出来 | 惹火34 | 5.8 |
| 纵深同框写"近的在下"，模型让站着的人坐下了 | 第 29 集 | 3.19 |
