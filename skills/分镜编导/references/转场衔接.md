# 转场衔接：换场、换装、跳时间时，两个镜头怎么接得顺

环5 规则 5.15：戏和戏之间（换地方、换时间、换衣服、进出回忆）那一刀，从这里挑一种接法，写进分镜表"接法"一格，格式 `转场·遮挡：因为…所以…`。

- 来源：阿梨漫剧《这套AI转场运镜，你打几分？》（2026-10-25 用户给的视频），里面的五张公式卡整理过来，加上本技能的写法。**全部〔待验证〕**：还没在一集里拍过，拍过、导演认可后改成〔验证·剧名集数〕。
- 转场（大白话：从一场戏跳到下一场戏的那一下）。解决的问题：硬切换场，观众会觉得"画面断了一下，这是哪？"；有一个东西把两镜连起来，眼睛顺着走过去，换场就不跳。

## 先分清：戏里的切 vs 戏和戏之间的切

| | 戏里（同一场、同一时间） | 戏和戏之间（换场） |
|---|---|---|
| 用什么接 | 规则 5.3 的四种：看、动、因果、交代 | 本文件五种：动作承接、相似衔接、视线引导、甩镜、遮挡 |
| 目的 | 讲清因果、谁在哪 | 让观众舒服地跳到新地方 / 新时间 / 新衣服 |
| 关系 | "看""动"就是视线引导、动作承接在同一场里的用法 | 同样的手法，下一镜换了地方或衣服 |

## 五种转场

### 1. 动作承接

- **大白话**：上一镜抬脚，下一镜落脚，但脚已经落在新地方、穿着新衣服。一个连续的动作把两个画面缝起来。
- **适合**：换装、赶路、时间跳跃（伸手拿钞票 → 钞票落进另一个场景）。
- **分镜怎么写**：上一镜"画面"写到动作做到一半（"右手抬起，举到胸口高"）；下一镜"画面"从动作后半段开始（"右手从胸口高落下，按在……上"），不从头重演。
- **对齐**：人物在画面里的位置、动作方向、动作幅度两镜一致（上一镜人在画面左三分之一往右挥，下一镜也在左三分之一往右挥）。
- **切点**：动作进行到一半时切；删掉动作开始前和结束后的停顿（交给剪辑）。
- **竖屏**：上下方向的动作（抬头、举手、跳起、落下）最顺竖屏的长边。
- **横屏**：左右方向的动作（挥手、转身、迈步横穿画面）。

### 2. 相似衔接（匹配剪辑）

- **大白话**：上一镜结尾和下一镜开头，画面里有一个东西长得像（形状、颜色、位置），眼睛停在同一个地方，背景已经换了。
- **三种相似**：
  - 形状：黑色轿车 → SUV 车身；电话亭 → 大堂立柱；圆的月亮 → 圆的盘子。对齐轮廓和大小。
  - 颜色：黑大衣 → 黑车身；绿内搭 → 绿电话亭。相同颜色在相近位置。
  - 构图：人物居中 → 人物居中，头的位置、走路的路线、空间透视对齐。
- **适合**：换装、换景、表现时间和空间的变化（同一片街道从白天到暴风雨）。
- **分镜怎么写**：两镜的"画面"都写出那个相似的东西**在画面哪里、多大、朝哪**（"黑色车身横贯画面中部，占画面宽三分之二"），写成一样的。
- **切点**：在两个画面最像的那一帧切；可以配音乐节拍（交给剪辑）。
- **竖屏**：相似的东西放在画面中线上，上下位置对齐（竖屏左右空间窄，差一点就看出来）。
- **横屏**：可以用左右三分线对齐。

### 3. 视线引导

- **大白话**：人先看向某处，下一镜就是他看到的东西——而那个东西在新的地方，或者是另一个人的回应。观众的眼睛跟着角色的注意力走。
- **适合**：开场铺环境、引出关键人物、制造悬念（看到门后一个人影，观众忍不住想知道他看到了什么）。
- **分镜怎么写**：上一镜写清看的方向（"转头看向画面右上方"）；下一镜写他看到的，方向对得上（东西在他视线那边）。
- **切点**：转头快做完、视线落定时切，下一镜马上把重点放出来。
- **跟规则 5.3"看"、5.12 主观镜头一样要求**：他从那个位置、那个高度真的看得到。

### 4. 甩镜转场

- **大白话**：镜头猛地往一边甩，画面糊成一片；下一镜从同一方向的糊里甩出来，已经是新地方或新衣服。
- **适合**：节奏快的换场、追逐打斗、"与此同时另一边"。
- **分镜怎么写**：上一镜"角度 / 运镜"写"结尾向右急甩"；下一镜写"开头从左侧向右甩入，停在……"。两镜甩的方向一致，速度接近。
- **切点**：在运动模糊最强的地方切；必要时剪辑补一点方向模糊和"呼"的风声。
- **竖屏**：左右甩幅度小，可以试上下甩（结尾上甩到天空 → 下一镜从天空下甩到新场景）〔待验证〕。
- **注意**：和镜头动作词典里的"甩镜头"不同，那个是同一场里甩到另一个人；这个是甩到另一个地方。一集别连着用两次以上，会晕。

### 5. 遮挡转场

- **大白话**：有个东西（路人、柱子、门、衣摆、书本、车）从镜头前经过，把画面整个挡住；挡住的那一下切，东西移开时已经是新场景。
- **适合**：换装、换场，还能做出"一镜到底"的感觉。
- **分镜怎么写**：上一镜结尾写"××从画面右侧横穿镜头前，完全挡住画面"；下一镜开头写"××从画面左侧移开，露出……"。遮挡物移动方向、速度、颜色前后接近，最好是同一种东西（上一镜深色柱子 → 下一镜深色柱子）。
- **切点**：画面完全被挡住时切，别露出换场那一瞬间。
- **竖屏**：竖着的东西最好挡（门框、柱子、路过的人身），横着挡要很大的东西才能盖满。
- **横屏**：路人、车横穿画面最好用。
- **遮挡物要合理**：场景里本来就该有（街上有路人、走廊有柱子），不凭空出现（规则 5.13 物理上做得到）。
- **v2：遮挡物要会动，镜头不动**。路人走过、门关上可以；镜头钻过树篱、穿墙不行（320磅 第 6 集段 6 全黑一秒，人被树篱吞掉）。穿过去的换场用"走向开口 → 硬切 → 已经站在另一边"。

## 怎么挑

| 换场的情况 | 先试 |
|---|---|
| 同一个人换衣服、换地方 | 动作承接、遮挡 |
| 时间流逝（白天到夜里、季节变了） | 相似衔接（同一构图换时间） |
| 引出新人物、新地方、悬念 | 视线引导 |
| 快节奏、平行剪辑、打斗换场 | 甩镜 |
| 想要"一镜到底"的流畅感 | 遮挡 |
| 情绪要断一下、要停顿 | 不用技巧：戏型拍法"转场呼吸"（空镜、关门） |

- 一集里换场的地方才用；同一场戏里的切照规则 5.3，不要每刀都花式。
- 同一种转场一集里别连着用（遮挡 → 遮挡 → 遮挡观众会发现套路）。
- 钩子结尾的硬切（规则见戏型拍法"钩子悬念"）是故意断开，不用转场。

## 交给下游（提示词技能）

- 分镜只设计"上一镜怎么结束、下一镜怎么开始"，写在两镜的"画面"和"角度 / 运镜"里；**切点在哪一帧、补模糊和音效，是剪辑的事**，在"接法"里写一句提醒即可。
- AI 每个镜头分开生成时，模型不知道下一镜：上一镜结尾的遮挡、甩镜、动作做到一半，下一镜开头的接法，都要各自写进各自的提示词。两镜如果在同一个生成段里，也要写清这一刀在哪。
