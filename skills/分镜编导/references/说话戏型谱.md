## 零、六个维度：一场戏要什么

### 0.1 每个说话的人答六个问题

| 维度 | 问自己 | 可能的答案 |
|---|---|---|
| ① 目的 | 他说这些话要干什么 | 赢 / 发泄 / 说服 / 教会 / 交出自己 / 压住对方 / 套话…… |
| ② 掌控 | 他控制得住自己吗 | 控 ↔ 失（一场戏里可以变） |
| ③ 准备 | 这些话想过没有 | 备（想好的）↔ 临（临场的） |
| ④ 方向 | 有来有回吗 | 单（一个人说）↔ 双（你来我往）；单→等（说完等回应）；无（没有听的人） |
| ⑤ 曲线 | 情绪怎么走 | 爬 / 炸泄 / 平 / 铺 / 憋破 / 沉 / 松 / 翻（见 0.3） |
| ⑥ 关系 | 对谁说、离多远 | 抗 / 亲 / 上对下 / 下对上 / 众 / 无 |

**强度四档**（分镜定档，译镜翻成提示词里的固定短语）：**收**（只漏一点）/ **显**（看得清）/ **过**（一场戏的情绪高点，稍微演过头）/ **破**（崩溃、爆发，一段最多一次）。默认按型定，**不再默认收**：E 组那种"适中、别演过头"演出来等于没有。

### 0.2 维度 → 台词怎么说

| 答案 | 说话的样子 |
|---|---|
| 失控 | 断、卡、重复、一口气连说 |
| 掌控 | 流畅、短句、停在意思完整处；不卡 |
| 准备好的 | 有结构：排比、三连、先让一步再反驳、自问自答 |
| 临场的 | 碎、改口、说一半重来 |
| 双向 | 回合短、抢话、拿对方的原话反打。一镜只有一张嘴在动，**抢话靠切**：上一句截断，下一镜另一个人接上 |
| 单向 | 话长，按意思拆成几镜，中间插听的人 |
| 对抗 | 反问（尾音落下）、命令 |
| 亲近 | 问句是真在问（尾音上扬），称呼多 |
| 对一群人 | 视线扫过人群，不盯一个人（不看镜头） |

### 0.3 曲线：台词和情绪怎么走

| 曲线 | 什么戏 | 台词 | 强度走向和情绪 |
|---|---|---|---|
| 爬（往上爬） | 吵架、审讯、激将 | 一轮比一轮短、一轮比一轮狠 | 双向时两人轮流加一档，**不同时到顶**；最狠那句之后对方静 1 秒 |
| 炸泄（炸开再泄） | 愤怒宣泄、崩溃 | 顶点连说，之后碎、拖 | 显 → 破 → 收：憋着 → 炸 → 空；炸时近，泄时退开、坐下 |
| 平 | 教学、汇报、谈判、威胁 | 稳；情绪藏在一个停顿里 | 收 → 显；教学的戏眼在学的人（迷糊 → 试 → 懂了） |
| 铺（一路铺到高潮） | 演讲、说服、誓言 | 句首重复（排比），停顿越来越长 | 显 → 过：稳 → 热 → 顶；人群反应一层层起来 |
| 憋破（压着压着破了） | 告白、道歉、挽留、讲往事 | 开头卡，关键句前长停，关键词重复 | 收 → 显 → 说完悬着；听的人的反应是收尾，要给时间 |
| 沉（往下沉） | 报坏消息、告别、托付、悼词 | 越来越短、越来越慢；关键句短；说完停 | 收 → 显，往下塌；说完后的沉默要给时间 |
| 松（先紧后松） | 安慰、哄、和解 | 开头短、停顿多；松口以后句子变长、变软 | 被安慰的人从破或过回到收；说的人一直稳 |
| 翻（一下翻） | 反应类、打脸、对质亮证据、决裂 | 翻点前后长短、语气完全不同 | 翻点那一拍变档（收 → 破，或者破 → 冷）；翻点后多停 1 秒 |

### 0.4 每句台词标两件事：功能和意图

分镜表第 5 节的"句子功能 / 意图"一栏，每句台词写一条，译镜照它定句尾标点和尾音：

- **功能**：是非问 / 特殊问（有疑问词）/ **省略问**（没有疑问词：And the rest?）/ **陈述语序问**（You knew?）/ 附加问（…, didn't you?）/ 反问 / 陈述 / 命令 / 感叹 / 没说完 / 被打断。
- **意图**：一句话说这句想干什么，比如"逼他认""不敢信""求他别走""不是真在问"。
- 加粗那两种最容易被模型说成陈述（第 29 集段 5 实测），一定要写清楚。
- （2026-11-21）后面再加一项**说法**，写成 `功能｜意图｜说法`，见 0.5。

### 0.5 说法：这一句怎么说出口（环5 规则 5.25）

一个人说话卡不卡，不看这场戏是什么戏，看**这一句他的嘴跟不跟得上心里的东西**。所以六个维度里的"掌控"是这场戏的底色，说法要一句一句定。

**定说法问三件事：**

1. **这一句他控得住吗？** 控得住就是"顺"。准备好的谎、威胁、客套、开心地说，越顺越有戏，这时候写卡反而像心虚。
2. **控不住的是什么？** 怕、急、气、伤，查下表。
3. **破在哪个词上？** 放在最难出口、最疼的那个词上。一句话只破一两处，平均撒开就成了口吃的人。

| 说法 | 心里是什么 | 观众听到 | 英文写法 | 中文写法 |
|---|---|---|---|---|
| **顺** | 控得住：掌控、准备好的、客套、威胁 | 流畅，停在意思完整处 | 原样 | 原样 |
| **卡** | 紧张、害怕、急着解释、不敢问 | 一个词说两遍 | `He's— he's my fiancé!` | `我——我没有` |
| **断** | 震惊、说不下去、话到嘴边又咽回去 | 话停在半截，缓一下再接 | `Your fiancé— isn't who you think he is.` | `你的未婚夫——根本不是你以为的那个人。` |
| **一字一顿** | 压着的怒火、最后通牒 | 一个词一个词砸下来 | `Get. Out. Now.` | `滚。出。去。` |
| **拖** | 伤心、舍不得、犹豫、卖关子 | 中间留空，尾巴拖长 | `The company… You're retiring…` | `宝贝……今晚不行……` |
| **一口气** | 爆发、吵架、抢着说 | 中间不换气，一路冲到底 | 句号改逗号：`Your Majesty, I was deceived by Matilda—` | `你给我滚，现在就滚！` |

**曲线给默认，再按句调：**

| 曲线 | 说法通常怎么走 |
|---|---|
| 爬 | 顺 → 一口气；最狠那句可以一字一顿 |
| 炸泄 | 一口气 → 断、拖 |
| 平 | 顺；情绪藏在一个停顿里 |
| 铺 | 顺，停顿越来越长 |
| 憋破 | 卡 → 关键词前断 |
| 沉 | 拖，越来越短 |
| 松 | 断 → 顺 |
| 翻 | 翻点前顺，翻点后一字一顿或一口气 |

**几条边界：**

- 只改标点、把已有的词紧挨着重复。不加 uh、um，不改词和词序。"台词"列留剧本原文，带标点的这一版写在说法里，译镜照抄。
- 一句最多两处。同一个人一场戏里，卡和断不超过一半的句子。
- 每处卡顿或停顿多算 0.3–0.5 秒（5.19）。装不下先匀秒，再不行换成不占时间的说法（一口气、顺）。
- 强调用的重复（教学、演讲）是稳的，说法写"顺"，不算卡。
- 状态：卡 ✅（第 29 集段 5 的 `you— you`）；其他五种 ⚪，登记在 `测试登记.md` 的 5.25。

## 一、怎么分类

**一级按"说话的目的"分，共十一类**：一个人开口，总是想对对方或对局面做点什么。目的定了，掌控、准备、方向、曲线大多跟着定了。

**二级是修饰，叠在任何一型上**：潜台词、有没有旁人、身体状态、距离和通道、人数、喜剧、时间压力、人物身份。修饰不改目的，只改"怎么说出来"。

所以任何一场戏都是 **型 × 修饰**。例如"哭着打电话求他别走" = 挽留（影响类）+ 哭（身体）+ 电话（通道）。

**一个人一个型。** 同一场戏里两个人可以是不同的型：她在告白（交心类），他在拒绝（分离类）。

**一场戏里型会变。** 比如吵架 → 一方崩溃（宣泄）→ 和解（抚慰类）。按节拍分开，每段一个型；变型的那一拍往往就是情绪最高点或转折点，分镜在那里切镜或换景别。

### 六维度的简写

每一型的"六维度"栏按这个顺序写：**目的｜掌控｜准备｜方向｜曲线｜关系**。

| 维度 | 简写 |
|---|---|
| 掌控 | 控 = 控制得住；失 = 失控；控→失 = 越来越失控；半 = 一半一半 |
| 准备 | 备 = 想好的；临 = 临场的；备→临 = 准备过，临场乱了 |
| 方向 | 单 = 一个人说；双 = 你来我往；单→等 = 说完等回应；无 = 没有听的人 |
| 曲线 | 爬 = 往上爬；炸泄 = 爬到顶炸开再泄掉；平 = 平稳；铺 = 一路铺到高潮；憋破 = 压着压着破了；**沉 = 往下沉**；**松 = 先紧后松**；**翻 = 一下翻过来** |
| 关系 | 抗 = 对抗；亲 = 亲近；上对下；下对上；众 = 对一群人；无 = 没有对象 |

（八种曲线的台词和强度走向见 0.3。）

## 二、十一类五十多型

### 1. 对抗类：想压过对方

**共同点**：多半是双向，关系是对抗。台词短，多用反问（尾音落下），拿对方的原话反打。情绪按回合往上走，两人不同时到顶；输的一方显出来，赢的一方收着。镜头配方对应分镜编导的"冲突对峙戏"。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 吵架 | 亲近的人吵起来 | 赢、伤对方｜控→失｜临｜双｜爬｜亲而抗 | 回合一轮比一轮短；翻旧账（You always…）；截断抢话 | 两人轮流升档；最狠那句之后对方静 1 秒；越吵越近 |
| 对质、摊牌 | 拿出证据揭穿对方 | 逼对方认｜揭的人控，被揭的人失｜揭的人备，被揭的人临｜双｜爬→翻｜抗 | 揭的人一句一句摆证据（句号），用附加问逼认（尾音落下）；被揭的人否认 → 卡 → 没话 | 揭的人收；被揭的人收 → 显 → 破；证据亮出来那一下是翻点 |
| 威胁、恐吓 | 压住对方，让他怕 | 压住｜控｜备｜单｜平（越平越吓人）｜上对下 | 慢，短句，句号，条件句（If you…, I will…）；停在最狠的词前面；不卡、不喊 | 说的人几乎不动；被威胁的人显（呼吸、吞咽）；说的人往前压、压低身位 |
| 羞辱、嘲讽 | 当众贬低对方 | 伤对方、显高位｜控｜临｜单｜平或爬｜上对下 | 反话（叠潜台词修饰）、反问、拖长音、轻笑一声 | 说的人收着、在享受；被羞辱的人 1 → 2，再压回 1（现有规则）；旁观者反应 |
| 审讯、逼供 | 逼对方说真话 | 套出真话｜审的控，被审的控→失｜审的备，被审的临｜双｜爬｜上对下 | 审的人问得密，是非问（逼认，尾音落下）和特殊疑问交替，同一个问题反复问；也可以突然放软。被审的人短答、否认、重复对方的话拖时间，最后崩 | 审的收；被审的从收到破 |
| 谈判、讨价还价 | 两边都要好处 | 拿好处｜控｜备｜双、轮流｜平带尖峰｜抗但互相需要 | 让步加条件（I can do X, if…）；数字；用沉默当武器（停顿要算时间） | 两边都收；破绽在小信号上（谁先眨眼、谁先喝水） |
| 辩论 | 有规则的对抗 | 赢｜控｜备｜双、轮流不抢｜平带尖峰｜抗 | 引对方原话 → 反问（落）→ 排比；流畅不卡 | 收 → 显；赢的收、输的显 |
| 打脸、反击 | 忍了很久，一句翻盘 | 翻盘｜控｜备｜单（一锤定音）｜翻｜抗 | 前面短、收；翻的那句短而重，句号，可以照搬对方之前的原话 | 赢的收，输的显（现有爽点规则）；镜头对应"爽点高光戏" |
| 拌嘴、斗嘴 | 不伤人的你来我往 | 占上风｜控｜临｜双｜平（快）｜亲 | 快、短、接得紧，拿对方的词接梗 | 收 → 显，憋着笑；常叠喜剧修饰 |

### 2. 发泄类：想把情绪倒出来

**共同点**：失控、临场、单向，听的人是承受的那一方。曲线是"炸泄"或"破"。台词连着说、重复、自己打断自己；要时间，长的要拆成几镜。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 愤怒宣泄 | 憋了很久终于爆发 | 发泄｜失｜临｜单｜炸泄｜亲 | 顶点用逗号连到底、不换气；在最痛的词前自己打断；泄掉后短句、重复、往下落 | 显 → 破 → 收；憋着 → 炸 → 空 |
| 崩溃大哭 | 哭着说话 | 发泄悲伤｜失｜临｜单｜憋破→炸→空｜亲 | 关键词破音，句子被抽泣切碎（省略号），一句话反复说（I tried. I tried.） | 收（忍着）→ 破 → 空；叠"哭"修饰 |
| 抱怨、诉苦 | 吐苦水 | 求理解｜半｜临｜单｜平→爬｜亲 | 一件接一件（and… and…）；用附加问求认同（you know? 尾音上扬）；叹气 | 显；听的人点头或安慰 |
| 醉话、酒后真言 | 喝醉了说出真心话 | 发泄｜失｜临｜单｜忽高忽低→翻｜亲 | 拖音、重复、话题乱跳、说一半笑 | 显 → 过；身体晃；真话出来那一下突然清醒 |
| 嘟囔、自己生气 | 没人听，自己发火 | 发泄｜失｜临｜无｜爬｜无 | 碎、低、重复 | 叠"不对人说"那一类的写法 |

### 3. 影响类：想改变对方的想法或行动

**共同点**：目的明确，说的人多半掌控（求饶除外）。台词有结构：理由加请求。说的人看对方的反应调整（对方松动就加码）；**听的人的变化是戏眼**。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 说服、劝说 | 一对一讲道理 | 改变想法｜控｜备｜双｜铺｜亲或平 | 先认同再转（I know. But…）；讲理由；最后一句是请求或真在问（尾音上扬） | 显；听的人从抗拒到松动 |
| 求情、求饶 | 求对方放过 | 被放过｜失｜临｜单→等｜憋破（越求越低）｜下对上 | 重复 please、叫名字、省略号；句子越来越短 | 显 → 过；身体往下（跪、低头），往前抓 |
| 哄骗、忽悠、推销 | 让对方信 | 让对方信｜控（表面热情）｜备｜双｜铺｜装亲 | 流畅、快、热情；附加问求同意（right? 上扬）；不给对方插话 | 表面显，真意收；叠潜台词修饰，写藏不住的那一下（眼神一冷） |
| 演讲、煽动、战前动员 | 对一群人 | 鼓动｜控｜备｜单｜铺｜众 | 排比、对句，句号切短；每组后停；最后一句前长停，声音抬起来 | 显 → 过；视线扫过人群（不看镜头）；人群反应一层层起来 |
| 命令、训话 | 让对方照做 | 照做｜控｜备｜单｜平或爬｜上对下 | 祈使句、短、句号、不解释；重复命令加重；训话就一条条数错，加反问（落） | 说的人收（不动就是力量）；被训的人显 |
| 挽留 | 求对方别走 | 别走｜半→失｜临｜单→等｜憋破｜亲 | 叫名字、wait、半句话；真在问（尾音上扬） | 显 → 过；往前追一步、伸手 |
| 激将、挑衅 | 逼对方动起来 | 让对方动｜控｜备｜单｜爬｜抗 | 反话、贬低、反问（落）；停在刺上 | 说的人收着、带笑；被激的人收 → 显 |
| 撒娇、讨要 | 软着要东西 | 要到｜控（装的）｜临｜双｜平｜亲 | 拖长音、叫称呼、尾音上扬 | 显；靠近、拉袖子 |

### 4. 传递类：想让对方知道、听懂

**共同点**：说的人多半掌控、有准备。信息优先，情绪为信息服务。**戏眼常常在听的人的反应上**。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 教学、示范 | 手把手教 | 教会｜控｜备｜单（夹着问懂没懂）｜平｜上对下但亲 | 短指令；纠正用破折号（No— lower. 是打断动作，不是口吃）；用是非问查懂没懂（上扬）；重复是强调，语气写 with weight, not a stammer | 说的人收 → 显；戏眼在学的人：迷糊 → 试 → 懂了 |
| 汇报、通报 | 交代事实 | 交代｜控｜备｜单｜平｜上下 | 陈述句、数字、句号，快而清楚 | 收；情绪藏在一个停顿里（坏消息前停一下） |
| 宣布、宣判 | 定下结果 | 定结果｜控｜备｜单｜平→落锤｜上对下或众 | 慢、句号、关键词前停；最后一句短、落锤 | 收；听的人和群众的反应才是戏（审判群戏、爽点） |
| 报坏消息、报丧 | 心疼对方又不得不说 | 让对方知道｜控→半｜备（想过怎么说）｜单→等｜沉｜亲 | 绕、开头卡（I… there's something…）；关键句短；说完停住 | 说的人收 → 显（说出口那一下自己也痛）；听的人接反应类 |
| 报喜 | 分享好消息 | 分享｜失（兴奋）｜临｜单→等｜爬｜亲 | 快、抢着说、重复（We did it. We did it!）、感叹号 | 过；听的人从不信到跳起来 |
| 讲往事、讲故事 | 让对方懂过去 | 被理解｜半｜备（记了很久）｜单｜铺→憋破｜亲 | 句子长、有画面；讲到痛处停、卡；声音变（像回到当时） | 收 → 显；视线离开对方、看远处（不看镜头）；要拆镜，插听的人 |
| 解释、辩白 | 急着让对方理解自己 | 被理解｜半｜临｜双｜爬（越解释越急）｜亲或抗 | No, listen—、That's not—；改口；越说越快 | 收 → 显；常被打断 |
| 念信、念遗书、读文件 | 传达别人的话 | 传达｜控｜备（文字）｜单｜铺→憋破 | 书面语、节奏稳；念到某一句念不下去（省略号、停） | 念的人收 → 破；也可以叠 OS（写信人的声音） |

### 5. 交心类：想把自己交出去

**共同点**：怕（失控）、准备过但临场乱。曲线是"压着压着破了"；说完悬着等回应；**听的人的反应是收尾，要给时间**。镜头配方对应"情感戏"。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 告白 | 说出喜欢 | 交出心｜失｜备→临｜单→等｜憋破｜亲 | 第一句流畅（准备好的）→ 关键句前卡（I… I'm）→ 说完慌了 | 收 → 显 → 悬着；说前视线先掉下去再抬起来 |
| 坦白、认罪 | 卸下秘密 | 卸下｜控→失｜备（憋了很久）｜单→等｜憋破→沉（说完反而平静） | 开头绕；关键句前长停；关键句短而平；说完沉默 | 收 → 显 → 空（解脱） |
| 道歉 | 修补关系 | 修补｜半｜备或临｜单→等｜憋破｜亲 | 对不起不能说得太顺（太顺像敷衍）；说清错在哪；不辩解（一辩解就成了"解释"） | 收 → 显；视线掉下去再抬起来 |
| 求婚 | 交出未来 | 交出｜失（紧张）｜备（排练过）｜单→等｜铺→憋破→等｜亲 | 准备好的那段流畅 → 关键的问句卡住、尾音上扬（Will you…?） | 显；跪下 |
| 托付、临终遗言 | 交代后事 | 交代｜勉强控｜备｜单｜沉｜亲 | 短句、句中换气、重复叮嘱 | 说的人收（没力气）；听的人过或破；叠"虚弱"修饰 |
| 感谢 | 说出感激 | 感激｜半｜临｜单｜憋破（说着说着动情）｜亲 | 开头客气、流畅，说到具体的事卡住 | 收 → 显 |
| 倾诉心事 | 把憋着的说出来 | 被理解｜半｜临｜单｜平→憋破｜亲 | 句子说不完整、I don't know…、自问自答 | 收 → 显；视线游离 |

### 6. 抚慰类：想让对方好受

**共同点**：说的人为了对方稳住自己（掌控），关系亲近，曲线是"先紧后松"。台词慢、短，重复安抚的词；**情绪的变化在被安慰的人身上**。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 安慰 | 陪对方难过 | 让对方好受｜控｜临｜单｜松｜亲 | 慢、短、重复（It's okay. It's okay.）、叫名字，句尾往下落（稳） | 说的人收（稳），自己心疼漏出一点；靠近、碰一下 |
| 哄 | 哄孩子、哄恋人 | 让对方不哭、开心｜控｜临｜单｜松｜亲或上对下 | 声音软；尾音上扬（Yeah?）；逗、拖音 | 显（为对方演出来的） |
| 稳住惊恐的人 | 危急时让人冷静 | 让对方冷静｜控（硬撑）｜临｜单｜平｜亲或陌生 | 命令和安抚交替（Look at me. Breathe. You're okay.）；短句、重复 | 说的人收，但自己也怕、漏一点；被稳住的人破 → 收 |
| 鼓励、打气 | 给对方勇气 | 给勇气｜控｜临｜单｜铺｜亲 | 短的肯定句，重复关键词 | 显 |
| 和解 | 两边重新靠近 | 修补（双方）｜半｜临｜双｜松｜亲 | 开头试探（短、停顿多）；一方先松口；之后句子变长，笑出来 | 收 → 显；距离从远到近 |

### 7. 试探类：想从对方那里拿到东西，又不暴露自己

**共同点**：嘴上说的和心里想的不一样（叠潜台词修饰）。说的人掌控，双向，节奏是攻和防。表演靠"藏不住的那一下"（原理：模型只演看得见的）。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 套话、试探 🟡 | 想知道对方知道多少 | 拿信息｜控｜备｜双｜平（暗流）｜装亲 | 随口的问句（装不在意）→ 突然一个具体的问题 → 停下来看反应 | 收，眼睛盯着对方的反应；被套的人迟疑一下 |
| 撒谎、掩饰 🟡 | 不让对方知道 | 瞒住｜控（很费劲）｜备或临｜双｜平（表面）｜任何 | 太顺或细节太多；重复对方的问题拖时间；反问转移话题 | 表面收；写藏不住的那一下。第 29 集段 5 的文森特就是这一型 |
| 调情、暧昧 | 试探心意 | 试心意｜控（装不在意）｜临｜双｜慢慢收紧｜亲 | 慢、轻、半句话；尾音上扬；停顿长（要算时间） | 收 → 显；距离一点点近；镜头对应"暧昧戏" |
| 话里有话、客套交锋 | 社交场合暗中较劲 | 较量｜控｜备｜双｜平｜装亲 | 客套话加停顿 | 笑着收，眼睛不笑 |
| 装傻、打哈哈 | 躲开问题 | 躲开｜控｜临｜双｜平｜任何 | 反问、笑着岔开、拖音（Me?） | 显（装出来的） |

### 8. 分离类：关系在结束

**共同点**：曲线是"往下沉"。关键的话很短；**说完之后的沉默比台词重**。两个人往往不同步：一个收着，一个破了。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 告别、离别 | 不得不分开 | 好好分开｜半｜备（想好要说什么）｜双→单｜沉｜亲 | 说的比想说的少，绕开最关键的那句，最后一句短 | 收（忍着）→ 显（转身以后） |
| 分手、拒绝 | 一方要结束 | 结束｜说的控，被分的失｜备或临｜双｜沉对破｜亲→抗 | 说的人用陈述句、句号，不给希望（语气写 not asking）；被分的人问 Why?（上扬，在求）、重复 | 一个收、一个破 |
| 断绝、决裂 | 永远不再往来 | 了断｜控（硬）｜备｜单｜翻→冷｜抗 | 慢、句号，最后一句像宣判 | 收（冷） |
| 临终、送别将死的人 | 最后几句话 | 道别｜勉强控｜临｜双｜沉｜亲 | 将死的人见"托付"；守着的人叠挽留和安慰 | 守着的人过 → 破 |

### 9. 仪式类：场合规定了怎么说

**共同点**：有准备、掌控，有固定的格式（怎么开头、怎么结尾）。**情绪出在格式裂开的地方**，比如念到一半哽住。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 致辞、祝酒 | 公开场合讲话 | 公开表态｜控｜备｜单｜平→铺｜众 | 套话开头、点名、举杯收尾 | 显（社交的笑）；常叠潜台词 |
| 誓言、宣誓、婚礼誓词 | 许诺 | 许诺｜想控｜备｜单（对一个人，有众人在场）｜铺→憋破 | 排比，句首重复（I promise…） | 显，哽住一次 |
| 悼词 | 纪念死去的人 | 纪念｜勉强控｜备｜单｜沉→憋破｜众 | 讲一件往事，加停顿 | 收 → 破一次 |
| 祈祷、对神说话 | 求 | 求｜半｜临或备｜无｜平→憋破｜无 | 低、慢，重复一句 | 叠"不对人说"那一类的写法 |
| 法庭陈述、庭审问答 | 说服法官、陪审团 | 说服｜控｜备｜单或双｜平｜众 | 同辩论和审讯 | 群戏 |
| 面试、采访 | 表现自己 | 表现｜控（很努力）｜备｜双（一问一答）｜平｜上对下 | 问的人用中性的问句；答的人流畅（准备过），有一处卡住 | 收 |

### 10. 反应类：接住一个突然来的消息

**共同点**：话很少，戏在反应的过程（曲线是"翻"）。台词就是一个词、半句话、重复对方的话。镜头配方对应"揭示戏"。

| 型 | 什么戏 | 六维度 | 台词 | 表演 |
|---|---|---|---|---|
| 震惊、听到噩耗 | 消化不了 | 消化｜失｜临｜单（像自言自语）｜翻→沉｜— | What? / No. / 重复对方的话（Dead?） | 两种走法：收 → 破，或收 → 空；情绪顺序：不信 → 显白了 → 塌下去 |
| 认出、相认 | 认出一个人 | 确认｜失｜临｜双｜翻→憋破｜亲 | 叫名字（上扬，不敢信）、半句话 | 收 → 过 |
| 惊喜 | 突然的好事 | 高兴｜失｜临｜单｜翻→爬｜亲 | 短、感叹、笑着说 | 过 |
| 恍然大悟 | 突然想通了 | 想通｜控｜临｜单｜翻｜— | 短句，That's why…，说着慢下来 | 收 → 显（变化在眼睛） |

### 11. 不对人说：现场没有听的人

**共同点**：没有对象，**视线没有落点，又不能看镜头**（译镜禁止看镜头）。所以视线要落在一样东西上：远处、照片、墓碑、手里的物件。内心独白嘴不动（现有规则 T8）。

| 型 | 什么戏 | 台词 | 表演 |
|---|---|---|---|
| 内心独白（OS） | 心里的话 | 照现有 T8：`<谁>'s inner voice, voice-over, her lips stay closed` | 嘴闭着，眼睛和呼吸在动 |
| 自言自语 | 一个人嘀咕 | 碎、低、自问自答 | 视线落在手上的事或物件上 |
| 对着不在场的人说 | 对墓碑、遗像、照片、空椅子 | 套交心类；停下来等一个不会来的回答（留白要算时间） | 显；视线落在那样东西上 |
| 对着设备说 | 电话留言、录音、视频日记 | 停顿（对方不会回答） | 视线落在设备上，不看镜头 |
| 旁白、画外讲述 | 画外有人讲故事 | 套传递类的讲往事；叠 OS | 画面里的人不说话 |

### 12. 少说话、不说话的戏

情绪规则照用，只是没有台词框：情绪顺序的格子挂在视线和动作的变化上，不挂在句子上。

| 型 | 什么戏 | 表演 |
|---|---|---|
| 沉默对峙、对视 | 谁也不说话 | 收 → 显；小信号，谁先移开眼睛 |
| 等待、心事、独处 | 一个人 | 镜头对应"独处心理戏" |
| 无声的哭、笑 | 不出声 | 显；声音只写呼吸 |
| 尴尬的沉默 | 冷场 | 停顿拉长（要算时间）；正剧和喜剧都有 |

## 三、修饰：叠在任何一型上

| 修饰 | 台词怎么改 | 表演怎么改 | 模型这边要注意 |
|---|---|---|---|
| **潜台词**（嘴上和心里不一样：撒谎、客套、反话、强装没事、讽刺） | 标点和尾音按**字面**的功能写 | 情绪顺序写真意"漏出来的那一下" | 藏起来的情绪模型演不出来（译镜 手册 7 读法 2） |
| **有旁人 / 私下** | 有旁人时说得更收、更短 | 有旁人降一档，加旁观者的反应镜；私下可以放开 | — |
| **哭着说** | 关键词破音，抽泣把句子切碎（省略号） | 先忍，再破 | 别写 tears streaming（坑词 T12），写 the rims of her eyes go wet |
| **虚弱、病中、临终** | 短句，句中换气，声音小 | 收（没力气）；情绪在眼睛 | 语速慢，要时间 |
| **受伤、喘、跑着说** | 句子被呼吸切碎：逗号、省略号，写 between breaths | 显 | 要时间 |
| **醉** | 拖音、重复、音量忽大忽小、说不完整 | 显 → 过；身体晃 | — |
| **冷、发抖** | 字断开、牙齿打颤 | 显 | 别写 shaking all over（坑词），写手不稳 |
| **惊吓** | 尖叫只出不带词的声音 | 破 | 剧本没写尖叫就不写（现有 T14） |
| **笑着说** | 笑声不能盖过台词 | 显 | 写 a breath of a laugh（坑词 T12） |
| **悄悄话、怕被听见** | 气声，音量小，但情绪可以很强 | 靠近、贴着耳朵 | 音量和情绪是两个通道，不打架（译镜 手册 7 读法 3） |
| **远距离喊话**（远、吵、险情） | 短，重复关键词，拉长元音 | 显 → 过 | 险情照现有 T14：喊在两次危险之间 |
| **电话、对讲机、隔着门** | 停顿等对方回答；要不要出对方的声音要写明（voice from the phone） | 一个人一张嘴 | 对方的声音算画外音，要写清楚是谁、用什么语言 |
| **一对多**（演讲、训话） | 见演讲 | 视线扫人群 | 人群只出不带词的声音 |
| **多对多**（群戏：会议、饭桌、审判） | 轮流说，插话靠切 | 旁观者的反应镜 | 一镜一张嘴；齐声说话做不了 |
| **喜剧** | 包袱前停一拍；一本正经说荒唐话；接梗快；尴尬就把沉默拉长 | 抖完包袱不笑；喜剧的"过"可以更过 | 模型可能自己笑场 |
| **时间压力**（倒计时、追逐中说话） | 快、短、省主语、不解释 | 显；眼睛不离开威胁 | — |
| **人物身份**（孩子、老人） | 孩子：短句、重复、问题多、尾音上扬；老人：慢、停顿多 | — | 外国口音、夹杂外语这次不管 |

## 四、遇到这份谱里没有的戏，怎么归类

1. **问目的**：这个人开口是想干什么？落进十一类里的哪一类。实在找不到，说明是新的一类：照六个维度自己回答，并把它补进这份谱。
2. **在类里找最近的一型**。找不到就用这一类的共同点，加上六个维度。
3. **叠修饰**：可以叠好几个（哭 + 电话 + 有旁人）。
4. **六个维度以这场戏为准**：谱里给的只是默认答案，剧本说了算。比如同样是告白，冷静的人告白，掌控就填"控"。
5. **看型会不会变**：一场戏里型变了，就按节拍分开，变型那一拍交给分镜去切。

例子：第 29 集段 5，文森特在**撒谎、掩饰**（试探类）、叠潜台词；奥利维亚是**对质**（对抗类），但关系亲近、她怕听到答案，所以掌控填"半"，表演从收到显。这样归类，和那一段测出来有效的写法对得上（测试在 E:Desktop第29集对照测试_段5_台词与中文逐拍）。

## 五、和"戏型拍法"（镜头配方）怎么对

| 这份谱的类 | 对应的镜头配方 | 现在还缺的 |
|---|---|---|
| 对抗类 | 冲突对峙戏（审讯、宣判用审判群戏，打脸用爽点高光戏） | 谈判、辩论的镜头 |
| 发泄类 | 冲突对峙戏（愤怒）、情感戏（大哭） | 宣泄的拆镜（憋、炸、泄） |

"缺的"那几项，进分镜编导时要补镜头配方，或者明确写"套哪个配方"。

### 曲线 → 切镜（v5，2026-11-21，环4 规则 4.13）

0.3 节的曲线管台词和情绪怎么走，这张表管镜头切多快、切给谁。都是默认，剧本和戏型说了算；这场戏靠沉默和静止更有力，就不切。

| 曲线 | 切多快（竖屏快；横屏每镜长一倍左右） | 切给谁 | 注意 |
|---|---|---|---|
| 爬（越说越凶） | 越往后越快：开头 3 秒一切，到顶 2 秒上下一切 | 一刀换一张嘴（5.17） | 双向的爬，两个人轮流升档，景别一起收紧（5.6） |
| 炸泄（一下爆开、倒出来） | 炸之前快，炸的那一段不切，一镜压住 | 炸完才切给听的人 | 炸的那段别被反应镜打断 |
| 平（一直一个劲） | 正常正反打，3 秒上下 | 说的人和听的人交替 | 靠景别呼吸避免单调（4.2） |
| 铺（讲事、交代） | 一句一镜，中间插画面（讲到的东西、听的人） | 讲到什么切什么 | 别全是说话的脸 |
| 憋破（一直压着，最后崩） | 憋的时候少切、一镜压住，破的那一刀切到最紧 | 破之前可以给一次听的人 | 破在重音上（2.15、2.16） |
| 沉（越说越低、越说越慢） | 越往后越慢，最后一句说完停住 | 说完给沉默 | 说完的沉默算进时长（5.19） |
| 松（缓下来、和解） | 慢，回到双人 | 双人同框 | 让观众看见距离变了（4.3） |
| 翻（局势翻了） | 翻点那一刀切反应 | 被翻的人 | 翻点后停约 1 秒（2.14） |

来源：漫剧老李的对话切镜节奏，是用户批评"站桩对话"以后定的："该吵的戏一刀换一张嘴，宣判、静场不切，节奏服务剧情，别为切而切"。秒数是估的，待验证。
