## 一句话

偏电影：镜头更长、景别更开、有呼吸，用调度和构图讲关系，快慢交替。快的地方（打戏、爆发）照样紧，慢的地方让镜头停得住。

## 构图（横屏）

- **两人可以一左一右**：主角在左，整场不越轴；用三分法（人放在画面三等分的线上）〔废土甜心 镜头语法手册；待验证〕
- **前景层次**：门框、柱子、人群的肩做前景，让画面有纵深〔待验证〕
- **横向运动最清楚**：横移跟拍、人物横穿画面；追逐、冲锋保持银幕方向一致〔废土甜心〕
- **宽景讲环境和孤立**：人小、环境大；空镜、环境镜头做呼吸和转场〔废土甜心〕
- **长镜头调度**：一个镜头里人物走位、镜头跟着，把两个人串在一个画面里，代替来回切（环5 规则 5.14）〔待验证〕
- **风格锁里的宽银幕词**按 `D:\漫剧公司\精品制作\剧设定\` 里这部戏的剧设定〔用户〕
- **慢动作**：生成时一律实速（v13 全片实速）；要慢的地方在设计里标"建议升格"，后期做〔v13〕

## 电影感怎么做（v5，2026-11-21）

下面是导演们的做法（道理见 `references/导演方法.md`），横屏最用得上。全部〔导演方法；待验证〕：电影里成立，AI 生成里还没试过。

- **镜头跟着全片的劲儿变（吕美特）**：前面松，越往后越紧。吕美特拍《十二怒汉》：前面广角、机位略高，越往后镜头越长、机位越近越低，最后几乎全是低于眼睛高度的特写。一集分镜可以先定这条线：哪一场最松、哪一场最紧，第 2 节"画面曲线"写下来（环2 规则 2.16、环4 规则 4.12 横屏那一栏）。
- **让人动，少来回切（斯皮尔伯格）**：一场对话戏，设计一次走位，让关系变了：谁走近、谁退开、谁挡在中间。用一个镜头跟住，代替三四刀正反打。前景放东西、人放在不同深度，一个画面里就有关系。要攒悬念时，故意不切。
- **镜头动要有理由，和人同速（芬奇）**：跟拍时和人物同速同向；没人带着就固定。特写少用，一用就是大事。
- **小也能要紧（希区柯克）**：横屏宽，要紧的东西可以小，但放在构图的焦点上，用光、线条、留白把眼睛引过去。
- **观众先知道（希区柯克）**：前景是危险、后景是不知情的人，一个镜头就是悬念（环2 规则 2.17）。
- **每场戏留得出剪的路（覆盖）**：一个交代全场的大景、两人各自的单人、过肩正反打、插入镜头。横屏镜头长，不等于只拍一个角度（环4 规则 4.14）。

## 和竖屏快节奏比

| | 竖屏快节奏短剧 | 横屏精品剧 |
|---|---|---|
| 一拍 | 2–3 秒 | 3–6 秒 |
| 一镜 | 2–6 秒 | 常规 3–8 秒，长镜头 8–12 秒，爆发 1–2 秒 |
| 同框 | 纵深、上下、过肩，不左右排开 | 可以一左一右，加前景层次 |
| 运动 | 顺着长边（纵深、上下） | 横向最清楚 |
| 峰值之后 | 不干停 | 文戏多停 1–2 秒 |
| 主力景别 | 近景、特写 | 中景、全景 |
| 关系怎么讲 | 镜头动作指出来（推、甩、移焦） | 调度和构图讲出来（站位、前景、留白） |

## 第一次用要验的

- 长镜头调度生成得出来吗：人物走位、镜头跟着，走位会不会丢。
- 慢的段落，观众会不会觉得拖。
- 一左一右站位，模型会不会越轴。
- （v5）走位改变关系的一镜调度，生成出来走位会不会丢；跟拍和人同速做不做得到。
- （v5）整集的"镜头越来越长、越来越低"，观众感觉得到吗。
