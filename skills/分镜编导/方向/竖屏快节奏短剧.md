# 方向：竖屏快节奏短剧（9:16）

状态：**已验证**。《惹火私厨》第 34 集：2026-10-22 分镜，导演"基本没问题"；用户 2026-10-25："本次执行的分镜脚本不错。"

## 一句话

两三秒一拍，每一拍要表达的东西，都用镜头动作引导出来。

用户 2026-10-22 原话："之前的分镜节奏是按照电影感觉来的，我需要的是快节奏短剧。两三秒一个拍，每个拍需要表达的东西都要镜头表现引导出来。"

## 构图（竖屏）

竖屏横向很窄（宽只有高的 0.56），横屏那种"两人一左一右站开"大多装不下。

- **不左右排开**：同框用纵深（近的虚化压住一侧前景，远的在深处另一侧三分线）或过肩〔验证·惹火34；v6 换了说法〕
- **用高低讲权力**：占上风的站着、在台阶上、仰拍；弱的跪着、坐着、俯拍。写姿态和台阶，不写"在画面上方 / 下方"（v6：会分屏，`../译镜/反面案例` 01）
- ~~脸放在画面上方约六成以内，下方留给字幕~~〔❌ v6 作废：提示词照抄"画面上方"会分屏。改成主体落在左侧或右侧三分线；字幕位剪辑时处理〕
- **过肩的前景虚化压住画面一侧**，只占约五分之一（v6：不写下角）
- **要看清的移动顺着画面长边走**：走向镜头、走进深处、上下；横着走一两步就出画〔验证·惹火34 镜29〕
- **竖摇把上下两件事串成一条线**：惹火34 镜40 徽章从皇帝手里 → 凯恩接 → 别到她胸前〔验证·惹火34〕
- **高的东西用画面的高度拍**：台阶、门、楼梯、高处的人〔废土甜心〕
- **两人挨得近（一步以内）才用中景以内的并排双人**，前后错开半步〔验证·惹火34 镜41〕
- （v5）**第一镜不用空镜交代**：给正在发生的冲突、正在反应的脸、或者一句炸裂的台词；环境借人物推门、落座带出来（环1 规则 1.4）〔竖屏短剧行业经验；待验证〕
- （v5）**松紧靠景别和纵深，少靠俯仰**：竖屏上下窄长，大幅仰拍、俯拍容易把人拉扁；强弱先用站坐高低、前后远近讲（3.19）。大仰、大俯留给一集里权力最悬殊的一两下〔第 29 集 3.19 的教训；外部 zenstory 同一结论；待验证〕
- （v6）**镜头有呼吸、焦段有变化**：每镜有起点有落点，一场戏最多一两镜固定；广角给空间、标准镜给关系、长焦给情绪（环5 5.27）〔用户 2026-11-23；验证·E27 v2、E30〕
- （v5）**最紧的留给重音**：竖屏本来就近景多，更要省着用大特写和最极端的角度，留给每场戏的重音（环2 规则 2.15、2.16）〔导演方法；待验证〕

## 和电影节奏比

| | 电影节奏（之前） | 竖屏快节奏短剧 |
|---|---|---|
| 一镜多长 | 3–5 秒 | 2–6 秒，一拍 2–3 秒 |
| 一拍的信息怎么交给观众 | 镜头停得久，让观众自己看 | 每一镜一个镜头动作，直接指给观众看 |
| 长台词 | 一个镜头说完 | 拆进几个镜头：说话的人 → 被说的人 → 旁观的人 |
| 峰值之后 | 多停一会儿 | 不干停，交给下一镜的反应 |
| 剪辑理由 | 每一刀都要有 | 不变：快不等于乱切 |
