# 测试登记：还没验证的写法都在这里

v5（2026-11-21）新建。分镜编导里所有〔待验证〕〔导演方法〕〔外部实测·zenstory〕的规则，在这里各占一行：从哪来、期望看到什么、怎么测、失败是什么样子、现在什么状态。

三种用法：
- **成片出了问题**：先按 `SKILL.md` 的"出问题时找哪一环"找到规则号，再来这里查这条规则验过没有。没验过的，最可能是它。
- **要测一条规则**：照下面的"测试规程"做，测完填最后的"测试记录"，再改这一行的状态和规则后面的标记。
- **要退回一条规则**：v5 的新规则每条单独一段，删掉那一段就退回了，不牵连别的。整个技能的升级前备份在 `D:\漫剧公司\技能备份\分镜编导_大版本升级前_20261121\`。

## 状态标记

| 标记 | 意思 |
|---|---|
| 未测 | 还没在漫影工坊上生成过对照 |
| 测试中 | 已经开始生成，还没看完 |
| 验证·XX | 在 XX 上测过，成立。规则后面的标记同步改成〔验证·XX〕 |
| 部分验证 | 一部分成立（比如竖屏成立、横屏没测），写清哪部分 |
| 不成立 | 测过，没效果或者更糟。规则要改或删，迭代记录写原因 |
| 工具·回归过 | 不靠生成验的：脚本、格式。在旧分镜上跑过，没有误报 |

## 测试规程

照第 29 集段 5 的对照测试和 zenstory 的做法：

1. **挑一场戏**：挑这条规则管得着的戏（测重音挑有一句狠话的戏，测抢话挑吵架戏）。
2. **写两版分镜，只差这一处**：A 版照新规则，B 版照旧做法，别的一字不改。一次只测一条规则；两条一起改，分不清是哪条起的作用。
3. **两版都交给译镜写提示词**：译镜的写法不动。两份提示词除了这一处，别的也要一样。
4. **每版生成几次**：平台按次收费，次数你定。zenstory 每种写法生成 3 次。一次看不出规律，一次好也可能是运气。
5. **打乱顺序看**：请别人把文件名改成编号，你看的时候不知道哪条是 A。这叫"盲看"，防止心里偏向新写法。
6. **记下来**：写了什么 → 出了什么 → 结论，填进最后的"测试记录"。

有些规则不用生成就能先看：机位图、重音标得对不对、强度表合不合用，可以先给导演或你看分镜本身，再决定值不值得花生成次数。
