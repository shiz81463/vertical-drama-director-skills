# 声音：音效和配乐从哪来、怎么做出质感

## 一、先说结论：写实的声音靠录音，不靠合成

以前用代码"合成"音效：拿正弦波、噪声拼出脚步、风、重音。这样做出来的声音一听就假。问题不在合成器好不好，在方法：

- 真实的脚步、衣服摩擦、开门、纸张、水、打击声，是很多种材料一起振动，再在房间里来回反射，频率成分非常乱、非常细。合成器是从几个简单的波形往上搭，再好的合成器也搭不出这么乱的东西，所以听起来"塑料""电子"。
- 合成器擅长的是**设计出来的声音**：呼的一下、上升音、低频轰、悬疑长音、电子提示音、科幻音。电影里这类声音本来就是合成器做的。

所以分工是：

| 要什么声音 | 首选 | 其次 | 不要 |
|---|---|---|---|
| **写实动作声**：脚步、衣服、门、纸、杯子、兵器、拳头、呼吸 | 录音素材库：剪映音效库、Sonniss 免费音效包 | AI 对着画面生成（混元 Foley），声音自动对上动作 | 用代码合成 |
| **环境铺底**：风、雨、室内底噪、人群、虫鸣、河水 | 录音素材库 | AI 按文字生成（Stable Audio Open），要几秒都行、可以循环 | 用代码合成 |
| **强调点**：重音、咚、呼、悬疑音符、上升音、低频轰 | 合成器（Surge XT）现做：`scripts/sound/surge_sfx.py`，随时出、不用找不用下（2026-11-21 用户听过样品定的） | 剪映音效库（`house-style.md` 第 5 节有常用名），脚本里没有的声音再去找 | 用正弦波直接拼 |
| **配乐** | 合成器现写：`scripts/sound/surge_music.py`，按切点定长、全程连贯、有头有尾或无缝循环（2026-11-21 用户听过样品说能用） | 剪映曲库（公司惯例）；AI 生成纯音乐（ACE-Step） | 用代码拼音符 |

**给模型的规矩**：
- 写实的声音不要用代码从波形、噪声合成。
- 要合成就用真正的合成器（Surge XT）做设计类声音和配乐。
- 生成出来、合成出来的每一个声音，都要人听过才能进片。

## 二、质感：声音进片前的处理

同一个音效，处理过和没处理过差很多。"质感好"大半来自这一步，不全来自音源。每个声音进片前过一遍：

1. **剪干净**：头尾空白剪掉；起音对准画面动作那一帧；头尾拉淡变（数值见 `house-style.md` 第 5 节：音效淡出约 1.3 秒）。
2. **放进同一个空间**：同一场戏的声音要像在同一个房间里。大殿要长混响，小屋要短，室外几乎没有。最真实的做法是**卷积混响**：用真实空间录下来的"空间回声样本"（脉冲响应）给声音加混响，一场戏用同一个样本。剪映里有"混响"类音效可以凑合用。
3. **远近**：远处的声音小一点、高频少一点、混响多一点；近处反过来。
4. **频率让位**：对白在中频。音效和音乐在对白出现的地方，把中频让出来（均衡器压一点），对白自然清楚，不用把音量推很大。
5. **电平**：对白最响，音效其次，音乐最低（预告片要求第 4 条，正片同样适用）。
6. **全片响度**：导出后用 `qc_media.mjs` 看响度和真峰值。已测的定稿成片在 −10.6 到 −20.5 LUFS 之间，各集差了近 10 dB，真峰值多数超过 0（会削波）；第 34 集深度精剪是 −19.5 LUFS、真峰值 −2.1 dBFS。TK 交付文档没写响度标准；同一部剧各集至少要对齐到相近的数。真峰值建议不超过 −1 dBFS（这是各平台常见的建议值，不是公司规定；超过 0 就会削波失真）。

### Surge XT + pedalboard：装在哪、怎么用（已测）

- 位置：`D:\漫剧公司\工具\音频\`
  - `SurgeXT\`：Surge XT 1.3.4 插件版，官方 GitHub 下的 `surge-xt-win64-1.3.4-pluginsonly.zip`（46.8 MB，md5 对过，原包在 `下载\`），解压后 110 MB。没装出厂音色包，不影响脚本用。
  - `py311\`：Python 3.11 独立环境，装了 pedalboard 0.9.26 + numpy，86 MB。
- 做音效：`scripts/sound/surge_sfx.py`，一条命令出一套 48 kHz 24 位 WAV，峰值 −1 dBFS，开头对准起音、尾巴剪干净：
  ```
  & "D:\漫剧公司\工具\音频\py311\Scripts\python.exe" -I "<技能目录>\scripts\sound\surge_sfx.py" <输出目录> [hit boom whoosh riser drone]
  ```
  五个配方：`hit` 影视重击、`boom` 悬疑咚、`whoosh` 呼（左甩到右）、`riser` 上升音（3 秒，收住接重击）、`drone` 悬疑长音（9 秒）。
  - **按镜头定长短、音高**（11-21 加，测过长度准到采样）：音效名后面跟 `len=2.4`（秒）或 `len=72f`（帧，默认 30fps，`fps=24` 可改）、`pitch=-3`（半音，-12 到 12，负数更沉）。例：`riser len=72f hit pitch=-3 drone len=20`。上升音的文件结尾就是最高点，结尾对准切点；"呼"脚本会报最响点在第几秒；同一集多次重击换音高，免得像复制粘贴。不写参数就是用户听过认可的那一版。
  - **五种以外的声音，不用改代码**：写一份 JSON 配方跟在命令后面（`surge_sfx.py <输出目录> 我的配方.json`）。配方写 `name`、`len`、`layers`（每层的合成器参数 `set`、音符 `notes`、弯音 `bends`、参数扫动 `sweep`、音量 `gain`、起始 `at`）、`fx`（`highpass`、`lowpass`、`drive`、`reverb`）。范本是 `scripts/sound/example_custom_sfx.json`（系统解锁提示音）。还是只做设计类声音，写实声音不走这里。
- 做配乐：`scripts/sound/surge_music.py`（11-21 加，用户听过样品说能用，配乐首选）：
  ```
  & "D:\漫剧公司\工具\音频\py311\Scripts\python.exe" -I "<技能目录>\scripts\sound\surge_music.py" <输出.wav> mood=悬疑:12,打戏:30,悲伤:45 hits=12,21 stems=1
  ```
  - **连贯靠三样不变**：全程一个调、一个基础速度、一条贯穿的短旋律（各段换乐器奏同一条）。打戏靠十六分音符变快，不换速度。和弦之间选走动最少的摆法。
  - **对切点**：`mood=情绪:到第几秒`，时间可写秒或帧（`360f`）。每段的拍长微调，换情绪的那一拍正好落在切点上；`hits=` 在指定时间砸重音，其他乐器让开一点。
  - **首尾**：`start=soft` 先铺底再进（默认）或 `hit` 第一拍全进；`ending=ring` 落到主和弦自然收（默认）、`stinger` 最后砸一下收住（留悬念）、`loop` 首尾无缝循环。
  - 七种情绪：悬疑、压迫、打戏、爽点、悲伤、温情、甜。其他参数：`key=Dm`、`bpm=76`、`seed=3`（换一条旋律）、`melody=off`（台词密的段落不放旋律，不和对白抢）、`stems=1`（分轨，能在剪映里单独调每种乐器）、`plan=计划.json`（把这些写成文件）。每次另出一份 `_配乐表.txt`，写每段起止、和弦、重音时间。
  - 测过的：长度准到采样；鼓点落在切点上，误差 0–2 毫秒；七种情绪的铺底 13/13 个和弦都在写好的音上；循环接缝的跳变小于普通相邻采样；没有削波和无声洞。这些数字不代表好听，每条新写的配乐还是要人听过才进片。还没放进一集真实成片和对白一起听过。
- 脚本控制 Surge 的六个坑（都写在 `surge_sfx.py` 开头，改脚本前先看）：
  1. 要加载 `.vst3` 包里面 `Contents\x86_64-win\` 下那个文件，指外层文件夹报 "scan failure"。
  2. 没有出厂音色包时，滤波器 1、2 和失真模块默认是"关电源"状态：只改滤波器类型，声音完全不变。脚本开机时改一次存档把它们打开。
  3. 改参数要空跑一小段才生效；一个音中途改参数（滤波器扫频、声像移动）靠小缓冲分段渲染。
  4. 读回默认音色后，再设成和之前一样的值会被跳过，脚本先推一下再设回。
  5. 弯音轮不在存档里，上一个声音弯到顶会把下一个带高，`reset()` 里发"弯音回中"。11-21 用户听的长音因此比原设计高 2 个半音，默认音高已改成听到的那个高度。
  6. 分段渲染时，松键事件正好压在段尾可能被丢掉，音就停不下来（配乐里表现为上一个和弦的音赖着不走）。事件要按采样点分到段里。
- 测过的：滤波器、包络、声像、弯音（重击低频 84 → 41 Hz 滑下来）、分段改参数都按设定出声。
- **用户听后的结论（2026-11-21）**：比以前用代码拼的音效好；比剪映音效库方便：剪映要一个个找、还要下载，合成器随时现做。所以强调点类声音先用它（见第一节的表）。没说比剪映的更好听，两边音质没有一对一比过。
- 混响现在用的是 pedalboard 自带的算法混响。"卷积混响"（用真实房间录下来的回声文件做混响，更像真的空间）要另下回声文件，没下。
