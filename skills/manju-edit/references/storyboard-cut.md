# 按分镜剪：基础剪辑和深度精剪

两步，先后做，不能跳：

| | 基础剪辑 | 深度精剪 |
|---|---|---|
| 要回答的问题 | 分镜要的东西，生成出来的素材里有没有、剪出来对不对 | 剪对了以后，怎么让这一集更好看：素材和分镜的长处放大，短处藏住 |
| 依据 | 分镜脚本（分镜编导出的） | 戏本身：每场戏的重音、情绪曲线；公司惯例；参考片 |
| 能不能偏离分镜 | 不偏离。做不到的地方记下来，交给兜底或补拍 | 可以调顺序、长短，加反应镜头，重复用镜头。前提是不加新剧情、新台词，不破公司十条 |
| 交付物 | 镜头对照表 + 剪辑方案 + 补拍需求 | 精剪改动表（每一刀改了什么、为什么）+ 自检报告 |
| 验证状态 | 流程按分镜脚本的格式推出来，没在本技能里完整剪过一集 | 原则是剪辑常识加第 34 集深度精剪成片看到的，同上，没完整做过 |

公司第 5 条是两步的顺序：先把画面、声音剪到没错、自己成立，再求精彩，音乐最后加。

## 一、基础剪辑：照着分镜剪

### 要准备什么

| 材料 | 在哪 | 用来干什么 |
|---|---|---|
| 分镜脚本 | 分镜编导出的 `第X集_分镜脚本.md` | 每镜要什么（4. 分镜表）、怎么分段（7. 生成段切分）、台词（8. 英文台词总表）、后期要做的事（9. 后期清单） |
| 每个生成段的成片 | 平台上生成、用户下载到本机（下载要先问） | 素材 |
| 编译报告（用译镜写的提示词才有） | `第X集_编译报告.md` | 每段几个镜头、每段的结束状态 |
| 剪映草稿（剪到一半要检查时） | 本机剪映 | 查规范、查夹帧 |

分镜表里和剪辑直接相关的列：**时长**、**景别 / 角度 / 运镜**、**画面**、**作用 ｜ 接法**、**台词**（同期还是画外）、**声音**。

### 步骤

1. **读分镜**：先读"快节奏怎么做"、节拍拆解、生成段切分、后期清单，知道这一集的重音在哪、哪里要静、哪里要升格。
2. **每段素材体检**：对每个生成段的成片跑 `qc_media.mjs <段N.mp4>`，拿到内部镜头表、接触表、头尾残帧。
3. **镜头对照表**：把素材里的内部镜头逐个对到分镜的镜号上（看接触表，对着分镜"画面"一列）。每一镜标一个状态：
   - 对上了；
   - 景别/角度不对（能不能放大、镜像救，见兜底手册 A4、A5）；
   - 缺镜（素材里没有这一镜）；
   - 多出来的镜（AI 自己加的，一般不用）；
   - 顺序反了；
   - 穿帮（手、脸、文字、道具、服装、人数，对照分镜第 6 节的角色状态表和高风险镜头）。
4. **定取用区间**：每个镜号定入点、出点。
   - 入点：动作已经开始、起幅僵直之后，并且在素材内部切点**之后**至少 1 帧。
   - 出点：动作做完、变形之前，并且在内部切点**之前**至少 1 帧。
   - 有台词的，最后一个字说完再多留几帧，或者把声音分离出来单独留尾巴（兜底手册 B4）。
   - 时长先照分镜的"时长"列；素材里的表演更长、更好的，可以多留，在方案的"为什么"一栏写明。
5. **按"接法"定切点**。分镜的"接法"一列就是这一刀的理由，剪的时候照着落刀：

   | 接法 | 刀落在哪 |
   |---|---|
   | 看（视线匹配） | 上一镜人物眼睛看过去、视线停住的那一刻切；下一镜是他看到的东西 |
   | 动（动作剪辑点） | 动作做到一半切：上一镜出点在动作进行中，下一镜入点接同一个动作的下一瞬间，别让动作重复或缺一截 |
   | 因果（反应） | "因"落地的那一刻切到"果"：话的最后一个字、拳头打到的那一帧、东西落地的声音 |
   | 交代（定场、关系） | 留够看清所有人位置的时间（一般 2 秒以上），别切太快 |
   | 段首 | 生成段的第一个镜头，常常是关系镜头；和上一段的结尾按"跟下一段怎么接"一列接 |

6. **台词和字幕**：对着英文台词总表核对每一句都在、没被剪断（规则 3）。"画外"的台词，画面切到听的人，声音拖过来（L cut）。字幕按《字幕标准》（`company-rules.md`）。
7. **声音**：分镜每一镜的"声音"一列加上后期清单，整理成音效清单，时间码换成成片时间。AI 自带的音乐要去掉（兜底手册 B1）。三层声音：环境铺底、动作同步、强调点（兜底手册 B5）。音效从哪来、怎么做出质感，见 `sound-design.md`。
8. **后期清单里的特殊处理**照做：升格（慢放）、数码跳推、硬切黑、全场静音。改了时长要整集统筹。
9. **做不到的**：先按兜底手册救。救不了的，写补拍需求（兜底手册 D 节），交回编导套装补单镜（模型流程树的补镜头节点）。
10. **交付前自检**：`qc_draft.mjs`（包括头尾残帧）+ 导出后 `qc_media.mjs`。

### 交付物格式

```
# 第N集 基础剪辑方案

## 镜头对照表
| 分镜镜号 | 分镜要的 | 素材（段N 内部第几个镜头，素材内时间） | 状态 | 处理 |
|---|---|---|---|---|
| 1 | WS 鸟瞰，拖进来按跪下，3s | 段1 ①（0.00–3.40） | 对上了 | 掐头 0.4s（起幅僵直） |
| 3 | MCU 过肩俯拍主教冒汗，2s | 段1 ③（6.10–8.00） | 景别松 | 放大 125% |
| 5 | MS 双人，眼珠斜向主教，3s | 段1 —— | 缺镜 | 用段1 ④ 放大裁成单人顶上；补拍需求见下 |

（格式同 SKILL.md 工作流四“剪辑方案格式”：画面 / 声音 / 剪不出来的 / 改完后自查）

（兜底手册 D 节格式）
```

## 二、深度精剪：让它好看

前提：基础剪辑已经没有错，关掉音乐也能看（规则 5）。精剪的每一刀都要写得出理由，审片人会问。

### 八遍，每遍只看一件事

一遍看一件事，比一遍什么都看抓得准。每遍改完，重跑一次自检。

**1. 重音**：每场戏最重要的那一拍，落地了没有？
- 重音在哪：分镜的节拍拆解、"镜头怎么引导"一列；没写就自己找：这场戏转折的那句话、那个动作、那个表情。
- 让它落地的办法：
  - 重音前留一点空：停顿、静音，或者先给一个远一点的镜头；
  - 重音用最近的景别，或者推近、放大一档；
  - 重音后留够反应时间，别马上切走；
  - 声音上压一个强调音效，或者反过来全场抽空。

**2. 去水**：哪些帧没有信息？
- 说完话之后的空停、走位、转身、开门进门的过程，能删就删，留结果。
- 对话戏用声音叠接（J cut / L cut）吃掉两人之间的停顿（兜底手册 B4）。
- 留下来的拖沓动作可以 1.1–1.5 倍轻微加速（兜底手册 A3）。
- 参考：公司定稿成片里观众感受到的是两秒左右一个镜头，动作戏一秒一个（`house-style.md` 第 3 节）。

**3. 反应**：每一句重话、每一个重动作之后，有没有给到受的人？
- 重话之后切到听的人，话还没说完，声音留在下层继续（叠盖反应镜头，兜底手册 A2）。
- 第 34 集深度精剪就是这样：58 秒宣判"Her title revoked"，话还在说，画面已经切到主教捂脸。
- 反应镜头不够长，就慢放 0.7–0.8 倍（开补帧），或者从别的段借一个同角色的反应。

**4. 连贯**：视线、动作、方向接得上吗？
- 看的方向一左一右；动作做到一半接上；人物在画面里的左右位置不跳。
- 接不上的，按兜底手册 C1 从代价小的试起：换出入点 → 插反应 → 镜像或放大 → 声音先行。

**5. 画面加工**：素材本身不够劲的，靠剪辑补。
- 推近：放大一档，或者分割成两三段，每段放大一点，做成跳推。分镜里写了"三连猛推"、生成出来却是平滑推的，就这么补。
- 升格：关键动作慢放（倒下、摘冠、出拳落下），分镜后期清单里写了的照做。
- 全集放大倍数统一，放大超过约 150% 画质会变软（兜底手册 A4、E）。

**6. 声音设计**：画面以外的另一半。
- 三层声音铺齐（环境、动作、强调），见 `sound-design.md`。
- 静音也是一种声音：全场骤然安静，比任何重音都重。
- 声音先行：下一场的声音提前几帧进来，把观众带过去。
- 音乐最后加。进出点踩在画面节奏上（重音、转场、情绪转折），段与段之间交叠淡变。
- 对白、音效、音乐互不干扰：对白不叠、音效不压对白、音乐不高过对白。

**7. 开头和结尾**
- 开头 3 秒要有冲突、悬念或强画面。不够的，可以把后面最抓人的一镜提前当钩子（兜底手册例子：校园06 把最后一个镜头提前到开头）。
- 结尾停在情绪最满、或者悬念刚抛出的那一帧。公司惯例是片尾定格加特效（`house-style.md` 第 4 节）；第 34 集深度精剪结尾是女主流泪的特写，接硬切黑。按这一集的情绪选。
- 片尾声音收住，不要戛然而止（规则 3）。

**8. 整集过一遍**
- 先关掉音乐轨看一遍：节奏是不是画面自己给的（规则 5）。看完恢复音乐轨（规则 8）。
- 再完整看一遍，只当观众。哪里走神了、哪里没看懂，就回到对应那一遍改。
- 最后跑自检，**逐帧看每一个改过的接缝**。精剪改了几十刀，残帧最容易在这时候冒出来（`frame-residue.md`）。

### 精剪改动表（交付物）

```
# 第N集 深度精剪改动表

| # | 时间码 | 哪一遍 | 改了什么 | 为什么 |
|---|---|---|---|---|
| 1 | 00:34:10 | 1 重音 | "Enough." 前删掉 0.4s 走位，后面全场静音 1.2s | 这句是本集转折，前面拖、后面不静，砸不下去 |
| 2 | 00:58:02 | 3 反应 | 叠盖主教捂脸 1.6s，对白留在下层 | 宣判要落到被判的人脸上 |
```

### 参考片：第 34 集深度精剪 v02

用 `qc_media.mjs` 量出来的（2026-11-21）：

- 116.6 秒；按切点数，36 个镜头。分镜计划是 120 秒、42 镜。
- 镜头时长：中位 2.96 秒，最短 1.71 秒，最长 7.17 秒。
- 响度 −19.5 LUFS，真峰值 −2.1 dBFS，动态范围 8.2 LU。校园系列定稿约 4 LU，这一版起伏更大。
- 机器自检 0 条问题。

看接触表能确认的手法：
- 对白拖过切点，压在反应镜头上；
- 反应镜头留得够长；
- 结尾落在流泪的特写上。

没有它的草稿和原始素材，所以说不出它具体剪掉了什么、改了什么。拿到草稿后，用 `stats_drafts.mjs` 和 `dump_timeline.mjs` 补进这里。
