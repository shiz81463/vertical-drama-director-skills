# 剪辑交付自检

这是通用检查清单，不是特定团队或平台的交付规范。项目有要求时，以项目提供的版本为准。

- **草稿**：先备份；交付前检查停用素材、隐藏轨道、误留的复合片段和时间线空洞。
- **画面**：逐帧检查切点附近的夹帧、卡帧、无关画面和穿帮；特别检查镜像后的文字、服装、道具和动作连续性。
- **声音**：确认对白完整可辨、音效与动作对齐、音乐不盖过对白；检查突兀静音和音频截断。
- **字幕**：按交付要求确认语言、行数、可读性和同步，逐条校对台词。
- **文件**：向项目方确认命名、画幅、字幕或无字幕版本、截图及其他交付物，不套用其他项目的要求。

预告片在交付前再检查是否剧透、音乐和声效是否干扰对白，以及切点是否准确。先跑 `qc_draft.mjs` 或 `qc_media.mjs` 找疑点，再看片确认；脚本不能代替审片。
