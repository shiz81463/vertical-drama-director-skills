# 人物表演档案（模板）

每部戏的主要角色各一张，写好给用户确认后，存进这部戏的剧设定（`竖屏制作\剧设定\<剧名>.md`）的"人物表演档案"一节，整部戏照它演（规则 T1）。改档案和改风格锁一样，先问用户。

来源按这个顺序：剧本人物小传 → 剧本括号里的表演提示（把这个人所有的括号提示扫一遍，找重复出现的）→ 资产图 → 用户的话。

## <中文名> <英文名>（<身份 · 年龄>）

| 项 | 写什么 | 这个人 |
|---|---|---|
| 身体和重心 | 怎么站、怎么坐、怎么走，身体的分量在哪 | |
| 平时的脸 | 没事的时候脸是什么样 | |
| 情绪从哪漏 | 一两个部位 | |
| 习惯动作 | 一两个，紧张或得意时会做的 | |
| 声音 | 音高、快慢、音色、口音的味道 | |
| 不会做的事 | 这个人绝不会这样演 | |
| 阶段 | 第几集到第几集，上面哪几样会变 | |

**进提示词的那一句**（英文，不超过 160 字，T2）：每段从上表挑用得上的，格式 `<英文称呼> (<中文名>): <这一段的状态>; <情绪从哪漏>; <习惯动作>.`

示例：`Ethan (伊森): came far too early, head high, at ease on the surface; it leaks from his hands, which keep going back to his tie and cuffs.`
