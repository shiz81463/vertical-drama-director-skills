# 文戏设计：从台词和场景到分镜（竖屏 9:16）

用户给什么，见 `SKILL.md` 的"输入"。按下面七步设计，结果写进设计单（格式见 `SKILL.md` 的"交付"）。切入理由这类"给人看的"内容不进提示词（规则 H11）。

这一份里的做法**都还没有生成验证过**。来源写在每节开头，生成后看效果再定去留。

这份从横屏原版改出来：节拍、人物、情绪、微表情、台词这些和画幅无关，照旧；站位、构图、正反打按竖屏改，竖屏专门的做法集中在**第十二节**，第五节的站位图、第六节的对照表、第十节的例句也换成了竖屏的写法（标〔竖屏〕）。

## 一、七步

1. **一句话**：这一段讲什么——谁想要什么、被什么挡住、关系最后变成什么样（规则 D1）。
2. **人物设定**：每个人想要什么、藏着什么、怕什么、谁占上风（第二节）。
3. **节拍**：15 秒放 2–4 拍，至少一次转折（第三节）。
4. **秒级情绪表**：每一秒外面在发生什么、里面在发生什么、观众看到什么（第四节）。
5. **站位和视线**：俯视站位、轴线、视线方向和高低；〔竖屏〕再定机位在哪、同框时谁近谁远、谁在画面上谁在下（第五节、第十二节）。
6. **分镜**：每镜一个情绪任务，按对照表选手法，排正反打（第六、七节）。
7. **可行性检查**：谁看得到谁；主观镜头看得到吗；微表情的景别够不够；台词装不装得进镜头；〔竖屏〕窄画面里两人装不装得下、手在不在画面里（规则 D7、E10、J3、V1）。

## 二、人物设定

| | 甲 | 乙 |
|---|---|---|
| 想要什么 | | |
| 藏着什么（不说出口的） | | |
| 怕什么 | | |
| 对对方的态度 | | |
| 谁占上风，什么时候反转 | | |
| 情绪从哪里漏出来（哪个身体部位） | | |

例（填写示例：溪边告别）：

| | 宁小贤 | 女子 |
|---|---|---|
| 想要什么 | 走，去乌云那边 | 他留下 |
| 藏着什么 | 舍不得 | 想留他，但不肯开口求 |
| 怕什么 | 多看她一眼就走不了 | 他真的走 |
| 谁占上风 | 他：已经决定了 | 她：只能等他的回答 |
| 情绪从哪漏出来 | 眼睛和手（脸一直绷着） | 呼吸、嘴角、攥发带的手 |

最后一行很重要：每个人只从一两个地方漏情绪，表演才会克制、可信（规则 E6）。

浓缩成提示词【戏的逻辑】里的 3–5 句英文 SCENE LOGIC。

## 三、节拍

来源：《废土甜心》storyboard 技能的节拍拆解；《镜头语法手册》第四、五节。

| 拍 | 秒 | 触发 | 谁的情绪从什么到什么 | 观众看到的信号（2–4 个） | 关系怎么变 |
|---|---|---|---|---|---|

规则：

- 每一拍都由上一拍引出（规则 D4）。触发可以是一句台词、一个动作、一个眼神、一件东西。
- **至少一次转折**：情绪反过来，或者往上推一级。从头到尾一种情绪，等于没有戏。
- **最想说的话常常不说出来**：让一件东西、一个动作替人说（规则 D6、E3）。
- **结尾停在悬点上**：那句话还没说出口、还没转身、手还没松开（规则 D8）。

例（填写示例）：

| 拍 | 秒 | 触发 | 情绪变化 | 观众看到的 | 关系 |
|---|---|---|---|---|---|
| 一 · 憋着 | 0–3 | 他的目光离开她，望向远处的乌云 | 她：等 → 明白他要走 | 他的视线移开；她的手攥紧发带 | 隔着三步，谁都没开口 |
| 二 · 开口 | 3–6 | 她说"雨要来了" | 她：压着 → 用一句不相干的话求他 | 吸一口气；嘴角想轻松，没成功 | 她先伸出手（用话） |
| 三 · 不答 | 6–9 | 他听懂了 | 他：硬撑 → 差点撑不住 → 压回去 | 眨眼、屏气；眼眶湿；吞咽、下颌绷紧；视线落到发带上 | 他的沉默就是回答的开始 |
| 四 · 接过 | 9–11 | 她递出发带 | 两人：答案落地 | 指尖碰了一下；她的手空了 | 东西换了手，关系定了 |
| 五 · 留下 | 11–15 | 他转身走 | 她：被留下 | 太阳照满她的脸；手还半举着 | 距离拉开，她一个人在画面里 |

## 四、秒级情绪表

| 秒 | 镜 | 谁 | 外在（动作、台词） | 内在（情绪） | 观众看到的信号 |
|---|---|---|---|---|---|
| 0–1 | 1 | | | | |

要求：
- 外在和内在分两列写。提示词里只写外在和信号，内在不写（模型画不出"内在"，只会给一张笼统的脸）。
- 关键反应按三层排时间：本能约 0.2–0.5 秒，漏出来约 0.5–1.5 秒，压回去约 0.5–1 秒（规则 E2）。
- 一镜里的拍数，模型大概能执行 3–4 拍；再多会被合并或跳过。

## 五、站位和视线

来源：《镜头语法手册》第二节（轴线、银幕方向）；第 22 行的视线教训。

**1. 俯视站位图**（用文字画在设计单里）：

```
        乌云（远）
  大树
  [宁小贤] ——三步—— [女子]        ← 两人之间的连线就是轴线
     ↖ 机位一直在这一边（远离溪水的一边），
       〔竖屏〕同框时放在宁小贤身后、靠机位一侧（他的右肩）后面，连线的一头偏一点：
       他离镜头近、在画面左下；她在三步外、画面右上
  ~~~~~~~~ 溪 ~~~~~~~~
  低低的太阳在左边雾后面
```

**2. 视线表**：

| 谁 | 看对方时看画面哪边 | 高低 | 英文称呼 |
|---|---|---|---|
| 宁小贤 | 右 | 往下一点（高一个头） | the swordsman |
| 女子 | 左 | 往上一点 | the woman |

**3. 要点**：

- 机位一直留在轴线同一边，人就一直一左一右（规则 F2）。
- 〔竖屏〕同框时再定远近上下：谁离镜头近、在画面下方，谁远、在画面上方，整段不换（规则 F2、V1、V2）。
- 单人镜头里，视线擦着镜头边过去，不看镜头（看镜头 = 对观众说话）。
- 视线要有具体目标；看画外时，下一镜要给他看到的东西（规则 F6）。
- 视线高低对上：站着的往下看一点，坐着的往上看一点。写清"镜头停在他们眼睛的高度"，防止镜头跟着仰（规则 E9）。
- 入画绑在视线上：他正好从她望着的地方进来（规则 F5）。
- 背对镜头的人只转头、不转身（规则 E8）。

## 六、镜头怎么表达情绪

来源：《镜头语法手册》第四节"情绪对应什么手法"，加上王家卫、杜可风常用的做法。每镜只挑 1–2 样，不要全堆（规则 H4）。

| 想要的情绪 | 景别和角度 | 运镜 | 焦点和构图 | 光 | 节奏 | 声音 |
|---|---|---|---|---|---|---|
| **心事被看穿、泄露** | 近景 → 特写 | 慢慢推近（因为他漏了） | 浅景深，背景虚掉 | 脸从暗处转到光里 | 停在脸上，不急着切 | 环境声压低 |
| **憋着、压抑** | 近景，画面压在一边 | 固定不动（因为情绪也停着） | 前景遮住一角（门框、帘子） | 脸一半在暗里 | 镜头比台词长，留沉默 | 只剩呼吸 |
| **疏离、隔阂** | 干净的单人，不用过肩 | 固定，或者慢慢拉开 | 两人分在画框两边，中间空着；门框窗格把两人隔开 | 两人在不同的光里 | 正反打越切越慢 | 两边的环境声不一样 |
| **亲近、连着** | 过肩，两人同框 | 轻轻跟着，不离开两人 | 两人在同一片景深里 | 同一个光源照着两个人 | 正反打越切越短 | 对方的呼吸听得见 |
| **孤独、被留下** | 全景、远景，人在画面里很小 | 慢慢往后拉（因为她被留下） | 大片负空间 | 人在光里，四周暗 | 最后一镜停得最久 | 环境声变大，人声没了 |
| **震动、意识到** | 近景，突然收紧 | 一下推近（急推） | 移焦：从东西拉到脸上 | 光一变（灯焰一歪） | 先给反应，再给他看到的东西 | 声音一下抽空 |
| **上风和下风** | 占上风的正面、在画面高处；弱的侧面、在边上 | 占上风的一方镜头更稳 | 弱的一方被前景压住 | 占上风的背光（看不清他），弱的被照亮 | 让占上风的一方镜头停得久 | 占上风的声音更近 |
| **余韵、说完以后** | 近景或全景都行 | 不动，或者极慢地拉 | 留出空间 | 光慢慢变（太阳落、灯暗） | 不切，多停 1–2 秒（规则 H6） | 只剩环境声 |
| **心乱、动摇** | 近景，荷兰角（画面微微倾斜） | 手持轻晃 | 焦点在脸前后漂 | 光不稳（火苗晃） | 切得不规则 | 环境声忽大忽小 |

〔竖屏〕上表的景别和构图，在竖画面里这样落地（待验证）：

| 想要的情绪 | 竖屏怎么构图 |
|---|---|
| 心事被看穿、泄露 | 近景到特写，脸撑满画面宽、在画面上半；推近时脸越来越占满宽度 |
| 憋着、压抑 | 脸压在画面一侧，另一侧被竖着的门框、帘子遮住一条 |
| 疏离、隔阂 | 一道竖着的门框、窗格把竖画面切成两条，两人各在一条里；或者两人分在画面上下两头，中间空着 |
| 亲近、连着 | 过肩，两人挤在同一条窄画面里，一前一后叠着 |
| 孤独、被留下 | 人小小地站在画面中间偏下（字幕位上面一点），头顶大片的天、屋顶或空墙；镜头往后拉时，上方的空越来越大 |
| 震动、意识到 | 纵深同框，移焦：焦点从近处下方的人一下移到远处上方的人（或反过来） |
| 上风和下风 | 占上风的在画面上方、往下看；弱的压在画面下方、往上看（镜头不跟着仰） |
| 余韵、说完以后 | 人小小地留在画面中间偏下（字幕位上面一点），上面留空，不切 |

几条通用的：

- **镜头只在情绪变化时动**（规则 H2）。运镜链里写清"因为谁的情绪怎么变，镜头怎么动"；不动就写"固定，因为……"。
- **景别跟着情绪的距离走**（规则 H5）：越亲密、越激烈越紧；孤立、余韵、关系断了就拉开。
- **光也演戏**（规则 C6）：谁在光里、谁在暗里；光一变，要有画面里的原因（风、云、有人挡光又走开）。
- **王家卫味道的几样**：前景遮挡（隔着纱帘、门框、雨玻璃拍）；人压在画框边上，中间空着；镜子或水面里的倒影；抽帧（风格锁里已经有"抽帧、慢门"，不另写慢镜头）。用之前想清楚它表达的是什么情绪。

## 七、正反打

来源：《镜头语法手册》第五节"对话戏"；`精品制作\拉片_景别与正反打.md`。

正反打大白话：两个人面对面，镜头先从这边拍那边，再切到那边拍回来。

**1. 对话戏的标准排法**（规则 G1–G5）：

1. 同框（关系镜头）：交代两人位置和距离；〔竖屏〕用纵深：一个人的肩背在画面左下或右下、离镜头近，另一个在深处、画面上半（规则 V1）；
2. 过肩正反打：说话的人在画面里，听的人的肩在前景，只占一角、虚焦（规则 G7）；〔竖屏〕前景的肩压在画面下角，说话人的脸在画面上半；
3. 单人近景：情绪加强时，两边一起收紧；
4. 关键那句话：给特写；听的人的反应常常比说话的人更重要；
5. 位置或情绪转折之后，再同框一次，让观众看见距离变了。

**2. 两边要对等**（规则 G2）：正打近景，反打也近景；角度对称；机位都在轴线同一边。情绪升级时两边一起往紧走。故意不对等（一边特写一边全景），只用来表现地位不对等，要在设计单写明。

**3. 过肩还是单人**（规则 G3）：过肩 = 两人还连在一起；干净的单人 = 隔开了。关系断开的那一刻，从过肩换成单人。

**4. 听的人**（规则 G4、E5）：关键那句台词，镜头可以停在听的人脸上，说话声从画外来。这时要写画面里的人嘴唇闭着（规则 J4）。听的人每一镜都要有一个小变化。

**5. 三个人**：先给三人同框（三角站位）；按"谁在跟谁说话"建立轴线；第三个人插话时，先给他的反应或一个新的同框，再换轴线。〔竖屏〕三人同框从最近那个人的肩后往远处拍，三人前后错开（规则 V2）。

**6. 一次生成里能做的**：15 秒最多 6 镜，文戏建议 3–5 镜。正反打来回切很多次的，拆成两行生成，或者生成时每镜长一点，剪辑时再剪短。

## 八、微表情怎么写

来源：Seedance 2.5 官方指南（"用 2–4 个可观察的表现"）；libtv 悟空战二郎（反应分三层、视线落点）；第 22 行。

**1. 信号词表**（写进英文逐拍；一次挑 2–4 个）：

| 部位 | 中文 | 英文写法 |
|---|---|---|
| 视线 | 移开 / 落在…… / 回到他脸上 / 找 | her gaze slides away; her eyes land on ...; his eyes come back to her face; her eyes search the ... |
| 眼睛 | 眨一下 / 眼眶湿 / 闭了一下 | a blink; the rims of her eyes wet; she shuts her eyes for a moment |
| 眉 | 眉心一紧 / 眉尾往下 | a crease between her brows; her brows draw down |
| 嘴 | 嘴唇抿住 / 嘴角想笑没笑成 / 嘴唇张开又合上 | she presses her lips together; the corner of her mouth tries to smile and fails; her lips part, then close |
| 呼吸 | 屏住 / 长出一口气 / 吸一口气准备说话 | she holds her breath; a long breath out; a small breath in before she speaks |
| 喉咙 | 吞咽 | he swallows |
| 下颌 | 咬紧 | his jaw sets |
| 肩颈 | 肩一缩 / 肩塌下来 | a small flinch of her shoulders; his shoulders drop |
| 手 | 攥紧 / 松开 / 伸出去又收回 | her hand tightens on ...; his fingers open; she reaches out, then pulls her hand back |
| 脚步 | 停住 / 退半步 | he stops; she takes half a step back |

**2. 反应三层**（规则 E2）：

```
First a blink and a breath he does not let out; then his eyes come back to her face and stay, the rims of his eyes wet for a moment; then he swallows, his jaw sets, and his eyes drop to the ribbon in her hand.
```

本能（不由自主）→ 漏出来（真实的情绪）→ 压回去（他在控制）。不是每个反应都要三层，关键的那一两个才用。

**3. 潜台词：两个通道打架**（规则 E3）：

- 嘴上轻松，手攥紧："she says it lightly; at the bottom of the frame her hand tightens on the ribbon."
- 脸不动，眼睛漏了："his face stays still; only his eyes are wet."

**4. 视线三步**（规则 E4）：先找 → 落在哪 → 带出身体反应。

```
Her eyes search his face, land on the ribbon in his hand, and her breath stops for a moment.
```

**5. 景别要够**（规则 E10）：瞳孔、睫毛要特写；眼眶湿、嘴角、下颌、喉咙要近景以内；手的细节要单独一个特写，或者确认手在画面里。全景里只写看得见的：姿势、距离、手还半举着。

**6. 不要写的**：

- 抽象情绪词当主语："she is sad"、"he feels angry"（规则 E1）。
- 强情绪词："eyes burning"、"怒火"（会带出发光的眼睛，规则 E7）。
- "looks back"、"turns around"（背影会整个转过来，规则 E8）；"look up"、"chin lifts"（镜头跟着仰，规则 E9）。
- 眼泪写在通用规则里（会从第一帧就挂着泪），只写在出现的那一拍（规则 B7）。

## 九、台词怎么写

来源：《废土甜心》Seedance 提示词规范（第八、九集）；Seedance 2.5 官方指南。

**格式**（规则 J1）：单独一行，谁说 → 对谁说 → 语气和说话方式 → 用什么语言 → `{台词}`，`}` 后面什么都不写。

```
Dialogue: the woman, to the swordsman, lightly, about the weather, in Mandarin Chinese: {雨要来了。}
```

- 一镜最多一句（规则 J2）。
- 装得进镜头：普通话每秒不超过 4 个字（情绪重的 3 个），英文每秒不超过 2.5 个词（规则 J3）。
- 画外音：在语气前面写 off-screen，并在逐拍里写画面里的人嘴唇闭着（规则 J4）。
- 台词是用户给的原文，一个字不改（规则 A8）。没有台词就写无台词的戏，靠视线、表演和镜头讲。
- 语言按剧设定：大部分戏 in American English；《宁小贤》in Mandarin Chinese（规则 J7）。

## 十、写进提示词的样子

完整的一条见 `templates/填写示例_未验证.txt`（v3 换成了《320磅》第 10 集段 1 的瘦身稿，17 秒 5 镜，8,335 字）。下面几种常用镜头还是旧示例"溪边告别"的写法，看拍法用；写进提示词时按 v3 骨架压短（rules.md N 节）：

**开场同框（关系镜头）**：纵深，不左右站开（规则 V1）


## 十一、不要做的

- 不编台词，不加剧情（规则 A8）。
- 不拿情绪词当主语，不堆信号（一次 2–4 个）。
- 不让镜头为了动而动；不变焦。
- 不在情绪最高点马上切走。
- 不在全景里写只有特写才看得见的微表情。
- 不在提示词里写"为什么切到这里"。
- 〔竖屏〕不把两个人一左一右站在全景两头、中间一片空（规则 V1）。
- 〔竖屏〕不在近景里写手上的细节却不管手在不在画面里（规则 E3、E10）。

## 十二、竖屏空间和构图〔竖屏〕

来源：《废土甜心》竖屏剧集的《镜头语法手册》二.4、导演反馈（第十七、十八集白模），加上为这套提示词新写的做法（都待验证）。

### 1. 站位图上多定两件事

1. **机位**：放在两人连线的一头、偏一点（一般在主角肩后），这样同框时两人一近一远，自然排成斜线。
2. **远近上下**：同框时谁离镜头近、在画面下方，谁远、在画面上方。整段不换；要换就用一个运镜带过去（规则 F2、V2）。

### 2. 同框的四种办法

| 办法 | 什么时候用 | 写法 |
|---|---|---|
| 纵深（一近一远） | 开场关系镜头、转折后再同框 | 一个人的肩背在画面下角、离镜头近；另一个在深处、画面上半，从头到脚都在 |
| 过肩 | 对话的正反打 | 前景的肩只占画面下角、虚焦；说话人的脸在画面上半（规则 G7、V7） |
| 上下 | 一个站一个坐、一个在台阶上一个在台阶下 | 高的在画面上方往下看，低的在下方往上看；镜头停在原来的高度，不跟着仰（规则 E9） |
| 并排（中景以内） | 两人挨得很近（一步以内）：并肩坐着、靠在一起 | 两个上半身一前一后叠着，脸都在画面上半 |

### 3. 竖屏的单人镜头

- 近景：胸口以上，脸在画面上半，头顶留一点空。
- 特写：脸撑满画面宽，头顶和下巴都在画里。
- 视线擦着镜头边往画面左或右看，和对方那一镜对得上（规则 F3）。竖画面窄，视线那一侧要留一点空，不让脸贴着画框看出去。
- 手上的信号（攥紧、松开）：近景里手常常在画面外，要么镜头松到手进画面下方，要么单独一个手的特写（规则 E10）。

### 4. 竖屏讲关系的几个位置

- **上下 = 高低**：占上风的在画面上方，弱的压在下方（规则 G6）。
- **头顶的空 = 孤独**：人站在画面中间偏下，上面大片的天、屋顶（规则 H7）。字幕位在画面下方约四成，人别压得太低。
- **竖着的门框 = 隔开**：一道门框、窗格把竖画面切成两条，两人各在一条里。
- **纵深 + 移焦 = 意识到**：焦点从近处的人移到远处的人（规则 H8）。

### 5. 走动和入画

- 走近、走远、离开，顺着纵深走（走向镜头、走进深处）；横着走两步就出了窄画面（规则 V5）。
- 入画：从深处走近，或从画面上方、下方进来，比从侧边进来更看得清；照样绑在视线上（规则 F5）。
