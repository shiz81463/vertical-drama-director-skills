# 打戏设计：从资产和场景到分镜（竖屏 9:16）

用户给什么，见 `SKILL.md` 的"输入"。按下面八步设计，结果写进设计单（格式见 `SKILL.md` 的"交付"）。切入理由这类"给人看的"内容不进提示词（规则 I7）。

标〔待验证〕的做法还没有生成验证过，用了要在设计单里注明，生成后看效果。

这份从横屏原版改出来：打法、回合、攻防、逻辑这些和画幅无关，照旧；分镜和构图按竖屏改，竖屏专门的做法集中在**第九节**，第六节的例句也换成了竖屏的写法。样片（灵笼、新龙门、环太平洋）都是横屏，节奏可以学，构图要按第九节翻成竖的。

## 一、八步

1. **定这一段讲什么**：局面怎么变；每个人从中知道了什么。每一步都由上一步引出（规则 J1）。
2. **双方设定**：体型、快慢、看不见和够不着的地方、怕什么、想要的距离、能力的代价（第二节）。
3. **回合**：一段 15 秒放 1–3 个回合（加了松镜头、反应和接力时只放 1–2 个，规则 H15）。每个回合回答四件事：谁主动；对方怎么回应；靠什么拉开或拉近距离；双方各学到什么（第三节）。
4. **秒级攻防表**：每 0.5–1 秒一次交换，每一格标出进攻 / 闪避 / 防守 / 反击 / 受击；受击一次比一次重，最重的一下放在结尾；结尾停在动作里（第四节）。
5. **打戏逻辑检查**：每一招是不是被局面逼出来的、结果有没有把人送到下一个位置（第五节，规则 J9–J12）。
6. **竖屏空间**：画俯视站位图，定左右（轴线）、谁离镜头近谁远、谁在画面上谁在下；挑竖着的地标；定被打飞、冲刺的路线顺着哪条长边走（第九节，规则 V 节）。
7. **分镜**：先定主力景别，再排紧和松；15 秒最多 6 镜，切点用整数秒；开头和结尾各一个关系镜头；每镜写清同框方式（纵深、上下、过肩、单人）；每一刀写"因为……所以切到这里"，只写在设计单里（第六节）。
8. **物理可行性检查**：谁够得着谁；镜头机位看不看得见这个动作（侧面机位拍到的是靠机位一侧的手）；反常识的运动有没有支点；特效的出处在不在画面里；窄画面里装不装得下（规则 J8、D8、V1）。

## 二、双方设定

| | 甲 | 乙 |
|---|---|---|
| 体型 | | |
| 快慢 | 大动作、小动作各多快 | |
| 看不见、够不着的地方 | | |
| 怕什么 | | |
| 想要的距离 | 在哪儿最安全（安全区），在哪儿最能打到对方（杀伤区） | |
| 能力的代价 | 用完会怎样、哪里露破绽 | |

大白话："安全区 / 杀伤区"就是一方待在哪儿最安全、另一方在哪儿最能打到对方。打戏就是双方在抢这块地方。

**一样大的两个人怎么分安全区**：看兵器长短和地形。长兵器要距离，短兵器要贴身；柱子、桌子、门框、楼梯这些东西，谁会用谁占便宜。把这些地形写进场景，之后每个关系镜头都要看得到（规则 H18）。

**例一（体型悬殊，未验证）：视频28 伊芙对霜牙**（`精品制作\视频28_伊芙战霜牙_冻住又炸开_设计.md`）

| | 霜牙 | 伊芙（加上复生者） |
|---|---|---|
| 体型 | 身长 300 米，一片鳞比伊芙大 | 一米六 |
| 快慢 | 大动作起手短而重（吸气、收翼），然后又快又挡不住 | 本人几乎不动；靠复生者挡，靠按地反击 |
| 看不见、够不着 | 贴地的小目标要俯冲才打得到；俯冲转不了急弯，会冲过头 | 够不着天上的龙；只有龙低飞时，碎冰才打得到 |
| 怕什么 | 碎冰打进鳞缝 | 人墙没了，被龙正面盯上 |
| 想要的距离 | 把人墙清掉（空地是它的杀伤区） | 一直躲在人墙后面（她的安全区） |
| 能力的代价 | 吐息要先吸气，暴露起手 | 按地要单膝跪下、一秒不动，打完人发晃 |

**例二（巨物天战，v13 横屏验证过）**：见 `竖屏比例差打戏` 的 `references/打戏设计.md` 第二、三节（巨魔对骑鸟的宁小贤）。

**关于"大的一方慢"**：大的一方慢在起手和反应（要转身、要找人），出手本身不慢。提示词写"慢"，模型会给慢镜头；要写成"起手短而重，然后又快又挡不住"（规则 G3、J5）。

## 四、秒级攻防表

| 秒 | 镜 | 谁 | 动作 | 属于 |
|---|---|---|---|---|
| 0–1 | 1 | | 已经在打 | 建立空间 |
| … | | | | 进攻 / 闪避 / 防守 / 反击 / 受击 |

要求：
- 0.5 秒内就开打；不赶路、不摆姿势、不对峙（规则 J4）。
- 每次大招，上一镜结尾就让观众看到起手（肩往后转、手抬起来、吸一口气）。
- 接触只有一瞬就分开；闪避是全身反射（眼 → 头 → 胯 → 肩臂 → 膝 → 头发、袖子落后）。
- 一镜里的拍数，模型大概能执行 3–4 拍，再多会被合并或跳过；也不要少到只有一拍，否则这一个动作会被拉满整镜（规则 J11〔待验证〕）。

## 五、打戏逻辑检查〔待验证〕

来源：用户 2026-10-20 看快节奏版 v2，说"是暴躁了但是打戏没逻辑"。原因是为了快和狠，往镜头里堆招（劈刺刺刺刺、砍腕砍肘砍肩）：招没有目的、不断重复、互不相干。

写完攻防表，逐行问：

1. **主角要去哪？** 打到哪里才算数（例：宁小贤要冲到巨魔脸上，只有眼睛附近砍了才疼）。
2. **这一招是被什么逼出来的？** 离得多远、兵器在哪、谁背对着谁。贴身只能用短的动作，拉开了才刺、才扫。
3. **这一招的结果，把人送到了哪？** 下一招要从那个位置开始。
4. **大招前有没有看得见的空当？** 例：对方横扫用力过猛、兵器甩过头、门户大开，主角才出大招。
5. **物理上做得到吗？** 例：一根扫过去的戟齿不能连磕三下，改成前后两根戟齿各磕一下。
6. **暴躁从哪来？** 靠怒气（吼、咬牙、喘）、运镜（跟着被打飞的人翻、撞到东西猛震）和节奏（越切越短），不靠多加招（规则 J10）。

## 六、分镜

节奏先于镜头类型。这一节全部〔待验证〕：来源是导演 2026-10-19 的点拨、三个样片的两次拉片（灵笼、新龙门客栈、环太平洋），加上 10-20 的看片意见。证据、时间码和宫格图在：

- `精品制作\拉片_打戏镜头表现_三样片.md`（节奏：紧紧松、打击接力、反应镜头）
- `精品制作\拉片_景别与正反打.md`（景别和正反打）

检查脚本只查 H9 和 H17，都只出 ⚠️；其余要人工看。

### 1. 先定主力景别（规则 H19）

一段里交手用什么景别，看这一段要观众看什么：

| 要观众看什么 | 主力景别 | 样片 |
|---|---|---|
| 身法、一招一式完整 | 全景（人从头到脚都在画面里） | 新龙门：交手 45 镜里 28 个全景 |
| 两方扭在一起的分量 | 中景（腰以上，两个上半身都装得下） | 环太平洋：49 镜里 32 个中景 |
| 速度、贴身、疼 | 近景（胸口以上） | 灵笼：18 镜里 10 个近景 |

一段只选一个主力景别，其他景别做点缀。远景、大远景很少（3%–12%），几乎都用来交代位置和看结果。

〔竖屏〕竖屏的全景装得下一个人从头到脚，装不下两个人左右排开。主力选全景时，两人用纵深排开（一个近、在下方，一个远、在上方）；主力选中景时，两个上半身扭在一起、一前一后叠着，比并排更装得下；近景在竖屏里最有力，脸撑满画面宽（规则 V1、V8）。

### 2. 核心三条：紧紧松、打击接力、反应镜头

1. **紧紧松**（H9）：一串短的近景、特写（紧），接一个停得更久的大景别（松）。紧的时候，观众看清打在哪、有多疼；松的时候，看清有多大、飞了多远、有多强。
2. **打击接力**（H10）：一次大打击拆成 2–3 个镜头，跟着被打飞的路线换机位：打中（特写）→ 身体折起（中景，换角度）→ 被甩出去的路线（俯拍或仰拍，拉到大景别）。
3. **反应镜头**（H11）：大打击之后接一张脸（挨打的痛、旁观的惊、出手的狠）；大招之前也可以给一张脸，憋一口气（H12）。

### 3. 打戏的正反打（规则 H20–H22）

正反打大白话：两方面对面，先从这边拍那边，再切到那边拍回来。说话的戏两边给的都是脸；打戏不一样，**正 = 出招或逼近的一方，反 = 挨招或被逼的一方**。

切过去的那一镜（反打）可以给这五种东西：

| 给什么 | 例子 | 作用 |
|---|---|---|
| 结果：挨打的人被打成什么样、飞多远 | 新龙门 #031 → #032 → #033：出掌 → 中掌 → 滚下沙坡 | 力道多大，看结果 |
| 脸：挨打的人或旁观的人 | 新龙门 #071–#073：中招两镜，第三镜旁观者抬头震惊 | 给打击加上情绪，也让节奏停一下 |
| 某一方的眼睛：主观镜头、过肩 | 新龙门 #037：镜头当成出招人的眼睛，贴着沙面冲向三人 | 让观众站到某一方的位置上 |
| 躲开了 | 灵笼 #007 → #008：开火 → 闪开 | 反打不一定是挨打，躲开也是一种回答 |
| 另一个空间 | 环太平洋 #109–#115：拳头从街上打进写字楼，停在一个牛顿摆前 | 把一下打击的范围撑大 |

四个固定搭配：

1. **同框开头或收尾**（H21）：来回切两三次，就给一个同框镜头，把两方放回一个画面。样片里这种镜头 0.4–2.9 秒，看清位置就切走；一次生成里至少 1 秒，剪辑时再剪短。〔竖屏〕同框用纵深或过肩，不左右排开（V1）。
2. **越切越快**：越逼近，镜头越短；打中那一下停住。
3. **过肩省一刀**：前景压着一方的身体，深处是另一方，一个镜头里就有正有反。
4. **占上风的一方迎着镜头**（H22）：正面、往镜头冲；吃亏的一方给侧面、背面、从上往下拍。局面反转，机位也反转。不靠仰拍来做（H7）。

### 4. 关系镜头接成链（规则 H18）

关系镜头不能只是"有个远景"。每一个关系镜头都要回答：两边各在哪、兵器在什么状态、地标在哪、比上一个关系镜头变了什么、为什么会有下一招。

- 先定全片空间地图：轴线（谁在左、谁在右）、地标（倒下的桌子、门、火盆、一道裂缝）、安全区和杀伤区在画面哪一块。
- 设计单的分镜表里，关系镜头的"内容"一栏写清：甲 / 乙在哪 / 兵器状态 / 地标 / 变了什么 / 引出什么。
- 每个预兆都要有看得见、物理上说得通的出处（光从哪来、声音从哪来）；大招的来向要顺着出招的方向。
- 用地标把前后两个关系镜头钉在一起。

出处：比例差打戏的补镜头版 v1（视频36–38）补了远景，用户说"关系镜头的逻辑链还是不够强"；逐个排下来断了四处（没交代为什么只能用空手、被打飞后去了哪、光的变化说不通、大招的来向和出招方向对不上）。

### 5. 镜头类型（常规打戏）

| 类型 | 用来 | 写法要点 |
|---|---|---|
| 关系镜头 | 开场、来回切之后、结尾看结果 | 两边都在画面里，地标看得到；镜头在动（被风吹得抖、跟着摇），不写"稳住、水平"；〔竖屏〕两边用纵深排开（近的在下、远的在上），或者高俯角把场地竖着排进画面 |
| 贴身跟拍 | 连续交手 | 镜头和人一样快，近处的东西两三帧闪过；被每次冲击撞开 |
| 过肩 | 一镜里同时有正有反 | 前景只压对手的一块身体，写清只占画面一角、时长多少，不然模型会在前景人物上停一秒多（第 22 行的教训） |
| 主观镜头 | 让观众站到一方的位置 | 写清是谁的眼睛、在多高；只拍他从那个位置看得到的 |
| 跟着被打飞的人翻 | 受击最重的一下 | 镜头和人一起翻、一起撞上，撞上那一下画面一震；〔竖屏〕飞的路线顺着画面长边（往镜头深处、或者从上往下砸） |
| 长焦远景 | 收尾、看结果 | 很远处拍，镜头被风吹得发抖、跟着摇 |
| 微距插入（慎用） | 刀刃、伤口的手感 | 多镜头段落里单独一镜，写 hard cut、at real speed；一镜到底里不写 |
| 子弹时间（全片最多一次） | 最重的一击 | 写清起止秒数；前后写 back to full speed；环绕不超过 90 度，不越轴 |

### 6. 15 秒 6 镜的两个模板

**模板 A：两次紧紧松**

| 镜 | 秒 | 紧/松 | 内容 |
|---|---|---|---|
| 1 | 0–2 | 松 | 关系镜头：已经在打，交代位置和地标 |
| 2 | 2–4 | 紧 | 连续交手，镜头贴身 |
| 3 | 4–5 | 紧 | 细节或反应：打中的局部，或一张脸 |
| 4 | 5–8 | 松 | 同框：大招全貌、被甩出去多远，停 3 秒 |
| 5 | 8–11 | 紧 | 打击接力前半：打中 → 身体折起 |
| 6 | 11–15 | 松 | 打击接力后半：极端角度看被甩出去的路线，拉到大景别，停住 |

**模板 B：憋气 → 接力 → 长收**

| 镜 | 秒 | 紧/松 | 内容 |

### 8. 一个镜头里的张力

大部分已经在规则里了，写的时候挑一两样用，不要每镜都堆：

- 镜头被打击撞开、跟着翻滚、甩向新威胁慢半拍（H6）
- 前景的东西擦过镜头（C3、G1）
- 主体压在画面边上，荷兰角
- 焦点从刀刃拉到脸（rack focus from the blade to his face）
- 镜头真的冲过去，从远推到近，不变焦
- 爆发前一瞬间声音抽空（全片只用一次）
- 打中时顿 2–4 帧

### 9. 剪辑单（规则 H16）

写在设计单里，不写进提示词：

| 镜 | 生成时长 | 剪成 | 说明 |
|---|---|---|---|
| 2 | 3 秒 | 1.2 秒 | 只留最狠的两下 |
| 5 | 3 秒 | 0.8 秒 + 0.6 秒 | 拆成两段，中间插镜 3 的脸 |
| 补拍 | 另生成 2 次 | 各 0.6 秒 | 同一下打中，从下面、从正面各拍一次，三连放 |

一次生成里做不了的：1 秒以下的快切、同一下打击连放三遍（模型会演成打了三下）。这些靠另外生成和剪辑。

## 七、招式设计

招式不先定，先定局面。每一招都要说得出：从哪个位置出、为什么只能这样出、结果把人送到哪（第五节）。

- **地形就是招式**：桌子可以踢起来挡、柱子可以绕、门框可以卡住长兵器、楼梯可以居高临下。场景里有什么，先列出来。
- **兵器长短决定距离**：长兵器要距离，被贴身就只能用杆、用尾；短兵器要贴身，被拉开就要借东西扑上去。
- **能力必须有代价和破绽**（规则 J6）：用完脱力、要蓄一下、会被打断。
- **体型悬殊的招式**：见 `竖屏比例差打戏` 的招式库（掠斩、绕臂盘旋斩、斜剑一磕、钻缝、借回收的兵器杀回、翻滚反手斩……），大多可以改成地面版。

## 八、不要做的

- 不写"从远处跑来""举剑蓄力""对峙"（规则 J4）。
- 不往镜头里堆没有目的的招（规则 J10）。
- 不用两个脸部特写收尾。
- 一镜不塞超过 4 拍，也不只给 1 拍。
- 镜头机位要看得见动作（规则 J8）。
- 〔竖屏〕不把两个人左右排在画面两边、中间一片空（规则 V1）。
- 〔竖屏〕不让被打飞的人横着穿过窄画面就算交代了"飞多远"（规则 V5）。

## 九、竖屏空间和构图〔竖屏〕

来源：《废土甜心》竖屏剧集的《镜头语法手册》二.4、导演反馈（第十七、十八集白模），加上为这套提示词新写的做法（标〔待验证〕）。

### 1. 先画俯视站位图，再定三件事

```
          [对手]  ← 远处，画面上方、偏右
            ↑
      （两人的连线）
            ↑
  [主角]            ← 近处，画面下方、偏左
     ↖ 机位在主角身后、靠机位那一侧的肩膀后面，离连线的一头偏一点
```

1. **左右**：主角在左、对手在右（180 度规则，整段不越轴，规则 H5）。
2. **远近上下**：同框时谁离镜头近（在画面下方）、谁远（在画面上方）。两人连成一条斜线，比左右排开装得下（规则 V1、V2）。
3. **长边**：被打飞、冲刺、俯冲的路线顺着哪条长边走：往镜头深处，还是从画面上方砸到下方（规则 V5）。

### 2. 同框的四种办法

| 办法 | 什么时候用 | 写法 |
|---|---|---|
| 纵深（一近一远） | 开场、来回切之后的同框、隔着一段距离对峙的瞬间 | 一方的肩背在画面下角、离镜头近；另一方在深处、画面上半；两人中间看得见地面和地标 |
| 上下 | 一方在高处（楼梯、屋顶、马上）、一方在低处 | 高的在画面上方往下打，低的在下方往上挡；镜头不跟着一路仰（规则 H7） |
| 过肩 | 贴身来回、出招和挨招的正反打 | 前景的肩或手臂只占画面下角，深处是对方的脸和兵器（规则 V7） |
| 并排（中景以内） | 只在两人贴身扭在一起（一步以内） | 两个上半身一前一后叠着，脸都在画面上半 |

### 3. 地标选竖的

柱子、门框、旗杆、楼梯、树、悬着的灯笼，放进窄画面也认得出；横着的长东西（长桌、长墙、长街）用高俯角顺着它拍，让它竖着排进画面（规则 H18、V6）。

### 4. 运动顺着长边

- 被打飞：从画面上方砸到中下部（俯拍；落点留在字幕位上面一点），或者往镜头深处飞，越飞越小。
- 冲刺、扑过来：冲向镜头（越来越大），或者从深处冲到近处。
- 跃起、坠落：用画面的高度。
- 横着穿过画面：两三帧就出画，只用来表现"快到看不清"（规则 V5）。

### 5. 脸和字幕位

脸和打中的那一下放在画面上方约六成以内；画面下方留给字幕，放地面、脚、前景（规则 V3）。

### 6. 横屏的 15 秒 6 镜模板翻成竖屏

| 镜 | 横屏（第六节模板 A） | 竖屏怎么拍 |
|---|---|---|
| 1 关系镜头 | 两人一左一右，地标在中间 | 纵深：主角肩背在左下，对手在深处右上，竖着的地标在两人之间 |
| 2 贴身交手 | 侧面跟拍 | 过肩或贴身跟拍，出招的手在靠机位一侧 |
| 3 细节或脸 | 特写 | 特写，脸撑满画面宽、在上半 |
| 4 同框看大招 | 宽画面里横着看 | 高俯角或低机位，大招的路线顺着画面长边 |
| 5 接力前半 | 打中 → 折起 | 同左 |
| 6 接力后半 | 被甩出去，拉到大景别 | 俯拍，从画面上方砸到中下部；或顺着纵深飞远 |
