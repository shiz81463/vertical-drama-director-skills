# 环1 拆戏：一集 → 几场戏

版本：v2（2026-10-25）｜竖屏快：验证·惹火34｜横屏精品：待验证

## 管什么

把一集拆成几场"戏"。一场戏 = 一件事、一种戏型。这一环决定后面用什么拍法（环4 按戏型选配方），以及时长怎么分。

不管：戏里面的情绪怎么一步步变（环2）。

## 步骤

1. 通读本集，找"事情变了"的地方：换了地点、换了对手、局势翻了、戏型变了（从吵架变成宣判，从宣判变成受封）。
2. 每一段起个名字，写一句话：谁对谁做了什么，结果怎样。
3. 定戏型：对照 `references/戏型拍法.md` 开头的戏型表，一场戏一个主戏型。
4. 写观众要明白什么、谁占上风（开始 → 结束）。
5. 定这场戏在集里的作用：钩子 / 推进 / 转折 / 高潮 / 收尾。
6. 估时长：先数台词，按方向的语速算出台词要几秒，再加上没有台词的动作拍。各场戏加起来，要落在单集时长范围里。

## 规则

- **1.0 戏表必须有**，每场戏都写戏型，戏型用戏型表里的名字〔自动 1.0〕〔通用〕
- **1.1 按"一件事"分，不按剧本场次号分**：一个场次可以拆成几场戏，一场戏也可以跨场次（同一地点、时间连续）。分界是局势、对手或戏型变了〔人工〕〔验证·惹火34：34-1 一个场次拆成"当庭互咬""宣判""败者退场"三场戏〕
- **1.2 一场戏一个主戏型**：混了两种（先吵后打），就拆成两场戏。戏型决定拍法，混在一起，镜头节奏会两头不靠〔人工〕〔通用〕
- **1.3 时长预算先算台词底线**：台词全留，用户要压才压，要删的逐条列出来给用户确认；英文按每秒不超过 2.5 个词、中文每秒不超过 4 个字（情绪重的 3 个）来算；再加动作拍。合计超过单集上限，列出能压的无台词拍给用户选〔自动 1.3：分镜表总时长不在单集范围里报 ❌〕〔用户；验证·惹火34〕
- **1.4 第一场戏的开头 3 秒是钩子**：冲突、危险或悬念的画面。钩子之后尽快给关系镜头，让观众看懂谁在哪〔人工〕〔废土甜心；验证·惹火34 镜1 按跪 + 铁镣砸地〕
- **1.5 最后一场戏照剧本收**：剧本是悬念，就停在事情发生之前；剧本是情绪收束，就停在人物的眼神上。不替下一集做事〔人工〕〔通用；验证·惹火34 停在艾拉看凯恩的眼神上〕
- **1.6 不加新剧情、新台词、新的可识别角色**，也不固定下一集要继承的状态（站位、数量、动作）。只补让观众看懂必需的镜头（关系、反应、视线），补了什么写在汇报里〔人工〕〔交接规则〕
- **1.7 转折密度按方向**：竖屏快每 10–15 秒一个小转折；横屏精品每 15–30 秒一个〔人工〕〔竖屏快 验证·惹火34；横屏精品 待验证〕
- **1.8 每场戏只讲清一件主要的事**，戏表里写清"观众要明白什么"。说不出来的，要么并进相邻的戏，要么是剧本本身缺东西，写进汇报的待确认〔人工〕〔通用〕

## 验收（交给环2 之前自问）

- 每场戏能用一句话说清吗？
- 每场戏的戏型都在戏型表里吗？
- 时长合计落在单集范围里吗？台词全留了吗？
- 开头有钩子吗？结尾照剧本收了吗？

## 出问题时的样子

- 看完不知道这集讲了什么，重点不突出。
- 某场戏情绪不对路，比如该温柔的拍成了吵架的节奏：戏型定错了。
- 节奏一锅粥：几件事挤在一起，没有分界。
- 时长超了，或者差很多。
