# 环0 开工卡

版本：v2（2026-10-25）｜竖屏快：验证·惹火34｜横屏精品：待验证

## 管什么

开工之前，把"不能猜"的事定下来。这一环错了，后面每一环都跟着错：节奏按错的方向排、场景尺寸和资产图打架、台词长度估错、接不上下一集。

不管：剧情怎么拆（环1）、镜头怎么排（环4、环5）；资产行、人物状态、穿帮（交给提示词技能）。

## 输入

用户给的剧本、场景资产图、制作要求。

## 步骤

1. 定方向：竖屏快节奏短剧，还是横屏精品剧。读对应的 `方向/` 文件。
2. 读剧本三段：本集全文、上一集结尾、下一集开头。
3. 项目有提供时，读 `<项目根目录>/_制作规范/导演反馈记录.md`。
4. 看场景资产图，记下出场人物。
5. 定单集时长范围、台词语言。
6. 填开工卡，记下这次用的各环版本。

## 规则

- **0.1 开工卡第一行写方向**："竖屏快节奏短剧"或"横屏精品剧"，和 `方向/` 里的文件名一字不差。方向决定一拍几秒、一镜几秒、怎么构图，脚本也按它查〔自动 0.1〕〔通用〕
- **0.2 四件不能猜的事，没给就先问**：方向、单集时长范围、台词语言（决定台词多长，影响镜头时长）、场景资产图〔人工〕〔验证·惹火34：台词语言是开工以后才定下的，镜头时长跟着返工〕
- **0.3 剧本读三段**：本集全文、上一集结尾、下一集开头。集数以剧本和文件夹名为准，有疑问先问；剧本有几个版本、或者有扩写版，先问用哪个〔人工〕〔废土甜心〕
- **0.4 场景的样子和尺寸照场景资产图**，不按剧本文字自己编。项目文件夹里有图就看图；只在平台上的，请用户给一张或说清布局〔人工〕〔验证·惹火34〕
  - 坑（惹火34）：分镜里写"台高一米、五级台阶"，场景资产图是一大段长台阶；"皇帝四秒走下五级台阶"就不成立了
- **0.5 开工前读导演反馈记录**，里面每一条和分镜有关的规则都要满足〔人工〕〔废土甜心〕
- **0.6 开工卡里记下各环版本**："环0 v2、环1 v2……"。以后哪集出问题，查得到是哪一版规则做的〔人工〕〔用户 2026-10-25〕

## 验收（交给环1 之前自问）

- 四件不能猜的事都有答案了吗？
- 场景资产图看过了吗？
- 下一集开头读了吗？

## 出问题时的样子

- 节奏按错了方向排（该快的排慢了）。
- 场景尺寸、样子和资产图打架。
- 台词长度估错，镜头装不下台词。
- 跟下一集接不上。
