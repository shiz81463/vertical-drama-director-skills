# 环4 镜头配方：按戏型定拍法

版本：v3（2026-10-27）｜竖屏快：验证·惹火34（冲突对峙、审判群戏、爽点高光、情感、转场）｜横屏打戏：部分验证·雪原铠甲（4.8–4.11，见 `references/打戏镜头调度.md` 各条状态）｜其余戏型和横屏精品：待验证

## 管什么

写逐镜之前，先给每场戏定一张"配方"：主力景别、景别怎么呼吸、必须有哪些镜头、镜头骨架。同一种戏用同一套拍法，节奏才稳。

用户 2026-10-25 的原话："情感戏就要用到正反打，给到一个近景，然后给到一个特写，特写面部也好、特写手部也好；打戏会有很多的近景，然后一个松的远景大景——有呼吸感的景别和镜头节奏。"

不管：每一镜的细节（环5）。

## 步骤

1. 按戏表里的戏型，去 `references/戏型拍法.md` 找配方，看对应方向的做法。
2. 写这场戏的主力景别：观众主要看什么。
3. 写景别呼吸：照环2 的紧 / 松 / 停，标出哪里紧、哪里松。
4. 列必备镜头：关系镜头放哪、每个事件后的反应镜头、插入镜头（手、道具）。
5. 写镜头骨架：不写细节，只写镜头类型的顺序。例："关系（纵深双人）→ 过肩正反打 ×2 → 单人近景 → 手的特写 → 回到双人"。

## 规则

- **4.0 每场戏一张配方**，写在第 4 节，戏号和戏表一致〔自动 4.0〕〔通用〕
- **4.1 戏型决定配方**。配方用着别扭，先回环1 看戏型定对没有，再改配方〔人工〕〔通用〕
- **4.2 景别要有呼吸：紧和松交替**。打戏用"紧紧松"：一串近景、特写（紧），接一个停得更久的大景别（松）；连着紧不超过 3 镜，松的镜头 2–3 秒，比紧的长〔自动 4.2：打戏里连着 4 镜以上近景或更紧，或者整场没有全景以上，报 ⚠️〕〔v13（16:9 打戏验证过）；用户 2026-10-25〕
- **4.3 情感戏由松到紧**：双人或过肩交代关系 → 过肩正反打（两边同景别）→ 单人近景 → 特写（脸，或者手上的动作）→ 转折以后回到双人，让观众看见距离变了〔自动 4.3：情感戏、暧昧戏一个特写都没有，报 ⚠️〕〔用户 2026-10-25；废土甜心 对话戏拍法；验证·惹火34 戏5〕
- **4.4 一场戏一个主力景别**，按观众要看什么来定：看表情 → 近景；看关系、两人的分量 → 中景、过肩；看动作、招式 → 全景；看规模、孤立 → 大全景。其他景别做点缀〔人工〕〔v13 拉片结论；验证·惹火34〕
- **4.5 必备镜头**：戏开头（或者进入新阶段）一个关系镜头；每个重要事件后一个反应镜头；插入镜头（手、道具、伤）出现之前，观众已经知道是谁的〔人工〕〔废土甜心 导演"镜头太孤立"〕
- **4.6 竖屏和横屏用同一个骨架，构图各按方向**：竖屏纵深、上下；横屏左右、前景层次。每个配方的两种做法都写在 `references/戏型拍法.md`〔人工〕〔通用〕
- **4.7 骨架先过一遍，再写逐镜**：骨架错了，逐镜写得再细也是错的。用户要逐环看时，这一环单独交〔人工〕〔用户 2026-10-25〕

### 有样片、拼长打戏（`references/打戏镜头调度.md`）

- **4.8 用户给了样片，先拉片再借镜**：切镜头表、打斗段加密抽帧，列"值得抄"清单（原片时间码、手法、观众感到什么），在第 4 节配方表下面加一张**借镜表**（新镜 / 借哪段 / 借了什么 / 改了什么）。只借镜头语言和打法结构；样片的人物、造型、台词、发光能量招不搬。样片里短于 1 秒的切点不硬塞进生成，写进"接法"交给剪辑〔人工〕〔用户 2026-10-27"这镜头调度不错"；验证·雪原铠甲 视频1、4、5、6〕
- **4.9 几段样片拼成一场，按局面排顺序**：先定谁占上风、怎么翻，再把样片段落放进去；几个场景统一成一张空间地图（左中右各一个地标）；断的地方补衔接戏，衔接戏要给下一段的高潮一个理由（雪原铠甲：火被冷雾闷灭 → 最后全开爆气）；兵器和伤口跨段记账〔人工〕〔用户 2026-10-27；待验证：拼出来的 90 秒还没整段生成〕
- **4.10 长打戏拆段，每段按局面选段落骨架**：群战开场、贴身对拳打远、局面反转、压轴登场、先吃亏、爆气终结（`references/打戏镜头调度.md` 第四节）。每段 10–15 秒、4–6 镜；每段第一镜接上一段最后一帧的动作〔人工〕〔验证·雪原铠甲：群战开场、压轴登场、先吃亏、爆气终结四段生成出来了；其余待验证〕
- **4.11 打戏的镜头手法从那份清单里挑**（擦镜、贴地跟脚、过肩纵深、冲镜、吞画面加空镜、前景大脸远处小人、先给脚再起身、前景大虚中景起身、俯拍关系地图、爆气环绕推近……）。每段至少一个"前景压一方、深处另一方"的纵深镜头，让一个镜头里有正有反；挑哪个都要答得出"因为……所以切到这里"〔人工〕〔用户 2026-10-27；各手法状态见清单〕

## 验收（交给环5 之前自问）

- 每场戏都有配方吗？戏型和配方对得上吗？
- 有样片时：借镜表里每一条都写了原片时间码吗？样片的人物、台词有没有被搬进来？
- 长打戏：每段选了哪个段落骨架？段和段之间接的是什么动作？衔接段给下一段的高潮理由了吗？
- 景别有紧有松吗？打戏有没有连着紧太久？
- 情感戏有特写吗？正反打两边同级吗？
- 每场戏开头有关系镜头吗？每个重要事件后有反应镜头吗？

## 出问题时的样子

- 情感戏不打动：缺特写、正反打两边不对等、转折后没回到双人。
- 打戏看不清（一直紧，没有松的大景交代位置），或者看累。
- 景别单调：一整场戏全是近景。
- 镜头孤立：缺关系镜头、缺反应镜头。
