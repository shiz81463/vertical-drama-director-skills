# 方向：横屏精品剧（16:9）

状态：**待验证**。还没有一集用这个方向拍过。下面的参数来自三处：

- 《废土甜心》按电影节奏做的分镜规范（`<项目根目录>/_制作规范/镜头语法手册.md`）：用户说之前的分镜"是按照电影感觉来的"，就是这一套；
- 精品制作 16:9 的打戏 v13（`武戏编导` 技能，验证过的打戏写法）；
- 16:9 的 `文戏编导提示词`（待验证）。

第一集用完，用户或导演认可哪条，就把哪条改成〔验证·剧名集数〕。

## 一句话

偏电影：镜头更长、景别更开、有呼吸，用调度和构图讲关系，快慢交替。快的地方（打戏、爆发）照样紧，慢的地方让镜头停得住。

## 参数

| 项 | 值 | 来源 |
|---|---|---|
| 一拍 | 3–6 秒 | 废土甜心 镜头语法手册（平静段每镜 3–5 秒）；待验证 |
| 一镜 | 常规 3–8 秒；长镜头调度 8–12 秒；打戏、爆发 1–2 秒的短镜 | 同上；打戏 v13；待验证 |
| 小转折 | 每 15–30 秒一个 | 待验证 |
| 开头 | 定场镜头可以长（大全景 3–5 秒）；钩子可以是一个悬念画面，不一定是冲突 | 待验证 |
| 峰值之后 | 文戏多停 1–2 秒，让余韵出来；打戏相反，不停 | 文戏编导提示词 H6；v13 |
| 台词语速 | 和竖屏一样的上限；句子前后留气口；听的人的反应镜头更长 | 待验证 |
| 主力景别 | 中景、全景为主，特写留给关键时刻 | 待验证 |
| 单集时长 | 按剧定，开工卡里写 | 用户 |

## 构图（横屏）

- **两人可以一左一右**：主角在左，整场不越轴；用三分法（人放在画面三等分的线上）〔废土甜心 镜头语法手册；待验证〕
- **前景层次**：门框、柱子、人群的肩做前景，让画面有纵深〔待验证〕
- **横向运动最清楚**：横移跟拍、人物横穿画面；追逐、冲锋保持银幕方向一致〔废土甜心〕
- **宽景讲环境和孤立**：人小、环境大；空镜、环境镜头做呼吸和转场〔废土甜心〕
- **长镜头调度**：一个镜头里人物走位、镜头跟着，把两个人串在一个画面里，代替来回切（环5 规则 5.16）〔待验证〕
- **风格锁里的宽银幕词**按 `<项目根目录>/精品制作/剧设定/` 里这部戏的剧设定〔用户〕
- **慢动作**：生成时一律实速（v13 全片实速）；要慢的地方在设计里标"建议升格"，后期做〔v13〕

## 和竖屏快节奏比

| | 竖屏快节奏短剧 | 横屏精品剧 |
|---|---|---|
| 一拍 | 2–3 秒 | 3–6 秒 |
| 一镜 | 2–6 秒 | 常规 3–8 秒，长镜头 8–12 秒，爆发 1–2 秒 |
| 同框 | 纵深、上下、过肩，不左右排开 | 可以一左一右，加前景层次 |
| 运动 | 顺着长边（纵深、上下） | 横向最清楚 |
| 峰值之后 | 不干停 | 文戏多停 1–2 秒 |
| 主力景别 | 近景、特写 | 中景、全景 |
| 关系怎么讲 | 镜头动作指出来（推、甩、移焦） | 调度和构图讲出来（站位、前景、留白） |

## 第一次用要验的

- 长镜头调度生成得出来吗：人物走位、镜头跟着，走位会不会丢。
- 慢的段落，观众会不会觉得拖。
- 一左一右站位，模型会不会越轴。
