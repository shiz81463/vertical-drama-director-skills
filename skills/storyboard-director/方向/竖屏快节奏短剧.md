# 方向：竖屏快节奏短剧（9:16）

状态：**已验证**。《惹火私厨》第 34 集：2026-10-22 分镜，导演"基本没问题"；用户 2026-10-25："本次执行的分镜脚本不错。"

## 一句话

两三秒一拍，每一拍要表达的东西，都用镜头动作引导出来。

用户 2026-10-22 原话："之前的分镜节奏是按照电影感觉来的，我需要的是快节奏短剧。两三秒一个拍，每个拍需要表达的东西都要镜头表现引导出来。"

## 参数

| 项 | 值 | 来源 |
|---|---|---|
| 一拍 | 2–3 秒 | 用户 2026-10-22 |

| 小转折 | 每 10–15 秒一个 | 验证·惹火34 |
| 开头钩子 | 3 秒以内 | 废土甜心；验证·惹火34 |
| 峰值之后 | 不干停，停留交给下一镜的反应 | 验证·惹火34 |
| 台词语速 | 英文每秒不超过 2.5 个词；中文每秒不超过 4 个字（情绪重的 3 个） | 验证·惹火34 |
| 主力景别 | 近景、特写为主（竖屏的单人近景脸撑满画面宽，最有力）；大景别只用来交代位置和"松" | 验证·惹火34 |
| 单集时长 | 按剧定（惹火：60–120 秒），开工卡里写 | 用户 |

## 构图（竖屏）

竖屏横向很窄（宽只有高的 0.56），横屏那种"两人一左一右站开"大多装不下。

- **不左右排开**：同框用纵深（一个离镜头近、在画面下方，一个远、在画面上方）、上下或过肩〔废土甜心；验证·惹火34〕
- **用上下讲权力**：占上风的在画面上方，弱的压在下方。惹火34：皇帝在台阶顶上，跪着的人在下〔验证·惹火34〕
- **脸放在画面上方约六成以内**，下方留给字幕〔废土甜心；验证·惹火34〕
- **过肩的前景压在画面下角**，只占约五分之一〔验证·惹火34〕
- **要看清的移动顺着画面长边走**：走向镜头、走进深处、上下；横着走一两步就出画〔验证·惹火34 镜29〕
- **竖摇把上下两件事串成一条线**：惹火34 镜40 徽章从皇帝手里 → 凯恩接 → 别到她胸前〔验证·惹火34〕
- **高的东西用画面的高度拍**：台阶、门、楼梯、高处的人〔废土甜心〕
- **两人挨得近（一步以内）才用中景以内的并排双人**，高的人的脸在上面〔验证·惹火34 镜41〕

## 和电影节奏比

| | 电影节奏（之前） | 竖屏快节奏短剧 |
|---|---|---|
| 一镜多长 | 3–5 秒 | 2–6 秒，一拍 2–3 秒 |
| 一拍的信息怎么交给观众 | 镜头停得久，让观众自己看 | 每一镜一个镜头动作，直接指给观众看 |
| 长台词 | 一个镜头说完 | 拆进几个镜头：说话的人 → 被说的人 → 旁观的人 |
| 峰值之后 | 多停一会儿 | 不干停，交给下一镜的反应 |
| 剪辑理由 | 每一刀都要有 | 不变：快不等于乱切 |
