# 分镜编导

> **整合包路径**：技能内文件从本文件所在的技能目录定位。`<本技能目录>` 替换成该目录的实际路径；`<项目根目录>` 是当前剧集项目。项目既有目录与规则优先；旧项目资料或案例原片未随包附带时，使用用户明确提供的等效资料。默认交付本地文件，只有当前请求明确要求平台操作时才读取或写入平台。

只做一件事：**把一集设计成分镜**。拆戏、定节奏、定空间和机位、按戏型配镜头、逐镜设计景别和运镜，以及每一刀为什么切。

- 2026-10-25 从《惹火私厨》第 34 集的分镜脚本整理出来。导演看完说"基本没问题"（2026-10-22），用户说"本次执行的分镜脚本不错"。这些做法写成了规则，标〔验证·惹火34〕。
- 流程拆成 **6 环**，每环一个文件，写清管什么、规则、产出、验收、出问题时的样子。分镜出了问题，按本页"出问题时找哪一环"那张表找到那一环，只改那一环的文件。
- 两个方向，参数各放一个文件：
  - **竖屏快节奏短剧**（9:16）：两三秒一拍，**已验证**（惹火34）。
  - **横屏精品剧**（16:9）：偏电影，镜头更长、更有呼吸，**待验证**（还没有一集用它拍过）。

## 管什么，不管什么

用户 2026-10-25："这个技能是纯粹用来做分镜脚本的……生成提示词的管穿帮的、管镜头里面人物表演肢体语言具体怎么表达、把分镜转译成提示词，这个是下一个技能（竖屏文戏、武戏编导）去做的，这里就是要把分镜专精设计好。"

| 本技能管 | 交给下一步的提示词技能 |
|---|---|
| 一集拆成几场戏，每场的戏型 | 生成段怎么切、每段几镜、段首段尾 |
| 节拍、情绪、节奏（紧 / 松 / 停） | 穿帮：人物只出现一次、群演、资产行、道具状态 |
| **可拍性（v2 新增）：机位放在模型拍得出来的地方（环3 规则 3.11–3.14）** | 可拍性在提示词阶段再查一遍（P 节） |
| 空间、轴线、视线、机位 | 人物表演、微表情、肢体语言怎么写 |
| 按戏型配镜头：主力景别、景别呼吸、镜头骨架 | 把分镜写成 Seedance 提示词 |
| 逐镜：景别、角度、运镜、镜头怎么引导、切入理由、时长、台词放在哪一镜 | 台词的口音润色、语气写法 |

下一步用哪个技能：小版竖屏文戏用 `vertical-dialogue-director`，武戏用 `vertical-action-director`；满血版的文戏、武戏、险情、混合段都用 `vertical-performance-director`。横屏提示词技能需另外安装。

## 先分清五个层次

| 层 | 是什么 | 例子（惹火34） | 在哪一环定 |
|---|---|---|---|
| 集 | 一集 | 120 秒 | 环0 |
| 戏 | 集里的一件事，戏型不变 | 戏1"当庭互咬"（冲突对峙戏）；戏4"受封"（爽点高光戏） | 环1 |
| 节拍 | 戏里局势或情绪变一次 | 主教甩锅 → 玛蒂尔达翻出账本反咬 | 环2 |
| 拍 | 观众得到一个新信息。竖屏快 2–3 秒一拍 | 她眼珠斜向主教 | 环2 定节奏，环5 落到镜头里 |
| 镜 | 一段连续画面，通常一拍一镜；也可以用镜头里的动作（移焦、推近、人物转身）装两三拍 | 镜7：甩镜头到玛蒂尔达，"Deceived?" | 环5 |

## 6 环流水线

| 环 | 做什么 | 产出（模板第几节） | 规则文件 | 脚本查哪几条 |
|---|---|---|---|---|
| 环0 开工卡 | 定方向，读本集和上下集，看场景资产图，定时长和台词语言 | 第 0 节 | `环/环0_开工卡.md` | 0.1 |
| 环1 拆戏 | 一集拆成几场戏，每场定戏型、作用、时长预算 | 第 1 节 | `环/环1_拆戏.md` | 1.0 1.3 |
| 环2 节拍与情绪 | 每场戏拆节拍：触发、情绪从什么到什么、紧 / 松 / 停 | 第 2 节 | `环/环2_节拍与情绪.md` | 2.0 |
| 环3 空间与机位 | 照场景资产图画平面图，定站位、轴线、视线，给机位编号 | 第 3 节 | `环/环3_空间与机位.md` | 3.4 |
| 环4 镜头配方 | 按戏型选拍法：主力景别、景别呼吸、必备镜头、镜头骨架 | 第 4 节 | `环/环4_镜头配方.md` + `references/戏型拍法.md` | 4.0 4.2 4.3 |
| 环5 逐镜分镜 | 每场戏一张分镜表：机位、景别、画面、镜头怎么引导、切入理由、台词 | 第 5 节 | `环/环5_逐镜分镜.md` + `references/镜头动作词典.md` | 5.0–5.5 5.8 |

方向参数（一拍几秒、一镜几秒、构图、语速）放在 `方向/竖屏快节奏短剧.md` 和 `方向/横屏精品剧.md`。各环规则里写"按方向"的地方，去方向文件里查数。

## 每次必做

1. **先做环0**：方向、单集时长、台词语言、场景资产图，这四件不能猜，没给就先问。读对应的方向文件；如项目提供导演反馈记录，再读 `<项目根目录>/_制作规范/导演反馈记录.md`。
2. **一环一环往下做**：每环做完，对照那一环文件里的"验收"，过了再做下一环。用户要逐环看的，就一环一环交给他看。
3. **照模板写**：`templates/分镜脚本模板.md`。表头不能改，脚本靠表头认列。
4. **交稿前跑脚本**：❌ 全部改掉，⚠️ 保留的逐条在回复里说明为什么。

```
node "<本技能目录>/scripts/check_storyboard.js" <分镜脚本.md>
```

   只写了一部分（比如先交一场戏）时加 `--partial`，不查整集时长和缺的章节。脚本报告按环分组，哪一环报错就回哪一环改。

5. **换成导演的眼睛过一遍**：只看第 5 节的"画面"列，从头到尾在脑子里放一遍（环5 验收最后一条）。

## 交付

- 路径：`<项目根目录>/<剧名>/第X集总/第一阶段_分镜脚本/第X集_分镜脚本.md`（X 用中文数字）。
- 回复（中文、大白话，术语第一次出现附一句解释）：
  1. 这集拆成了几场戏，每场的戏型，情绪曲线（两三行）；
  2. 剧本里没写、为了让观众看懂补的镜头，为什么补；
  3. 主要手法，以及它们解决什么问题；
  4. 脚本检查结果：几个 ❌、几个 ⚠️，保留的 ⚠️ 为什么保留；
  5. 待确认：剧本前后矛盾、要用户拍板的地方，不自己决定；用了哪些默认；
  6. 建议先给导演看过分镜，再交给提示词技能。

## 出问题时找哪一环

| 你看到的问题（审片、导演意见） | 先查 | 再查 |
|---|---|---|
| 看完不知道这集讲了什么，重点不突出 | 环1 | 环2 |
| 某场戏情绪不对路（该温柔的拍成了吵架的节奏） | 环1 戏型定错 | 环4 配方 |
| 情绪不到位，转折突兀，高潮不爽 | 环2 | 环4 |
| 节奏拖，或者一直一个速度没有起伏 | 环2 紧 / 松 / 停 | 环5 时长 |
| 看不懂谁在哪，人物换边，视线对不上 | 环3 | 环4 关系镜头 |
| 场景尺寸、样子和资产图打架 | 环0 场景资产图 | 环3 平面图 |
| 情感戏不打动；打戏看不清或看累；景别单调 | 环4 | 环5 |
| 打戏镜头平、没有调度感；给了样片却没学到 | 环4 规则 4.8–4.11 + `references/打戏镜头调度.md` | 环5 |
| 镜头孤立，"为什么切到这里" | 环5 切入理由 | 环4 必备镜头 |
| 画面像跳了一下（同一机位硬切到更紧） | 环5 规则 5.4 | — |
| 换场生硬，观众愣一下才知道到了哪 | 环5 规则 5.15 + `references/转场衔接.md` | 戏型拍法"转场呼吸" |
| 物理上说不通（够不着、看不到） | 环5 规则 5.12、5.13 | 环3 距离 |
| 台词装不进镜头 | 环5 规则 5.8 | 环1 时长预算 |
| 跟下一集接不上，抢了下一集的戏 | 环1 规则 1.5、1.6 | 环0 下集开头 |
| 人倒挂、透视崩、分屏、叠影、穿墙 | 环3 规则 3.11–3.14（v2） | 提示词技能 P 节 |
| 生成出来的穿帮、少镜头、嘴型、表演太大 | 不在本技能：去提示词技能 | 分镜里那一镜本身设计得对不对 |

## 怎么迭代一环

- **只改出问题的那一环的文件**。规则编号不重排：新规则接在后面；作废的规则留着，写"作废"和原因。（v2 是第一次使用前的整理，编号重排过一次，以后不再重排。）
- 那一环文件开头的版本号加一，文件末尾的"迭代记录"写一行：日期、问题原话（审片、导演或用户）、改了哪条、为什么。
- 每集分镜脚本的开工卡里记下这次用的各环版本（"环版本"一行）。以后哪集出了问题，查得到是哪一版规则做出来的。
- 规则状态：〔待验证〕的规则，在一集里用过、用户或导演认可后，改成〔验证·剧名集数〕；被证明不行的，改掉，并在条目下写"坑"（写了什么 → 出了什么 → 现在怎么写）。
- 用户要求维护制作规范时，将导演或用户的审片原话追加到 `<项目根目录>/_制作规范/导演反馈记录.md`，再按上面那张表找到对应的环改规则。
- 一个方向验证出来、对另一个方向也成立的写法，问过用户再同步。
- 能用脚本查的规则，加进 `scripts/check_storyboard.js`，编号和规则一致。
- 改规则先问用户：规则都来自用户和导演的验收。
