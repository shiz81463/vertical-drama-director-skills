# 用本机 GPT 出场景资产图

2026-11-09《320磅》第 29 集第一次这样做：派一个子代理控制这台电脑上的 ChatGPT 桌面版（开始菜单里叫"ChatGPT"），按出图清单出了 11 张，存到集文件夹，再一张张校对。下面是流程和踩过的坑。

用 GPT（ChatGPT、Codex）做这一步的组员，不用派子代理：直接在 ChatGPT 里照出图清单一条条发，出图、校对、存图的要求一样。

## 流程

这是可选的实际出图环节；只有用户明确要求生成场景图时才做。只有用户选择桌面代操作且工具可用时，才走下文的子代理路线。

1. **先写出图清单**：用 `templates/场景资产出图清单模板.md`。先有场景卡，才知道要哪几个方向。
2. **派子代理**：在 Claude 里说"派子代理用本机 GPT 按出图清单出图"。子代理会做这几步：
   - 加载电脑控制工具，申请控制 ChatGPT（写剪贴板那一项也要）；
   - 每场戏开一个新对话：先发总览，再在同一个对话里按方向一张张发；
   - 每张出来放大看一眼，按清单的校对四条检查，不合格就同一对话里改，最多重出两次；
   - 用 ChatGPT 自带的下载按钮存进目标文件夹，用清单里的文件名；存完核对文件在、大小不为 0；
   - 每存一张就记一张，最后在清单末尾填出图记录。
3. **总控复核**：子代理回报后，Claude 把总览和各方向图拼成几张小图，一张张看，再按图回改场景卡和场景锁的文字。
4. **人工过目后上平台**：每张图建一个主体，名字和提示词里的 @ 一样。

## 坑

| 遇到什么 | 原因 | 怎么办 |
|---|---|---|
| 权限弹窗返回"拒绝"，一张没出 | 申请控制 ChatGPT 的弹窗被拒了 | 停止桌面操作并回报；用户重新授权后才继续，也可让用户自行按清单出图 |
| 操作连着被打断（user interrupt） | 子代理靠截屏、点鼠标、按键盘控制 ChatGPT，人同时动鼠标键盘就会打断 | 出图这段时间（11 张约 25 分钟）人离开电脑；子代理也会把按键改成右键粘贴、点发送按钮 |
| 剪贴板被覆盖 | 长提示词是复制粘贴进去的 | 出图前把剪贴板里要留的东西存好 |
| ChatGPT 一口气出了几张 | 它自己给了几个版本 | 存它最后定的那张，在出图记录里写一笔 |
| 方向图左右和总览反了 | 掉头的方向，模型不一定会把左右对调 | 校对第二条专门看这个；第 29 集后台朝衣架那张就是重出了一次才对 |
| 图里的颜色、数量和清单写的不一样 | 模型照自己的理解画（T 台椅子画成浅灰褐色、五六排） | 不重出，以图为准，回改场景卡和场景锁的文字 |

## 不做的事

- 只发清单上的提示词和修改要求。不改 ChatGPT 设置，不登录、不退出、不换账号。
- 遇到登录、付费、额度用完、同意条款，就停下回报。
- 不碰别的应用和文件，不删文件。
