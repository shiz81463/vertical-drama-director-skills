# 戏型拍法：每种戏怎么拍

环1 给每场戏定戏型，环4 照这里选配方。每个配方写：观众要什么、镜头骨架、主力景别、景别呼吸、必备镜头、竖屏快怎么做、横屏精品怎么做、常见错、例子、状态。

**景别呼吸**：景别有紧有松，像呼吸一样。紧 = 近景、特写，信息密；松 = 全景、大全景，交代位置、喘口气。一直紧会累、会看不清；一直松会拖。

## 戏型表

| 戏型 | 什么戏 | 主力景别 | 景别呼吸 | 状态 |
|---|---|---|---|---|
| 情感戏 | 告白、心疼、和解、离别、感谢 | 近景 | 由松到紧，转折后松回双人 | 竖屏快 验证·惹火34（戏5）；横屏 待验证 |
| 暧昧戏 | 撩拨、贴近、心跳 | 近景 → 特写 | 一路收紧，被打断时一下松开 | 待验证 |
| 冲突对峙戏 | 吵架、互咬、威胁、谈判 | 竖屏近景；横屏中景 | 越吵越紧，权威介入时一下松开 | 竖屏快 验证·惹火34（戏1、戏3）；横屏 待验证 |
| 审判群戏 | 朝堂、审判、宴会、多人议事 | 中景 + 全景 | 审的人和被审的人一上一下正反打；群众反应做松 | 竖屏快 验证·惹火34（戏2）；横屏 待验证 |
| 打戏 | 人对人、对手和人差不多大的打斗 | 看观众要看什么（招式全景 / 分量中景 / 速度近景） | 紧紧松 | 横屏 v13，段落骨架部分验证·雪原铠甲；竖屏 待验证 |
| 揭示戏 | 发现证据、看到真相、认出一个人 | 特写（被揭示的东西）+ 近景（反应） | 先紧在反应上，再给东西，最后拉开看全貌 | 废土甜心；待验证 |
| 爽点高光戏 | 受封、打脸、反转、当众出头 | 近景 + 全景反应 | 宣布（紧）→ 旁观者（松）→ 本人怔住（停） | 竖屏快 验证·惹火34（戏4）；横屏 待验证 |
| 独处心理戏 | 独白、回忆、一个人的心事 | 特写 | 缓推，几乎不切 | 废土甜心；待验证 |
| 追逐潜入戏 | 追、逃、潜入、倒计时 | 中景 + 全景 | 越切越短，最后双方同框 | 废土甜心；待验证 |
| 转场呼吸 | 时间流逝、换场、关门 | 大全景、空镜 | 松 | 竖屏快 验证·惹火34（关门）；横屏 待验证 |
| 钩子悬念 | 开场钩子、结尾悬念 | 大特写 + 反应 | 推到顶，停在事情发生之前 | 废土甜心；竖屏快 验证·惹火34（开场） |

戏里先说后打：拆成两场戏，一场冲突对峙、一场打戏。

## 情感戏

- **观众要什么**：两个人之间的距离变了（近了或远了），感受到其中一个人的心。
- **镜头骨架**：关系（双人或过肩）→ 过肩正反打（两边同景别）→ 单人近景（情绪升级，两边一起收紧）→ 特写：脸（眼眶、嘴唇、喉咙一动）或手（触碰、攥紧、递东西）→ 回到双人（看见距离变了）
- **主力景别**：近景
- **景别呼吸**：由松到紧；转折后松回双人；关键那句台词之后留一拍
- **必备镜头**：开头的关系镜头；听的人的反应；至少一个特写，手上的动作往往就是情绪（别徽章、攥衣角、松开手）
- **竖屏快**：两张脸上下叠在画面上半部（高的人在上）；过肩的前景压在下角；单人近景脸撑满画面宽；手的特写单独一镜，或者用竖摇从手串到脸；峰值交给下一镜的反应，不干停
- **横屏精品**：两人一左一右（主角在左）；可以一个慢推的长镜头从双人推到单人；关键句之后多停 1–2 秒；可以用门框、窗框把两人框住或隔开
- **常见错**：正反打两边景别不对等；只拍说话的人，没有听的人；手的特写不知道是谁的手；推到眼睛切掉了下巴
- **例子（惹火34 戏5）**：镜40 竖摇（徽章从皇帝手里 → 凯恩接过 → 别到她胸前）→ 镜41 并肩双人慢推（他凑到她耳边低声说）→ 镜42 过凯恩肩，她低头看徽章，再抬眼看他
- **状态**：竖屏快 验证·惹火34；横屏 待验证

## 暧昧戏

- **观众要什么**：两人的距离一点点缩短，心跳起来。
- **镜头骨架**：双人（还有距离）→ 每一镜都更近一点（中景 → 近景 → 两张脸挨着）→ 身体局部的特写（手指勾领带、呼吸落在脖子上、锁骨）→ 被打断时一下拉开到大景
- **主力景别**：近景 → 特写
- **景别呼吸**：一路收紧；只在被打断（敲门、来人）时一下松开
- **必备镜头**：一个手的特写（主动的那一方的动作）；被撩的一方的反应（喉结、呼吸）
- **竖屏快**：两张脸上下叠（高的人在上），越来越近；声音放大呼吸、衣料
- **横屏精品**：两人侧脸相对，一左一右，中间的空隙越来越小；浅景深，背景全虚
- **常见错**：一上来就是特写，没有"距离缩短"的过程；尺度超出平台；局部特写不知道是谁的
- **状态**：待验证

## 冲突对峙戏

- **观众要什么**：谁在逼谁、谁在反咬，局势一下一下翻。
- **镜头骨架**：关系（双方同框）→ 正反打越切越近（中景 → 近景 → 特写）→ 甩镜头（猛地转到反咬的人）→ 旁观者的反应（前景道具、扇子、酒杯）→ 最凶的一句急推 → 权威介入：起势（手入画）→ 喝止（声音抽空）→ 大景别看双方僵住
- **主力景别**：竖屏近景；横屏中景
- **景别呼吸**：越吵越紧；权威介入时一下松开
- **必备镜头**：开头的关系镜头；每次反咬后被咬的人的脸；至少一个旁观者的反应
- **竖屏快**：两人用斜角一前一后叠起来（近的那个就是要说话的那个）；甩镜头顺着视线方向甩；长台词拆进说话的人、被说的人、旁观的人
- **横屏精品**：两人一左一右对峙，过肩正反打；可以让一方往前逼一步，用走位讲压迫
- **常见错**：只拍说话的人；正反打方向不对（像各骂各的）；没有松，一直吵到观众累
- **例子（惹火34 戏1）**：鸟瞰钩子（按跪 + 铁镣砸地）→ 金座背后定场 → 仰拍皇帝 / 俯拍冒汗的主教 → 纵深双人 → 甩镜头到玛蒂尔达 → 过肩互骂 → 菲利普的酒杯在"三座城"时停住 → 纵深急推 → 皇帝的手离开扶手 → "够了"全场静音 → 侧面对角线大全景
- **状态**：竖屏快 验证·惹火34；横屏 待验证

## 审判群戏

- **观众要什么**：谁在上、谁在下，判决一条条落在谁身上，众人怎么看。
- **镜头骨架**：定场（从审的人身后往下看，所有人位置一次排清）→ 仰拍审的人 / 俯拍被审的人（正反打）→ 第三方（旁听、同伙）的反应 → 宣判：每说一条罚，镜头推近被罚的人一点 → 被判的人垮下去（高机位俯拍）→ 人群反应（横移扫过一排脸）
- **主力景别**：中景 + 全景
- **景别呼吸**：审的人和被审的人之间一上一下来回；人群的反应做松
- **必备镜头**：开头的定场；每条判决落下时被判的人的脸；人群反应至少一次
- **竖屏快**：用画面的上下讲高低（审的人在上方，被审的在下方）；长判词拆成几拍，每拍落在不同的人脸上
- **横屏精品**：大全景交代整个场面（两排人、中间的过道）；可以用长焦压缩，让审的人显得压在被审的人头上
- **常见错**：判词一口气念完，没有落到被判的人脸上；没有人群反应；审的人和被审的人拍不出高低
- **例子（惹火34 戏2）**：皇帝把判决交给菲利普（皇帝左上、菲利普右下，同框）→ 菲利普放下酒杯起身 → 主教的脸一点点发白（缓推）→ 过主教冠仰拍菲利普 → 玛蒂尔达的脸，罪名念完推到大特写 → 高机位俯拍她瘫倒
- **状态**：竖屏快 验证·惹火34；横屏 待验证

## 打戏

- **观众要什么**：谁在打谁、打中没有、力有多大、局势怎么变。
- **一招的最小单位**：起势（让观众预判）→ 出招（动作做到一半切，下一镜做完）→ 接触（命中、格挡、闪避，双方同框）→ 后果（受击方和环境的反应）→ 引出下一招
- **镜头骨架**：关系镜头（双方位置）→ 一串紧（近景、特写，最多 3 镜）→ 一个松（全景，2–3 秒，重新交代位置）→ 再一串紧……大打击用"打击接力"：打中（特写）→ 身体折起（中景，换角度）→ 被甩出去的路线（拉到大景别）→ 一个 1 秒的反应脸
- **主力景别**：看观众要看什么：看身法、一招一式 → 全景；看两方扭在一起的分量 → 中景；看速度和贴身 → 近景。一段只选一个主力
- **景别呼吸**：紧紧松：连着紧不超过 3 镜，松的镜头比紧的长；每 2–3 个回合给一个关系镜头
- **必备镜头**：开场关系镜头；每次重击后的反应脸；每个大动作后一个关系镜头
- **竖屏快**：两方用纵深和上下同框，不左右排开；被打飞的路线顺着画面长边（上下、纵深）走；脸放在画面上方
- **横屏精品**：两方一左一右对冲，横向运动最清楚；银幕方向保持一致
- **常见错**：A 在挥拳，下一镜 B 倒地，命中那一下没出现；一直紧，看不清谁在哪；招式重复，招和招之间没因果
- **长打戏、有样片**：一场长打戏拆成 10–15 秒的段，每段按局面选段落骨架（群战开场、贴身对拳打远、局面反转、压轴登场、先吃亏、爆气终结）；用户给了样片就先拉片借镜。手法清单、段落骨架、借镜表都在 `references/打戏镜头调度.md`（环4 规则 4.8–4.11）
- **例子（雪原铠甲demo 压轴登场，横屏）**：前景反派头盔占右三分之一，左上远处山脊一个火人跳下 → 跟着他顺坡滑下冰面 → 滑铲推起的雪浪和白汽把反派逼退一步 → 贴地先给铁靴，再起身 → 受伤同伴抬头看呆 → 背后过肩，主角抬起臂铠开火口，冰面那头反派拔枪
- **交给下一步**：每一招的具体打法、力往哪走、动作怎么写，在 `竖屏武戏编导`（竖屏）、`武戏编导`（横屏）里做；分镜这里定镜头骨架和景别呼吸
- **状态**：横屏 v13；横屏段落骨架 部分验证·雪原铠甲（视频1、4、5、6 生成出来了）；竖屏 待验证

## 揭示戏

- **观众要什么**：一个重要的东西被看见了（证据、真相、一张脸），以及看见的人怎么反应。
- **镜头骨架**：两种。一是先给人物的反应（瞳孔一缩、手停住），再给她看到的东西，制造好奇；二是先给局部（一角、一个字），再拉开看到全貌。最后给看到的人的下一个动作
- **主力景别**：特写（被揭示的东西）+ 近景（反应）
- **景别呼吸**：先紧在反应上 → 给东西 → 拉开看全貌
- **必备镜头**：插入的特写之前，观众已经知道是谁在看；主观镜头只拍她从那个位置看得到的
- **竖屏快**：东西放在画面上方，脸在下方，或者用移焦把东西和脸连起来
- **横屏精品**：可以用一个慢推把东西揭出来；客观镜头交代人物看不到的部分
- **常见错**：两个特写直接硬接，中间没有"她在看"；主观镜头里拍了她看不到的东西
- **状态**：废土甜心（揭示拍法）；待验证

## 爽点高光戏

- **观众要什么**：地位一下翻过来，所有人都看见了。
- **镜头骨架**：宣布的人仰拍急推（最重的那句）→ 旁观者的反应（横移扫过一排惊掉的脸）→ 本人怔住（不切，给足两秒）→ 本人的动作（行礼、站直、抬头，用全景拍完整）→ 身边最亲的人的一个小动作（别徽章、扶一下腰）
- **主力景别**：近景 + 全景反应
- **景别呼吸**：宣布（紧）→ 旁观者（松）→ 本人（停）→ 亲密的小动作（紧）
- **必备镜头**：旁观者的反应（没有人震惊就不爽）；本人怔住的那一拍
- **竖屏快**：宣布的人在画面上方；人群从前景一排后脑和侧脸拍过去，背景留出主角的位置；本人走进光里
- **横屏精品**：大全景让人群和主角同在一个画面；可以用一个环绕镜头拍高光时刻
- **常见错**：只拍宣布的人和本人，没有旁观者；本人反应太快，没有"愣住"
- **例子（惹火34 戏4）**：皇帝叫"艾拉"→ 她朝镜头走来、走进阳光，两排贵族的头跟着她转 → 皇帝走下台阶 → 锦盒打开、徽章一闪 → "第一女伯爵"仰拍急推 → 贵族倒抽一口气、扇子停住 → 徽章到她脸上的移焦 → 她怔住两秒 → 屈膝行礼
- **状态**：竖屏快 验证·惹火34；横屏 待验证

## 独处心理戏

- **观众要什么**：一个人心里在想什么。
- **镜头骨架**：近景或特写，缓推 → 她走神、闭眼（"她在想"）→ 插入她想到的东西（回忆、想象）→ 回到她的脸
- **主力景别**：特写
- **景别呼吸**：缓推，几乎不切
- **必备镜头**：每个插入镜头之前，都有一个"她在想"的镜头
- **竖屏快**：脸撑满画面宽；头顶留出大片的空（负空间）= 孤独
- **横屏精品**：人放在画面一边，另一边留空；可以用大全景让人很小
- **常见错**：插入回忆之前没有"她在想"的镜头，观众不知道这是谁的回忆
- **状态**：废土甜心；待验证

## 追逐潜入戏

- **观众要什么**：距离越来越近（或越来越远），快来不及了。
- **镜头骨架**：交代双方和距离 → 交叉剪辑（追的人、被追的人来回切），越切越短 → 倒计时（距离数字、环境标记）→ 最后一刻双方同框
- **主力景别**：中景 + 全景
- **景别呼吸**：越切越短、越来越紧，最后同框时松一下
- **必备镜头**：开头的距离交代；最后双方同框
- **竖屏快**：追的方向顺着画面长边（纵深、上下）
- **横屏精品**：追的人和被追的人朝同一个方向跑（银幕方向一致）
- **常见错**：方向不一致，看起来像跑反了；从另一条线切回来时没有重新交代位置
- **状态**：废土甜心；待验证

## 转场呼吸

- **观众要什么**：时间过了、地方换了、气氛变了。
- **镜头骨架**：空镜、关门、光落到空地方、时间卡
- **主力景别**：大全景、空镜
- **景别呼吸**：松
- **竖屏快**：1–3 秒；门、光柱这类竖着的东西很好用
- **横屏精品**：3–5 秒；可以叠化
- **常见错**：两秒里塞了两个动作（关门 + 下摇），观众看不过来
- **不要停顿、要顺着冲过去的换场**：不用空镜，用 `references/转场衔接.md` 的五种转场（动作承接、相似衔接、视线引导、甩镜、遮挡）〔待验证〕
- **例子（惹火34）**：镜27 大门合上，镜头落到空了的红毯和阳光上，34-1 转到 34-2
- **状态**：竖屏快 验证·惹火34；横屏 待验证

## 钩子悬念

- **观众要什么**：开场 3 秒就想看下去；结尾想看下一集。
- **开场骨架**：3 秒内一个冲突、危险或悬念的动作 → 马上给关系镜头，让观众看懂
- **结尾骨架**：威胁的大特写 + 主角的反应 → 推到顶 → 停在事情发生前的那一帧，硬切
- **主力景别**：大特写 + 反应
- **竖屏快**：开场用强构图（正上方鸟瞰、极端仰拍）加一个硬声音（铁镣砸地）
- **横屏精品**：开场可以是一个长的定场加一个悬念细节
