# 场景卡（V2）：每场戏一节（同一个地方、同一个时段算一场）。这里的文字各段照抄。先读 手册/0_V2写法.md 第三节：先推方向，再写。
# 不写：地图、站位、不入画、锚点（V1 的键）。人在哪写在每段的开场、收场和那一镜里。

== 场景：〈地方〉，〈时段〉 ==
时间: 〈中文：这场戏是什么时候，如 冬夜〉
成片里: 〈中文：画面里除了写到的人还有谁、没有谁，如 栈道上只有本段写到的人〉
材质: 〈中文：这场戏特有的三四样材质，人身上的也写，如 湿木栈道反着灯光，头发被雾气打湿成一缕一缕〉
# 颜色句: 〈可不写，默认剧设定的画面质感句。如 暗部压深、带一点墨蓝。〉
# 风格锁: 〈可不写。场景版风格锁：只删这一场用不到的东西和片名、平台名，别的原样照抄剧设定〉
光源: 〈英文几句：这场戏的光只从哪几样东西来、各是什么颜色、照到哪。光源都要在场景里看得见。剧设定里有定义的写 @@特效:触发词@@〉
空气: 〈英文半句：空气里有什么〉
前景: 〈英文半句：虚焦的前景层，… down one side of the frame〉
高光: 〈英文一个词：高光来自什么，如 dock lamp〉
总览图: 〈平台上真正 @ 的那张总览图的名字〉
# 总览说明: 〈可不写。如 总览图是同一座码头的几个视角，取它的结构、材质、灯的位置和方位〉
总览: 〈中文：照图写这个地方。哪一头是什么、两条边各是什么、独一无二的东西在哪、灯在哪；给每样东西起一个固定的名字（陆地端、尽头、湖栏、第二盏灯）〉
地标: 〈全景里用来说人贴着什么的固定物，空格隔开，如 湖栏 横栏杆 集装箱 尽头灯〉
前景层: 〈中文：镜头常用的虚前景，如 栏杆柱、衣角、湿发、肩膀〉
后景层: 〈中文：虚掉以后是什么，如 化开的灯和湖面〉
# 焦段: 〈可不写。如 28–35mm 给空间和冲势，50mm 给关系，85mm 给情绪〉
环境声: 〈中文：这场戏的现场声，如 湖风、湿木板、衣料、呼吸〉
# 结尾: 〈可不写。场景版结尾句（英文），照剧设定那句改光和地点〉
# 打戏、险情才写：近处的东西、远处的东西、速度痕迹、打出来的东西（英文）；动作特效: <<< 多行英文 >>>
