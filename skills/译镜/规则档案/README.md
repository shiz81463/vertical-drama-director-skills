# 规则档案

> **V2（2026-11-24）：以 `手册/0_V2写法.md` 为准。** V2 作废的：V3、V4（脸在画面上方、TALL FRAME、upper two thirds）、P15 的 no split screen 一串、X1–X7 和 X6 站位锚点、F2 / F3 / G2 / H1 的英文固定句、B1 / B3 / B6 的旧区块、结尾"不生成BGM"。V2 的检查编号是 K1–K29（`scripts/lib/check_v2.js`、`build.js`），说明在手册 0 和手册 3 的报错表。仍然有效的：P 可拍性（除上面两条）、Q 台词、W、U、T6 / T12 / T14–T16、Z 打戏设计、L 账本、Y 时长。

这里是 v4 及以前的全部规则原文、证据和设计方法，一共约 20 万字。**平时写提示词不用读**：能自动做的已经由 `scripts/` 做了，要人判断的已经浓缩进 `手册/`。检查报了一个编号、想知道出处，或者总控要改规则时，来这里查。

改规则的地方只有这里和 `scripts/`、`手册/`，每条规则只有一份。改之前先问用户；验证过的写法不动。

## V1.1（2026-11-19）：E01 补拍审出来的

起因：用户让回看一集用译镜写的提示词（某黑帮圣诞剧 E01 补拍，8 段加 1 个单镜）。检查脚本几乎全过，但人读出了十几处会穿帮或自相矛盾的地方。分三类补：

- **脚本能查的，加成 U1–U8**（见上表）。出处都是这一集：段2、5、7、8 有人看镜头；段7 想"慢放重看"摸眉毛；段1、2 光句给一张脸打冷暖两种光；段1 暴怒抡树用了写恐惧的险情固定句；单镜31 开头"Hard cut to"；8 段都有"highlights highlights"；段2 玻璃碎了却用完好的方向图；段4→5 时间跳以后 "Come in." 不成立。
- **只有人能看的，加进 `审查清单_文戏.md` 第 40–51 项**，并且文戏、险情也必须审（用户 2026-11-19 定，原来只有武戏必审）。
- **修了三个误报和一个 bug**：单个"雷"字撞人名（I2 只认雷声一类的词）；剧设定不在本机时套用别的剧连报 S1–S5（相似度 0.8 以下只报一条 S1）；文件夹检查漏查单镜补拍；本机剧设定特效质感第三句以 highlights 开头，和模板接成"highlights highlights"（parse.js 去掉开头那个词；第 29 集和武戏样例重编后和存档一字不差）。

用户同时定了：看镜头一律禁止，主观镜头不例外；台词对分镜（G30）只留在 GPT 模式。

档案里提到的文件路径（`templates/提示词骨架.txt`、`references/…`、`文戏/scripts/…`）是 v4 的摆法。v5 里对应的是：骨架在 `规则档案/骨架/`，参考文件就在这个文件夹，脚本在 `scripts/` 和 `scripts/lib/`。

## v5 和这些规则的关系

- **没有删规则。** 文字原样搬过来，只是每份只留一份（v4 里文戏、武戏两个目录各有一套，9 个文件是重复的）。
- **固定句的出处**：`scripts/templates/文戏.tpl` 用的是《320磅》第 29 集生成用过的写法（v3 精简句，加 Restraint）；`武戏.tpl`、`险情.tpl` 照 `骨架/` 里的 v4 骨架逐句搬的。
- **由"查"变成"不会错"的规则**：B1 区块顺序、B6 逐拍时间连续、S1–S5 剧设定固定句、Q3 台词句数、Q4 台词起止秒、X1–X5 和 X7 同一场戏各段文字一致、资产行的固定开头。
- **新加的**：L1–L3 连续性账本；X6 站位锚点从"人工"变成自动查。
