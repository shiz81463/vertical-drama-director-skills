# 手册 2：人物卡和承接（V2）

旧格式的写法在 `v1/2_人物卡和账本.md`。

## 人物卡

`人物卡.txt` 里，这一集出场的每个人、每组群演、每样有资产图的道具各一节。节标题是人物键（`== Vincent ==`），段落源里用这个键指人。

| 键 | 写什么 |
|---|---|
| 名 | 中文名 |
| 图 | 平台上的 @ 名字。**一人一张**，别同时挂脸图和全身图（会出两个人，K21）。道具一物一种状态，开合两态拼一张的先裁开 |
| 音频 | 平台上的 @ 音频名。脚本只挂给这一段说话的人；不说话的人挂了音频会张嘴 |
| 类型 | 可不写，默认"人"。道具写"道具" |
| 固定 | 这一集每段都不变的话：只有一个、年纪和高矮对比、头发、**衣服写死颜色料子款式**（K28） |
| 记账 | 主要人物写"是"：每段都要写开场 |

- 只有一个：`成片里只有一个文森特，别人都不长他的样子、不穿他的衣服。`
- 尺寸用对比：`比伊森高半个头`。
- 参考图里的衣服和这一集不一样：先换参考图。只改文字没用，成片跟图（E30 写了针织裙，图是毛衣，两段成了毛衣）。
- 正在发生的东西（警灯、烟花、爆炸、雾、手铐铐住的样子）不建人物卡，只用文字写。
- 不写给人看的备注。

## 开场和收场 = 承接画面和结束画面

```text
开场: Ethan | 冲到文森特面前一臂远，脚还没落稳 | 在第二盏灯那圈光朝尽头的边沿 | 右手握着短刀 | 脸朝陆地端
收场: Ethan | 脸朝下趴着 | 在第二盏灯和尽头灯之间的湿木板上 | 右手腕软着压在身侧 | 头朝陆地端
结束: 短刀躺在湖栏边的积水里，水还在一圈圈荡
```

编出来是【承接画面】"第一帧就从下面的状态开始，动作接着往下走：伊森：……"和【结束画面】。

| 格 | 写什么 |
|---|---|
| 姿态 | 这一瞬身体在干什么。收场停在**动作中间**：`脚还没落稳`、`膝盖正弯到一半` |
| 位置 | 贴着哪样固定物，用场景卡"总览"里起的名字，各段同一个说法 |
| 手里的东西 | 东西在哪只手；空着写 `空着手` |
| 脸朝哪 | `脸朝尽头`、`面向右侧的奥利维亚`。没有的格写 `—` |

脚本查：

- **L1 ❌**：同一场戏里，这个人**最后一次出现**的收场（没写收场就是开场）和这一段开场四格逐字一样。隔了两段才再出现的人也查。
- **L2 ⚠️**：记账的人在场却没写开场。
- **L3 ⚠️**：这一段里变了，"状态"没写从第几镜起。
- 同一场戏真的过了一会儿：后一段写 `衔接: 时间跳`。跳过的变化会列进"要总控批的事"（U8）。
- 镜头 1 的运镜接着上一段的结尾写；段 1 接上一集最后一镜的状态。

**为什么**：模型不记得上一段。以前用"伊森身后永远是方向 1"锁站位，第一段演完人已经不在那了，第二段又被拉回开场、排成一排（反面案例 02）。

## 人、表演

```text
人: Vincent | 风衣下摆湿了一截
表演: 伊森又急又乱，全部的力气都在这一刀里，牙咬着，只有粗喘。文森特冷、准、省，眼睛先动，身体后动。
```

- `人` 竖线后面写这一段才有的、从头到尾都成立的话，可以空着。**某一镜才发生的变化不写在这里**，写"状态"。
- `表演` 中文一两句，说每个有名字的人这一段什么状态、从哪漏出来。固定句（REAL AND VISIBLE…）脚本贴；安静克制的戏加 `表演档: 收`。
- 冲、打、怒的人写嘴：`牙咬着，只有粗喘`（K18）。哭写泪光、眼眶湿，不写眼睛通红（K11）。
