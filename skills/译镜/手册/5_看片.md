# 手册 5：看片

成片下载回来（文件名里要有"段N"），先让机器筛一遍，人再看。

```
node "D:\漫剧公司\.claude\skills\译镜\scripts\review.js" "<提示词文件夹>" "<成片文件夹>"
```

结果在提示词文件夹下的 `审片\`：一份 `审片报告.md` 和按方向拼好的图。脚本只读成片，不改任何东西。找不到 ffmpeg 就加 `--ffmpeg <ffmpeg.exe 的完整路径>`。

## 报告里的三样

| 查什么 | 怎么查的 | 过线 | 不过回哪里改 |
|---|---|---|---|
| 背景和光 | 同一场戏、同一个方向的镜头各抽一帧拼成一张 | 同一张图里背景认得出是同一处：同样两三样东西、在同一边；光的方向和软硬一样 | 先看场景图对不对（`手册/1_场景卡.md`），再看场景卡那个方向的"背景"和"光" |
| 切点 | 成片里画面突变的时间，对提示词写的切点 | 写了几刀就切了几刀，差不到一秒 | "少切"多半是提示词太长，最后几镜没演到：砍字数，或者少一镜 |
| 台词 | 语音识别，逐句对 | 每句都听到，像不像在 0.9 以上；没有多出来的话，没有中文 | 没听到：看这段字数、这句是不是贴着段尾；多出来的话：看"声"里有没有写人声 |

机器的局限：

- 切点是按画面变化找的，慢推和甩镜头会找偏。
- 语音识别会漏掉 hi、no 这种很短的词，也分不清"说错一两个词"。"没听到"和像不像低于 0.9 的句子，自己听一遍。
- 台词这一项要装 Python 和 faster-whisper，还要一个模型文件夹（默认找 `D:\优质精品真人剧拉片素材\拉片工具\asr-models\faster-whisper-medium`，别处的用 `--asr-model` 指）。没有就跳过，前两项照出。
- 表演好不好、穿不穿帮，机器看不出来，要人看。

## 人看什么

- **连着看**：同一场戏的几段按顺序连着放一遍。单独看一段像穿帮的地方，连起来看可能是顺的（第 29 集段 2：温蒂坐下了，少了坐下的动作，单看像穿帮）。
- **表演**：情绪看不看得懂；有没有夸张、面具脸、定格；听的人有没有反应；和剧本括号里的提示对不对得上。
- **人**：姿态、位置、手里的东西，和编译报告里的连续性账本对一遍。
- **脸上的光**：同一场戏同一个方向，这一段和上一段脸一样亮吗。

每段记一行发给总控：

| 段 | 字数 | 台词全对几句 / 共几句 | 表演（1–5） | 背景和光跟同一场别的段对得上吗 | 有什么问题（第几秒） |
|---|---|---|---|---|---|

## 发现问题以后

改源文件，重新编译，只重生成有问题的段。同一场戏里前后有关联的两段（比如人从站到坐），要重生成就一起重生成。

同一类问题出现两次，告诉总控：是规则该补了，不是这一段写得不好。
