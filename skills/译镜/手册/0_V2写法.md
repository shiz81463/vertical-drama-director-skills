# 手册 0：V2 写法（先读这一页）

2026-11-24 起默认用 V2。和后面几本手册、规则档案打架的地方，**以这一页为准**。旧集要重编成老样子，集卡写 `格式: V1`。

来源：用户 2026-11-23 对第 27 集提示词的七条要求 → E27 v2（段 2、3、5、6 效果好）→ Gemini 照同一写法做的 E30 v2（24 镜全部用进成片）。坏的写法和成片结果都在 `反面案例/README.md`，写之前扫一遍。

## 一、用户的要求（原意）

| # | 要求 | 在 V2 里怎么落 | 查 |
|---|---|---|---|
| 1 | 不写画面上半、下半，会分屏。可以写三分法、黄金比例、左上侧、左下侧 | 【分镜】每镜一行"构图" | K2 |
| 2 | 第一段结尾的状态拿来当第二段的开头，不简单锁定站位 | 账本"开场 / 收场"四格 → 【承接画面】【结束画面】 | K4、K6、L1、X13 |
| 3 | 方向在 @ 的那张总览图里推理 | 场景卡"依据"；先画俯视格再写左右；图里没有的方向不用 | K4、K5 |
| 4 | 不要看不懂的镜头 | 没有人的孤立特写不要；每个眼神有由头；切点接着上一镜 | K7、K15、K19 |

## 二、编出来长什么样（每段都一样）

全局视觉风格 → 画面质感 → 实拍光影规范 → 场景与方位 → 人物与道具 → **承接画面** → 戏的逻辑 → 人物与表演 → 机位与视线 →（武戏、险情多一块 动作质感）→ 镜头语言 → 本段变化 → 分镜 → **结束画面** → 声音 → 结尾句。

你只写四种源文件，固定句、时间、台词行、承接和结束都是脚本拼的。范例：`examples/V2_黑帮圣诞第30集_文戏/源/`、`examples/V2_黑帮圣诞第27集段2_武戏/源/`。

## 三、先推方向，再写一个字

1. 打开平台，把这一集**真正 @ 的那张总览图**下载下来（不是本地另一张版本）。
2. 看它有几格：正面格、反面格、俯视格各是什么。**在俯视格上标出**：每个人站哪、脸朝哪；每个机位站哪、朝哪。
3. 每个方向推一遍：机位站在那里看过去，画面左边是什么、右边是什么、尽头是什么、光从哪边来。**机位转 180°，左右对调。**
4. 图里没有的方向不用。剧情一定要：先出一张这个方向的图，人看过左右，再写。（E27 的"朝集装箱"没有图：三条里一条变成朝尽头、一条背景变成湖、一条左右翻。）
5. 场景卡每个方向写"依据"：照哪一格推的。写不出来就是没依据，编译报 ❌。
6. 全景、远景镜在"机位"或"构图"里**再说一遍人贴着哪样固定物**（栏杆、桌、墙、灯），这样东西在画面哪一侧。固定物写进场景卡"地标"（K26）。

## 四、承接和结束

- 开场、收场写四格：`人物键 | 姿态 | 位置 | 手里的东西 | 脸朝哪`。没有的格写 `—`。
- 上一段收场 = 下一段开场，**逐字一样**。隔了几段才再出现的人，接他最后一次的状态。
- 收场停在**动作中间的那一瞬**，别停在站好、坐好。下一段第一镜的运镜写 `接着他……的这一步`。
- 一段里变了的东西写进"状态"（编出来是【本段变化】）：从哪一镜起变，然后保持。
- 不写"身后永远是方向 1"，不写"站成一排"。轴线可以写：`全段机位在湖栏这一侧，文森特在左、看右；伊森在右、看左`，只管这一段。

## 五、每个镜头

```text
== 镜头：一闪，一扣，一拧 ==
机位: 中景 35mm | 方向1 | 文森特右后方一步、靠湖栏、胸口的高度
运镜: 跟着伊森的冲势向左横移半步；手腕被扣住的一瞬镜头骤停、轻轻一震；刀脱手后缓缓推近半步，落定。
构图: 文森特的背和右肩占左侧三分线，伊森从右侧深处压进来，两人之间一臂；湖栏在右侧边缘往深处退。
光影: 尽头灯从左后方把伊森的湿发勾出暖边，他的脸由右侧湖面的冷光照着。
分镜秒: 3
拍 0.7: 出招：……
落幅: 刀正在往下掉，伊森歪着身子，文森特站得笔直，风衣还在落下来。
声: 衣料破风，一声清脆的“咔”，然后静半拍。
```

| 键 | 怎么写 |
|---|---|
| 机位 | 景别和焦距、方向、镜头站在哪和多高。镜头能站的实地。焦段一段里要有变化 |
| 运镜 | **起点 → 怎么动 → 停在哪**。第 2 镜起用"接着 / 随着 / 顺着"开头，说清这一刀接的是哪个眼神、哪句话、哪个动作。一段最多一镜固定，写清为什么 |
| 构图 | 一句：主体在哪条三分线或黄金分割点；前景是什么（虚）；看向哪边、留空在哪边；深处化开什么。过肩写"肩虚化压住右侧前景一角"，不写"右下角" |
| 光影 | 这一镜脸上的光从哪边来，是哪盏灯。光源在画面里看得见、全程都在；不写从镜头身后、画外来的光 |
| 拍 | 一拍至少 0.5 秒、只装一个动作。中文写，信号要这个景别看得清 |
| 落幅 | 这一镜最后停在什么上，写**还在动的**：呼吸、呵气、衣角、火苗、水波。不写静止、定格、纹丝不动 |
| 声 | 一个最要紧的声音。不写嗡嗡、心跳、音乐 |

没台词的动作镜 1.5–2.5 秒；反应、情绪镜 2.5–4 秒；有台词的照语速。一段里长短要错开。开头不留空：第一拍就在动作里。

## 六、人、表演、看哪

- 人物卡"固定"写死衣服：颜色、料子、款式，加"成片里只有一个……"。参考图里的衣服和剧情不一样，先换参考图（E30：写了针织裙，图是毛衣，成片跟图）。
- 音频写在人物卡"音频"，脚本只挂给这一段说话的人。
- 单人近景、特写只写这一个人，看谁写 `视线擦着画面左侧镜头边`。不提画外的人，不挂画外人的图。
- 背景里有第二个人就写清姿态（坐着、抱着膝），不然模型让他站着。
- 眼神动一次写一个由头：听见警笛、门响、看见刀。
- 没台词的镜有人冲、打、怒：写 `牙咬着，只有粗喘`。不然模型自己配词。
- 哭：`眼里全是泪光`、`眼眶湿了`，不写眼睛通红、充血、红着眼。
- 衣服、身体从镜头前过：写"从画面一侧边缘擦过，人始终看得见"。抱住、裹住：写露在外面的部分（头发、半张脸、攥着衣领的手）。

## 七、风格锁的场景版

剧设定的风格锁整部剧一份。场景卡可以写 `风格锁: ……` 给这一场用：**只删**这一场用不到的东西（码头戏里的烟花、圣诞树、皮草）和片名、平台名（《×××》、Netflix、HBO），换成同样意思的质感描述。验证过的质感句、镜头句、负面提示词原样留着，不改写。剧设定文件不动。

## 八、源文件里 V2 多出来、不再用的键

| 文件 | V2 加的 | V2 不用的 |
|---|---|---|
| 集卡 | `格式: V1`（只有旧集要）、`背景声词` | |
| 场景卡 | `风格锁`（场景版）、`颜色句`、`光源补充`、`总览说明`、`地标`（必填，空格或顿号隔开）、`前景层`、`后景层`、`焦段`、`动作特效`（武戏、险情）、`结尾`（场景版）；每个方向 `依据`（必填） | `地图`、`站位`（写了报 ❌）、`不入画`、`锚点`；方向的 `图`、`尺寸`、`朝` |
| 人物卡 | `音频` | |
| 段落源 | `名`（片头显示的段名，如"段2""衔接镜1"）、`机位视线`、`表演档: 收`（安静的戏）、`人声`（没台词的段）、`动作质感`（追加一句）、`类型: 衔接`（不查 8–20 秒）、开场收场第五格 | `空间`、`视线`（有"机位视线"就不用）、`同框`、`正反打`、`站位` |
| 镜头 | `构图`、`光影`、`落幅` | `Cut on the look` 这类英文切点类型（改在运镜里写"接着……"） |

武戏的设计（讲什么、设定、回合、攻防）照旧必填，见手册 6。拍里的标签可以写中文：`出招：` `闪避：` `格挡：` `反击：` `受击：`，最重的一下写"最重的一下"。

## 九、写完

1. `node scripts/build.js <源文件夹>`，❌ 改到 0，⚠️ 一条条看。
2. 照 `规则档案/审查清单_文戏.md` 或 `_武戏.md` 审一遍，意思上的矛盾脚本查不出来。
3. 回复里说：字数和旧稿比变了多少、为什么；哪几句改过、还没生成过。
4. 上平台前：平台 @ 的总览图就是推方向的那张；参考图的衣服和人物卡一致；一段一次填完核对字数。
5. 被平台拦（版权、违规）：**原样再生成一次**；还拦，一次只改一处再试，记下改哪处才过。别凭一次拦截就改构图（反面案例 22）。
