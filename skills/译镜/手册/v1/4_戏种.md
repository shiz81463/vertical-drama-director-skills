# 手册 4：戏种（文戏、武戏、险情）

段落源开头的"戏种"决定用哪个模板。三个模板的固定句不一样，选错了画面会出大问题。

## 怎么选

| 这一段是什么 | 戏种 | 说明 |
|---|---|---|
| 对话、对视、告别、等待、走秀、致辞 | 文戏 | 镜头只在情绪变的时候动 |
| 文戏里夹一下：一巴掌、推一把、泼一杯酒、摔一个杯子 | 文戏 | 那一下单独一镜，写三拍：起手 → 一眨眼的接触 → 反应。不用武戏模板 |
| 人对人连着打两个回合以上 | 武戏 | 镜头跟着打，一直在动 |
| 摔倒、塌陷、坠落、落水 | 险情 | 镜头站稳，人和东西动 |
| 一段里先说后打 | 能拆就拆成两段；拆不开用武戏，台词放在两次交换之间的空当 | |

**灾难戏不用武戏模板。** 前十集有 4 段灾难戏用了打戏的写法（镜头永远在动），全部严重穿帮。

三个模板的成片验证情况：

| 模板 | 状态 |
|---|---|
| 文戏 | 《320磅》第 29 集 10 段用过，背景、光、台词基本没问题 |
| 险情 | 固定句照 v4 险情骨架搬的，还没有成片验证 |
| 武戏 | 固定句是横屏 v13 验证过的，竖屏排法还没有成片验证 |

## 险情多写的键

段落源里：

| 键 | 写什么 | 例子 |
|---|---|---|
| 逻辑 | 英文 2–4 句：危险从哪里开始、按什么顺序变；谁要去哪、抓住了什么；什么还没发生 | The danger starts under Wendy's knee, one pane only, and grows one step at a time. … |
| 轴线 | 英文：谁在左谁在右 | Wendy is always on the LEFT, Ethan on the RIGHT |
| 战损开场 | 英文：开场谁带什么伤、裂到第几级 | nobody is hurt and the floor is whole |
| 战损新增 | 英文：这一段新增的伤和裂，从第几镜起 | from shot 1 one hairline crack runs from under Wendy's left knee |
| 实拍特效 | 英文：这场戏用到的实拍特效 | real glass grit and dust |
| 结束 | 英文：最后一帧谁在哪、抓着什么、危险到了哪一级；什么还没发生 | |
| 险情谁 | 可不写。`受惊`（默认）或 `动手`。人是砸东西、闯祸的那一方（暴怒抡树砸玻璃）写 `动手`，脚本把"THREE LAYERS""FACES"两句固定句从写恐惧换成写怒气（V1.1 加，动手的版本还没成片验证）。不写的话，检查看到人物句里是怒气、固定句却是恐惧，会报 ⚠️ U4 | 动手 |

不写"空间""视线""同框""正反打""状态"。

每个镜头多一行 `特效: ……`（英文）：这一镜谁的光照到谁、新出现了什么。

场景卡里多写"空气里的东西"和"接触特效"，见 `手册/1_场景卡.md`。

险情的写法：

- 镜头站在实地上，不飞、不掉、不翻；只在重物落在近处时轻轻一震。
- **一镜最多升一级**：裂纹从没有到一道、从一道到一片、从一片到塌，各是一镜。整块塌落拆三镜。
- 碎裂照剧设定的定义写，不写蛛网、spiderweb；写死在哪块地板、从谁的手或膝盖下开始，不写"他身后的裂纹"。
- 第 2 镜起每镜第一拍用 `Matched on action,` 开头。
- 害怕先从手和呼吸漏出来；没写在台词里就不喊叫。动手的一方是怒气从手和呼吸漏出来，写"险情谁: 动手"。

编译到 ❌ 0 以后，险情段和文戏段一样，照 `规则档案/审查清单_文戏.md` 审一遍（V1.1 起必做），结果写进回复。

## 武戏：先设计，再写镜头

**写武戏前必读 `手册/6_打戏设计.md`。** 武戏段的段落源开头要有打戏设计：`讲什么`、`设定`（双方各一行）、`回合`、`攻防`（攻防表）。没有的话编译报 ❌ Z1。编译会出一份《打戏设计单》，把这些摆成表给总控看。

编译到 ❌ 0 以后，武戏段还要照 `规则档案/审查清单_武戏.md` 审一遍，这一步必做，结果写进回复。

## 武戏多写的键

段落源里（设计那几个键见手册 6）：

| 键 | 写什么 |
|---|---|
| 逻辑 | 英文 3–5 句：谁拿什么、用哪只手；双方想要的距离；主角要去哪、打到哪才算数；每一招由局面逼出来 |
| 打出来的东西 | 英文：挨打时会被打出来的东西，如 sweat, dust or splinters |
| 挨打的人 | 英文：谁 |
| 撞到什么 | 英文：被打飞以后撞到什么，如 crashing through a table and tumbling |
| 轴线 | 英文：谁在左谁在右 |
| 进攻方向 | 英文：谁朝哪打、挨打的往哪飞 |
| 同框 | 英文：真有高低差写 A is near the lens, low in the frame, and B is farther back, higher in the frame；同一地面写 both stand on the same ground at their real heights, the nearer one larger |
| 近处的东西、远处的东西、速度痕迹 | 英文：镜头跟着人跑时，近处什么东西一闪而过、远处什么拖成线、速度留下什么痕迹 |
| 战损开场、战损新增 | 同险情 |
| 实拍特效 | 英文，如 real dust, splinters and sweat |
| 地方 | 可不写。英文，如 part of the room |
| 禁止项、主体规则、体型与比例、唯一的东西 | 可不写。对手比人大十倍以上才写"体型与比例"，照 `规则档案/武戏规则.md` |

场景卡里写"特效规范"（多行），见 `手册/1_场景卡.md`。

每个镜头多一行 `特效: ……`。武戏的拍要带 ATTACK / DODGE / DEFENSE / COUNTERATTACK / REAL HIT REACTION 这些标签，和攻防表里设计的一一对上（对不上报 ❌ Z3）；每一下打击写三段：风先到 → 一眨眼的接触 → 力传出去。第一镜第一拍用 `Already mid-fight.` 开头，第 2 镜起每镜用 `Matched on action,` 开头。

攻击、回应、闪避、防守、反击、受击各怎么设计，在 `手册/6_打戏设计.md`。镜头节奏（紧紧松、打击接力、正反打）和竖屏构图的细节，在 `规则档案/打戏设计.md` 第六节、第九节。
