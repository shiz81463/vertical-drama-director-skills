# 手册 8：机位术语库（34 个，可以直接调用）

用户 2026-11-24 给的清单：写镜头的时候直接用这些术语。在镜头里加一行，脚本就展开成固定写法：

```text
机位: 近景 85mm | 方向3 | 餐桌靠门口一侧三脚架、坐姿眼高
术语: 四分之三侧面、前景遮挡
```

编出来：

```text
机位：近景 85mm，四分之三侧面、前景遮挡（three-quarter view; shot through foreground）｜朝玻璃墙｜餐桌靠门口一侧三脚架、坐姿眼高
拍法：脸转向一侧约四十五度，两只眼都看得见，视线前方留空；前景有虚化的栏杆、烛火、门框或肩，压住一侧边缘，人在它后面是实的。
```

## 规矩

1. 一镜最多两个术语：一个角度或方位，加一个构图或光。两个角度会打架（低角度加高角度编译报 ❌）。
2. 术语只说镜头怎么拍。方向、人在哪、看哪边，照旧写在机位和构图里。
3. 写了术语，"构图"里就不用再说一遍同样的话。
4. 标"特殊"的一集最多用一次、一段最多一个（K29）：鱼眼、荷兰角这类用多了就是花活，用户要的是看得懂。
5. **状态**看的是在我们平台（漫影工坊 seedance 竖屏视频）有没有成片证据。截图里的图是图片模型出的静帧，术语通用，但能不能在我们这里稳定做出来，"待测"的先用在不要紧的镜头上试，看片后改状态。

## 和别的规则打架的几个

- **第一人称、自拍视角**：人会看镜头。规则 U1（用户 2026-11-19 定）是一律不看镜头，主观镜头也不例外。第一人称照样写对面的人看镜头旁边；自拍视角只有剧情真的在自拍、直播、视频通话才用。
- **荷兰角**：模板固定句写着地平线是平的。用了它，脚本自动把那两句改成"除了镜头 N"。
- **顶视视角**：只拍桌面、地面、手。站着的人从正上方拍，头身比例会坏。
- **航拍、洞内、冰箱内部、虫视**：都是新的方向，总览图里没有就先出图（K4）。
- **前景遮挡**：压一侧边缘，别盖住脸，别写"从镜头前扫过"（K12，成片黑过半秒）。
- **微距、放大镜**：别拍文字，会冒乱码。
