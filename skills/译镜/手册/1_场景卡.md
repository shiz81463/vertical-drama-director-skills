# 手册 1：场景卡（V2）

场景卡是一场戏的布景图纸：地方长什么样、镜头朝哪几个方向拍、每个方向画面左右是什么、光从哪来。同一个地方、同一个时段算一场戏，一场一节，一集的都写在 `场景卡.txt`。旧格式的写法在 `v1/1_场景卡.md`。

脚本把场景卡的文字原样贴进这场戏的每一段，所以守三条：

1. **只写整场戏都成立的事。** 不写"镜9""段2"（❌ X12），**不写谁站在哪**（❌ X13，反面案例 02）。人在哪写在每段的开场、收场和那一镜里。
2. **不写给人看的备注**（T16）。要留话写成 `#` 开头的注释行。
3. **方向只写图里有的。** 每个方向写"依据"，写不出依据的不用（❌ K4，反面案例 03、04）。

## 先推方向（必做，写字之前）

1. 下载**平台上真正 @ 的那张**总览图。本地的、飞书的、别的版本都不算。
2. 认出每一格是什么角度，找到俯视格。没有俯视格的，照几格对出一张平面草图。
3. 在俯视格上标：固定物（起名字）、灯、每个人、每个机位和朝向。存一张图放进源文件夹旁边（E27 的例子：`E27_方位推理图_照总览图.png`）。
4. 站到每个机位上推：画面左侧、右侧、尽头各是什么，脸的光从哪一侧哪盏灯来。机位转 180°，左右对调。
5. 剧情要的方向图里没有：先出一张这个方向的图，人看过左右，再写进来；或者改分镜，换图里有的方向。

## 每个键

| 键 | 写什么 |
|---|---|
| 节标题 | `== 场景：地方，时段 ==`。段落源的"场景"要和它一字不差 |
| 时间、成片里 | 中文。什么时候；画面里除了写到的人还有谁、没有谁 |
| 材质 | 中文三四样，人身上的也写（湿成一缕一缕的头发、吸了潮气发沉的大衣）。只写这一场有的，不留上一场的道具 |
| 颜色句 | 可不写，默认剧设定"画面质感" |
| 风格锁 | 可不写。场景版：只删这一场用不到的东西和片名、平台名，别的原样照抄剧设定（手册 0 第七节；K22） |
| 光源 | 英文几句：光只从哪几样东西来、各是什么颜色、照到哪、之间暗到什么程度。光源都要在场景里看得见，不写画外的灯（K14）。剧设定有定义的写 `@@特效:触发词@@` |
| 光源补充 | 可不写，英文，另起一行的光 |
| 空气、前景、高光 | 英文：空气里有什么 / 虚前景 `… down one side of the frame` / 高光来自什么（一个词，不写 highlights） |
| 总览图 | 平台上真正 @ 的名字 |
| 总览说明 | 可不写：这张图是什么（几个视角），取它的哪几样 |
| 总览 | 中文，照图写：哪一头是什么、两条边各是什么、灯在哪、多大。**给每样固定物起一个名字**，全集都用这个名字（陆地端、尽头、湖栏、第二盏灯） |
| 地标 | 必填。全景里用来说"人贴着什么"的固定物，空格隔开（K26） |
| 前景层、后景层、焦段 | 中文，拼进【镜头语言】：常用的虚前景、虚掉以后是什么、这场戏的焦段怎么分工 |
| 环境声 | 中文：这场戏的现场声。不写嗡嗡、心跳、音乐（K3） |
| 结尾 | 可不写。场景版结尾句（英文），照剧设定那句改光和地点 |
| 出图 | 可不写。总览图的英文出图提示词，写了就生成出图清单 |

每个方向一小节，标题 `-- 方向1：朝什么 --`，一场戏 2–4 个：

| 键 | 写什么 | 例子（E27 旧码头） |
|---|---|---|
| 背景 | 中文：画面左侧、右侧、尽头各是什么 | 集装箱和尽头灯在画面左侧，湖栏和黑的湖面在画面右侧，最远处横栏杆外是湖和对岸城市灯火 |
| 光 | 中文：暗处的脸、亮处的脸各由哪一侧哪盏灯照亮 | 暗处的脸由右侧湖面的冷光照亮，左侧发际有尽头灯的一线暖边 |
| 依据 | 照哪一格推的 | 平台 @S50 总览图的"朝尽头"格，左右和俯视格核对过 |
| 出图 | 可不写。这个方向的英文出图提示词（要补图的方向才写，同时写 `图: @名字`） | |

## 光

- 每个方向写清脸的主光从画面哪一侧来、是哪盏灯。背对亮处的方向也给脸一个明确的主光，不写"脸暗"（X10）。
- 剧设定写了"一张脸一次只属于一种光"的，一个方向的脸只给一种光，另一种只落在头发、肩、衣服边（U3）。
- 会变的光（警车、烟花）：光源写在画面里、全程都在；写清几辆、停在哪、一直转。参考图不挂，只写字（K14、K21）。

## 一个地方，前后两种样子

玻璃碎了、东西烧了、白天变夜里：**每一种样子算一场戏，各配一张总览图**，@ 名字带上状态（`_完好`、`_破窗后`）。拿完好的图配"玻璃已经碎了"的文字，成片会照图变回完好的（E01 段 2）。

## 出图：先全景，再拆单张，人工校对

1. 先出一张全景总览，定死布局、材质和这场戏的光；最好带俯视格。
2. 要补的方向：在同一个出图对话里照总览出单张，或从全景里裁。图里不能有人、不能有字。
3. 每张人工校对，过了才建主体。一张图一个主体。校对：没人没字；左右和俯视格一致（掉头左右对调）；光和场景卡一致；写的东西都在。以图为准，回头改场景卡。

`build.js` 会照"出图"生成 `<前缀>_出图清单.md`。本机 ChatGPT 出图的流程和坑见分镜编导 `references/本机GPT出图流程.md`。

## 打戏和险情多写的键

| 戏种 | 多写什么 |
|---|---|
| 武戏 | `打出来的东西`、`近处的东西`、`远处的东西`、`速度痕迹`（英文）；`动作特效: <<< … >>>`（英文多行：空气怎么动、地上溅什么、兵器怎么闪） |
| 险情 | `接触特效`（英文：这场戏的接触各一句）、`动作特效` |

## 自查

- [ ] 推方向用的是平台真正 @ 的那张图，俯视格标过人和机位
- [ ] 每个方向有背景（左、右、尽头）、光、依据；没有图里没有的方向
- [ ] 没有写谁站在哪、身后永远是什么
- [ ] 光源都在画面里看得见；没有画外光、镜头身后的光
- [ ] 地标写了；固定物全集一个名字
- [ ] 风格锁场景版只删不改
